# v0.8.4 实现与效果报告

本轮已完成规则改造与四次真实出图。原半身参考重做的青金图在叠手、袖摆、浅色内裙和长衣片上比上一轮更接近用户方向；材质局部调整的收益较小，整体轻盈感仍不及用户提供的全身标杆。两张用户原图继续保留，生成候选未升级为正式母图。

## 原因与实现

上一轮的实际提示词同时要求自然垂手、简洁束带、少露内裙、限制披纱、无长拖尾。这些约束适合克制扩展，却与本次用户展示的定妆效果不一致。仅检查「全身、白底、手指、鞋」无法覆盖构图美感与服装层次。

- 新增 `costume_showcase`：以颈肩腰、前中长衣片组织修长感，保留适合造型的宽袖、A形裙摆和自然遮鞋；显式手势仍优先，不强迫所有角色叠手。
- 新增 `full_body_anchor`：完整全身设计已给出时，绕过默认脸、年龄、九头身和手势，不再编造下半身。相冲突的预设覆盖明确报错。
- 补充标杆参考权限、实际构造描述和比较方法；审美标杆不自动接管身份，新的设计延展不冒充原图可见事实。
- 同步技能入口、代理描述、工作流、生成示例、回归模板、发布检查。局部 focus 的计划说明也同步收窄，避免文字说只修材质、计划元数据仍包含改灯光。
