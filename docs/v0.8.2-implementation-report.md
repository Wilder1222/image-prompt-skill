# image-prompt-skill v0.8.2 Implementation Report

## Release theme

**Asset Master Refinement**

v0.8.2 focuses on turning the successful white-background ancient-costume workflow into a repeatable production path rather than a one-off pretty-image generator.

## Implemented modules

### 1. Granular Face Profiles

Added five explicit face profiles layered on top of the legacy face modes:

- `beauty_first_clean`
- `beauty_first_character` **(default for ancient white-background female assets)**
- `humanized_real_light`
- `humanized_real_full`
- `stylized_beauty`

`beauty_first_character` keeps beauty and youth first while adding enough individual eyelid, cheek, mouth-corner and skin-response cues to reduce generic AI-beauty drift without aging the face.

### 2. P9 Fashion Asset

Added `P9_FASHION_ASSET` as a robe-aware proportion profile. It preserves the tall fashion read through waist placement, central vertical panels, controlled sleeve/hem width, footwear visibility and balanced hip-knee-ankle relationships rather than brute-force leg stretching or head shrinking.

### 3. Four-layer Material Separation

Added an ancient-costume material split:

1. primary fabric
2. sheer overlay
3. woven / embroidered pattern layer
4. structural layer

This targets the common failure where silk, gauze, embroidery and sash all collapse into one soft glossy fantasy material.

### 4. Generation-time Hand Guard

Added `elegant_crossed_hands_safe`. Crossed hands are now treated as a generation-time anatomy constraint with explicit primary/supporting-hand relationship, five-digit integrity, finger-length hierarchy, knuckle/wrist logic and sleeve-root visibility.

### 5. Asset Master Framing

Added `master_sheet_single` with top-ornament visibility, full footwear visibility, safe margins, controlled hem spread, readable shoes, balanced negative space and stable frontal body axis.

### 6. Studio Soft Separation

Added `studio_soft_separation`: high-key white seamless background, soft front-left upper key, weaker frontal fill, subtle edge separation, grounded floor contact shadow and non-clipped pale fabric.

## New isolated repair rounds

- `asset_master_face_refine`
- `asset_master_structure_refine`
- `asset_master_material_light_refine`

Recommended order:

`asset_master_face_refine → asset_master_structure_refine → asset_master_material_light_refine → final_photographic_polish → upscale`

The key policy is: **never sacrifice a passed face to improve materials, hands, proportions or lighting.**
