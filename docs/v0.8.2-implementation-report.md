# image-prompt-skill v0.8.2 实施报告

> 历史报告中文译文。原始提交：`c22950353e6f00b93870c7dc3fb9315b94609667`；原始文件：`docs/v0.8.2-implementation-report.md`；原文 SHA-256：`60604a5469c9546285137586d76c0081aec3c419ff99a09604c6e9091f386e2e`。下文忠实记录当时的默认值、阶段顺序和验证结果，不代表当前配置或新增图像验收。旧版露鞋、固定交叠手、年龄和白底要求不覆盖当前任务；当前规则允许姿态、表情、发型和背景按需求调整。

## 发布主题

**角色资产母版精修**

v0.8.2 聚焦将已有成功的白底古装工作流转化为可重复的生产路径，使其不只用于一次性的好看图片生成。

## 已实现模块

### 1. 细分面容方案

在旧面容模式上增加五个明确方案：

- `beauty_first_clean`：干净的美感优先方案。
- `beauty_first_character`：人物特征优先的美感方案，**当时古装白底女性资产的默认值**。
- `humanized_real_light`：轻度真人化方案。
- `humanized_real_full`：完整真人化方案。
- `stylized_beauty`：风格化美感方案。

`beauty_first_character` 保持美感与年轻感优先，同时加入人物特有的眼睑、面颊、嘴角及皮肤反应线索，降低通用人工智能美人脸漂移，不以衰老纹理增加真实感。

### 2. P9 时装资产比例

增加适配长袍的比例方案 `P9_FASHION_ASSET`。当时通过腰位、中央纵向衣片、袖摆宽度控制、鞋履可见度及髋膝踝的均衡关系保持高挑时装观感，避免暴力拉腿或缩头。

### 3. 四层材质区分

增加古装材质分层：

1. 主体布料。
2. 轻纱罩层。
3. 织造或刺绣纹样层。
4. 结构层。

用于处理丝绸、纱、刺绣与腰带混成同一种柔软亮面幻想材质的问题。

### 4. 生成阶段的手部约束

增加 `elegant_crossed_hands_safe`。当时将交叠手视为生成阶段的解剖约束，明确主手与承托手关系、五指完整性、指长层级、指节与手腕逻辑，以及袖口与手部连接处的可见性。

### 5. 资产母版取景

增加 `master_sheet_single`，当时要求顶部饰件与鞋履完整可见、安全留白、衣摆开度受控、鞋型可读、负空间均衡和稳定的正面身体轴线。

### 6. 柔光棚拍与边缘分离

增加 `studio_soft_separation`：明亮白色无缝背景、左前上方柔和主光、较弱正面补光、细微边缘分离、接地阴影，以及保留高光细节的浅色衣料。

## 新增局部修复阶段

- `asset_master_face_refine`：资产母版面容精修。
- `asset_master_structure_refine`：资产母版结构精修。
- `asset_master_material_light_refine`：资产母版材料与灯光精修。

当时推荐顺序为：资产母版面容精修 → 资产母版结构精修 → 资产母版材料与灯光精修 → 最终摄影质感润饰 → 放大。

对应接口顺序保留为：

`asset_master_face_refine → asset_master_structure_refine → asset_master_material_light_refine → final_photographic_polish → upscale`

核心原则：**不能为了改善材料、手部、比例或灯光而牺牲已经通过的面容。**

## 新增诊断项

面容：

- `face_template_generic`：面容模板化。
- `face_character_specificity_low`：人物面容独特性不足。
- `asset_age_impression_drift`：资产人物年龄观感漂移。

结构：

- `p9_asset_read_weak`：P9资产比例观感不足。
- `robe_volume_suppresses_height`：长袍体量压低身高观感。
- `asset_master_framing_loose`：资产母版取景松散。
- `footwear_readability_low`：鞋履可读性不足。
- `hand_cross_overlap_ambiguous`：交叠手的遮挡关系含混。

材料与棚拍：

- `material_layers_merged`：材质层混合。
- `embroidery_flat_print`：刺绣像平面印花。
- `gauze_opacity_wrong`：纱的透明度错误。
- `studio_light_flat`：棚光平板。
- `white_edge_separation_weak`：白色边缘分离不足。
- `floor_contact_shadow_missing`：缺少地面接触阴影。

## 当时的默认预设

`ancient_female_white_master`：古装女性白底母版。

- 渲染模式：`style_asset`。
- 面容方案：`beauty_first_character`。
