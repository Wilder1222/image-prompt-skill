# v0.9.0 Git 与 Codex 插件支持

新增标准 Codex 插件清单和 `skills/image-prompt-skill/` 入口，根 `SKILL.md` 继续作为唯一行为规则来源。独立 Skill、命令行和插件加载相同的参考、资源、模板与编译器。

## 交付

- Git 使用 `main` 分支；`.gitignore` 排除生成图片、参考附件、压缩包、构建目录和本机配置。
- `.gitattributes` 固定文本使用 LF，发布 SHA-256 不受跨平台检出换行影响。
- `plugin:sync` 同步技能元数据、代理配置和版本；支持保留官方本地更新 helper 生成的 `+codex.<token>` 后缀。
- `plugin:build` 输出完整独立插件目录，先校验源文件，再校验构建。已被人工编辑或含未知文件的旧构建不会被自动删除。
- [安装说明](codex-plugin.md) 使用默认个人 marketplace，不写入团队市场或远程仓库地址。

## 验证

- 241 项自动化测试通过，包含 8 项新增插件测试。
- 本机 Codex `validate_plugin.py` 校验通过；生成技能入口的 `quick_validate.py` 校验通过。
- 资源、入口链接、插件同步、JSON 和发布摘要检查通过。
- 测试中从独立构建目录启动编译器，保留全身母图的指令可正常生成，不依赖原仓库工作目录。
- 本机 CLI 检查使用 `codex-cli 0.147.0`。实际安装与缓存检查回执保存在 `dist/verification-v090/`；安装后的技能需要在新任务中加载。

本版本增加分发与加载能力，没有重新生成或替换 v0.8.4 的视觉测试图。源代码测试通过不代表视觉质量已经获得用户验收。
