# image-prompt-skill v0.7.7 详细模块升级方案

本文件为v0.7.7历史升级方案的中文整理。文中的“当前”“默认”“已通过”和定量门槛均指当时银发案例，不是本轮新评审，不覆盖现在的身份、妆容、动作、发型、背景与体型要求。YAML配置键值、诊断标识和兼容模型名保留原语法；历史局部编辑顺序不作为所有任务的强制流程。[不可变原文](https://github.com/Wilder1222/image-prompt-skill/blob/c8561d11115bc05c5e3e3c530cbc9320ecf8f857/docs/v0.7.7-design.md)及[译文来源](历史报告译文来源.json)可追溯。


## 版本定位

**版本：** `image-prompt-skill v0.7.7`\
**主题：** `人物生命感v3.1：从精致计算机渲染资产到摄影人物资产`

### 核心目标

v0.7.7 不再修改已经通过的 P9时装身材比例、参考忠实度、补全预算、设计密度、手脚完整性 等稳定模块，而是专门解决当前银发角色测试中最明确的短板：

> **人物资产已经稳定，但面部、眼睛、皮肤、头发和成像仍然更像“高级计算机生成角色渲染”，而不是真人模特白底造型展示册。**

本版本只提升：

1. 眼部光学真实性
2. 年轻皮肤区域光学差异
3. 面部软组织存在感
4. 妆容与真实皮肤融合度
5. 头发频率层级与随机性
6. 摄影镜头的焦点、锐度与高光衰减
7. 整张图不同模块的真实度一致性

# 3. 眼部光学真实感v2

## 内部控制项

```yaml
eye_optics_v2:
  sclera_tone: natural_off_white
  iris_uniformity: low
  iris_radial_variation: subtle
  corneal_highlight: studio_consistent
  eyelid_wrap: high
  lower_lid_volume: subtle
  tear_duct_visibility: subtle
  lash_root_integration: natural
  eye_white_contrast: restrained
  cg_glassiness: minimize
```

## 编译规则

必须表达：

- 眼白自然象牙白/暖灰白，而不是纯白发光
- 虹膜存在细微非均匀纹理
- 上下眼睑真实包裹眼球
- 下眼睑有轻微体积
- 睫毛从真实根部生长
- 高光只来自当前棚拍光源

禁止：

- 水晶眼睛
- 发光眼睛
- 宝石般虹膜
- 过度清晰的眼睛
- 完全对称的双眼

## 新增失败标识

```text
sclera_too_clean
iris_too_uniform
iris_too_glassy
catchlight_mismatch
eyelid_wrap_too_weak
lower_lid_volume_missing
lashline_too_graphic
eye_contrast_too_high
```

# 4. 年轻肌肤分区光学v2

## 核心理念

真人感不是“增加粗糙度”，而是：

> **皮肤整体仍年轻、细腻、干净，但不同区域具有不同反射、散射和纹理强度。**

## 区域模型

```yaml
skin_regions:
  forehead:
    texture: very_fine
    specular: low
    scatter: medium
  nose_bridge:
    texture: fine
    specular: medium
    scatter: low
  nose_tip:
    texture: fine
    specular: medium_high
    scatter: low
  nose_wing:
    texture: fine_visible
    specular: medium
    scatter: medium
  inner_cheek:
    texture: fine_visible
    specular: low
    scatter: high
  outer_cheek:
    texture: very_fine
    specular: low
    scatter: high
  eye_area:
    texture: delicate
    specular: low
    scatter: medium
    tone_variation: subtle
  chin:
    texture: fine
    specular: low
    scatter: medium
  lips:
    material: separate
    micro_lines: subtle
```

## 禁止

```text
全脸明显毛孔
大量雀斑
粗糙皮肤
明显痤疮
老化纹理
```

## 新增失败标识

```text
skin_too_uniform
face_material_too_uniform
nasal_side_texture_missing
cheek_scatter_too_flat
forehead_specular_too_strong
skin_waxy_surface
skin_texture_overdone
```

# 9. 真实感一致性评分

## 八通道

```text
eyes
skin
soft_tissue
makeup
hair
costume_material
lighting
camera_response
```

## 核心原则

任何单一模块“过度真人化”或“明显计算机渲染化”都会产生不协调。

例如：

```text
眼睛 = 计算机渲染
皮肤 = 摄影真实感
```

应输出：

```text
realism_mismatch_eye_skin
```

14. H2.7-A 不得修改 P9
