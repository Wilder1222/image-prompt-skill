# v0.8.0 Real-Test Diagnosis — Images 1–4

## Images 1 and 2 — silver character

Face Mode routing is broadly successful. `beauty_first` better preserves youthful ethereal appeal; stronger facial realism offers little benefit for this character and can slightly reduce beauty/age impression.

Conclusion: silver ethereal character should remain `beauty_first` unless the user explicitly asks for stronger photographic face realism.

## Image 3 — black/red/gold generated result

The character and costume are polished, but the output is routed as a clean white-background asset:

- blank white studio
- catalog-like lighting
- overly literal costume rendering
- static/posed presentation
- uniform sharpness
- weak atmospheric depth

This is not primarily a Face Mode failure. It is a Render/Style Intent failure.

## Image 4 — desired target style

The desired qualities are:

- painterly-cinematic oriental fantasy medium
- large sweeping hair/fabric arcs
- asymmetric dynamic composition
- luminous warm rim/backlight
- deep soft shadow masses
- atmospheric haze and mythic spatial depth
- selective rather than uniform detail
- ivory / black / antique-gold mass structure with restrained crimson
- expressive brush-like peripheral edges

## Root cause

The previous pipeline let the Asset Master presentation leak into the final render. The white-background asset inherited too much authority over final presentation, while the style target did not own render mode, environment, motion or medium strongly enough.

## v0.8.0 correction

- Explicit style target now resolves Render Mode before archetype defaults.
- Image 4 becomes Style Target.
- Full-body character asset becomes Asset Master.
- Final mode becomes `cinematic_hybrid` unless white background is explicitly requested.
- Style Target owns painterly medium/motion/light/atmosphere/composition.
- Asset Master keeps identity/costume architecture.
- Dynamic pose is authorized when required by the target style and not explicitly locked.
- Default face treatment for this painterly profile is `stylized_beauty`, not automatic `humanized_real`.
