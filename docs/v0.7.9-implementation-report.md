# image-prompt-skill v0.7.9 Implementation Report

## Theme

**Face Mode Router — Beauty-First / Humanized-Real / Stylized-Beauty**

## Why this version exists

Recent visual A/B tests showed that stronger facial photorealism is not universally better. For young ethereal ancient-fantasy characters, increasing eye-socket depth, facial-plane definition or mature editorial realism can make the character look older and less attractive even when the result is technically more photographic.

v0.7.9 therefore separates three questions that were previously coupled:

1. What facial aesthetic is correct for this character?
2. What visual age should be protected?
3. How much realism belongs on the face versus the rest of the image?

## Implemented modules

### Face Mode Router

Three modes:

- `beauty_first`
- `humanized_real`
- `stylized_beauty`

### Maturity Guard

Profiles:

- `youthful_18_22`
- `young_adult_20_26`
- `none`

The guard suppresses unwanted age drift without forcing childishness.

### Face / Non-Face Realism Split

Face realism and non-face realism are now independent axes. A beauty-first face can remain lightly stylized while hair, hands, body presence, fabrics, footwear and lighting receive high realism.

### Character Archetype Router

Default routing:

- ancient ethereal female → `beauty_first`
- warrior queen → `humanized_real`
- cyber oriental female → `humanized_real`
- stylized poster character → `stylized_beauty`

Explicit user choice overrides automatic routing.

### New repair rounds

- `face_mode_calibration`
- `non_face_realism_refine`

### New diagnostics

- `face_mode_mismatch`
- `beauty_loss_after_realism`
- `age_impression_too_old`
- `face_realism_overdrive`
- `face_realism_undershoot`
- `maturity_guard_breach`
- `non_face_realism_undershoot`
- `face_nonface_realism_coupled`

## CLI

```bash
node scripts/iteration-director.mjs face-mode --mode beauty_first
node scripts/iteration-director.mjs maturity-guard --profile youthful_18_22
node scripts/iteration-director.mjs realism-split --mode beauty_first
node scripts/iteration-director.mjs face-route --archetype ancient_ethereal_female
node scripts/iteration-director.mjs face-mode-plan --archetype ancient_ethereal_female
node scripts/iteration-director.mjs non-face-realism-plan --mode beauty_first
node scripts/iteration-director.mjs face-nonface-plan --archetype ancient_ethereal_female
```
