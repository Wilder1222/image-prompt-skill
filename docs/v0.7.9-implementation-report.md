## 主题

**面容模式路由：美感优先、真人质感与风格化美感。**

## 版本动机

当时的视觉A/B测试表明，更强的面部照片真实感并非总是更好。年轻空灵古风幻想角色若增加眼窝深度、面部转折刻画或成熟时尚大片式真实感，即使技术上更像照片，也可能显老并降低美感。

v0.7.9因此将此前耦合的三个问题分开：

1. 哪种面容审美适合此角色？
2. 应保护哪个视觉年龄？
3. 面部与画面其余部分分别需要多少真实感？

## 已实现模块

### 面容模式路由

三种模式：

- `beauty_first`：美感优先。
- `humanized_real`：真人质感。
- `stylized_beauty`：风格化美感。

### 成熟度保护

方案：

- `youthful_18_22`。
- `young_adult_20_26`。
- `none`。

保护机制抑制非预期年龄漂移，不强求幼态。

### 面部与非面部真实度分离

两者成为独立维度。美感优先面容可以保留轻度风格化，同时让头发、手、身体生命感、衣料、鞋履和灯光采用高真实度。

### 角色类型路由

当时默认：

- 空灵古风女性 → `beauty_first`。
- 女王战将 → `humanized_real`。
- 赛博东方女性 → `humanized_real`。
- 风格化海报角色 → `stylized_beauty`。

用户明确选择优先于自动路由。

### 新修复阶段

- `face_mode_calibration`：面容模式校准。
- `non_face_realism_refine`：非面部真实感精修。

### 新诊断项

- `face_mode_mismatch`：面容模式不匹配。
- `beauty_loss_after_realism`：真实化后美感下降。
- `age_impression_too_old`：年龄观感过老。
- `face_realism_overdrive`：面部真实度过量。
- `face_realism_undershoot`：面部真实度不足。
- `maturity_guard_breach`：成熟度保护失效。
- `non_face_realism_undershoot`：非面部真实度不足。
- `face_nonface_realism_coupled`：面部与非面部真实度耦合。
