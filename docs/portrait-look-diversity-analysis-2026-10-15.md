## 观察与推断分开

- **可见**：两板的后部扎束、发尾、发饰和衣领有区别；额前分缝、中央与侧向细发以及较长鬓发的分布反复相近。只换发髻和辫子并未充分改变脸前框架。
- **可见**：多数格维持相近的凝视、眉睑状态和微张唇，文字中的不同气质标签没有都形成清楚的可见表演差异。第二板多格偏头，不能据此称正脸端正要求已满足。
- **推断**：提示词可能过度共享脸前结构、妆面和表演，或模型沿用了参考中的刘海。原始提示词和执行输入不可得，不能确认具体成因，更不能把它归因于某个模型或参数。
- **设计决定**：将脸前发型、妆容和表演显式拆开设计并横向预检，适配本人而不改变本人五官；正脸、头位和指定发色作为固定要求独立验收。

## 优化方案与本次实施

| 目标 | 实施 |
| --- | --- |
| 分清身份与造型 | 新增多造型路线，保持稳定五官，允许获准改变分缝、刘海与鬓角；清理基底中的旧呈现冲突 |
| 防止只改后脑与发饰 | 按额前分区、刘海、鬓角耳侧、正面轮廓比较作者声明，不把造型名称或地区标签计作结构变化 |
| 让情绪落到表演 | 明确视线、眉部、眼睑和嘴部动作；不同情绪名但同一表演会进入重复诊断 |
| 让妆容与发型适配 | 每套写适配理由和具体妆面；适配不等于削脸、改年龄或借用参考模特身份 |
| 保持用户固定要求 | 所有变体继承基底的身份、正脸、不偏头、身材及媒介要求，共同发色等单列固定呈现条款 |
| 按请求研究流行款 | 路线要求实时检索、分组覆盖、日期与来源范围；本次示例仅作原创方法演练，不声称当前中日韩趋势榜单 |
| 可执行的前置检查 | 新增 `portrait-look-plan.mjs`，投影各套完整正文与关键验收，检查数量、分组及声明重复；不认证实图 |
