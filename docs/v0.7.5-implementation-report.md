## Regression policy

Proportion and human presence are intentionally staged. When both fail, P1P proportion issues are handled before P2H human-presence issues.

## Important limitation

The 8.7–9.0 head-count target is a visual fashion heuristic used by this project. It is not a vendor parameter and the tool does not measure pixels or infer anatomical truth from an image.

The local test suite validates catalog consistency, routing and prompt-planning behavior. It does not prove that a generator will produce a perfect nine-head body or a fully photographic face in every sample.
