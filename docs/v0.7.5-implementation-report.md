## 回归策略

比例与真人感有意分阶段处理。两者都失败时，先处理P1P比例问题，再处理P2H真人感问题。

## 重要限制

8.7–9.0头身目标是本项目的时装视觉经验值，不是厂商参数。工具不测量像素，也不从图片推断解剖真值。

本地测试验证资源一致性、路由及提示词规划，不证明生成器每次都能生成完美九头身或完全摄影式面容。
