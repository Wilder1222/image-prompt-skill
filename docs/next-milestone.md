## 目标与完成定义

用户提供参考图和自然语言描述后，Skill 能理解这次任务、识别参考中的关键特征、做有依据的设计判断，输出专属的中文分类生图提示词；需要测试时，能定位实际偏差并有效修订。操作复杂度由 Skill 承担，用户无需选模板、模式组合或填写内部记录。

下一阶段先验证角色定妆与服装资产这一核心范围：近景扩全身、全身母图保留、适度衣装优化、真人材质与东方幻想原画、局部修复。其他题材的通用能力在独立测试后再扩展。

成熟度以实际输入输出判断：参考理解准确、用户意图落实、人物比例协调、身份与美感兼顾、服装结构与材料可信、修订有效、换一张参考仍能工作。记录首次成功、修订成功、未通过和不可判断的情况；不以模板数量、提示词长度或程序测试数量代替效果。

## 第一批实际工作

1. 对最新三套候选采用同一评审标准复核，明确必须修复与证据不足项；保留原始结论。
2. 对青黛花卉、黑金幻想分别写出一个主要失败假设，修订对应提示词，再从规定输入生成对照。每套最多两轮针对性修订；无改善时停止并保留候选。
3. 将有效修改沉淀为“何时适用、如何判断、如何描述、如何检查”的规则。比例修正不能自动传播到现代自然比例或已有全身母图。
4. 将现代款作为防止古风默认串入的对照；检查材质与人体关系是否因新规则退步。

该批完成标准：当前关键缺陷有明确结论；至少能指出哪些修改改善了哪些可见问题；尚不确定的身份和遮挡项不伪装成通过。若核心问题未改善，继续修正理解或生成策略，不启动大批量复制。

## 第二批稳定性验证设计

完成第一批后，使用用户最近一组七张原参考做固定范围的回归：银白近景、复杂青金幻想、抱兔古装、青橙古装、黑金人物、青金花卉、舞蹈古装。它们属于已知回归材料，不声称是从未见过的新样本。

- 每张固定实际参考、中文提示词、媒介目标和验收标准，各生成两次，共 14 次初始输出；本轮已执行，修订另计。旧露鞋条件的中断队列不计入这 14 张。
- 真人材质与厚涂原画各自确定目标；改变媒介就是新条件，不能混在同一成功率中。
- 用开发样本完善规则，剩余样本用于本轮未参与调参的检验。后续再增加新的、未参与规则编写的参考，验证向新输入迁移。
- 另在新任务中重新调用同一 Skill 处理少量相同输入，检查“提示词编写过程的稳定性”；这与固定提示词重复生图的随机波动分开记录。
- 不为复现假造模型和种子；保持工具可控条件相同，记录不可控因素。两次重复只提供初步证据，不足以给出普遍可靠性承诺。

统计口径：

| 指标 | 定义 |
| --- | --- |
| 首次满足率 | 未修订输出中，全部关键项被评审通过的数量 / 全部完成的初始输出；同时列出分子分母 |
| 修订后满足率 | 在规定最多两轮修订内，达到同一目标的任务数 / 全部完成的初始任务；保留未修订即成功的任务 |
| 关键缺陷分布 | 分别统计身份偏离、明显比例失衡、服装漂移、媒介错误、裁切、背景和手脚问题 |
| 修订代价与退步 | 每项任务调用次数，以及修复一个问题后破坏已通过维度的次数 |
| 不确定与用户接受 | 单独报告证据不足、观察者通过、用户明确接受；未知不计成功，用户未回复不等于拒绝或接受 |

工具调用失败单独报告并计入执行代价，不能悄悄删除重试记录。评价标杆和服装生成参考分开统计。经修订图、重复文件和历史复用图不能算成新的初始成功样本。

## 下一里程碑交付标准

- 仅提供图和自然语言即可启动；所有最终提示词有中文语义标签，参考与正文一致。
- 对观察准确性和设计连续性有逐项视觉证据，不只通过字段检查。
- 当前两套古风问题完成针对性验证，并保留未解决项与适用边界。
- 固定测试集有完整结果账本和重复输出；新规则相对旧基线的优势与退步可查。
- 严重比例、身份、服装和取景错误不能被交付流程标为合格；重要不确定项明确展示。
- 插件在新任务中独立运行通过，历史规则不会覆盖用户最新目标。

下一里程碑达到上述标准，可称为“有实测依据的角色提示词生产 Skill”。是否达到稳定生产水平，继续由新参考、重复实测和用户实际接受情况验证。

当前安排以角色核心效果为先。模型专属适配、更多题材、图形界面及自动大批量执行，待核心流程在上述范围验证后再排期。
