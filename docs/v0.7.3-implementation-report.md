# image-prompt-skill v0.7.3 Implementation Report

## 版本主题

**Reference Fidelity & Human Presence Control**

v0.7.3 在 v0.7.2 的 Style Restoration / Reality Merge 之上，进一步解决单参考扩全身时的“参考越权”和“真人感仍偏CG”问题。

## 已实现

### Reference Control
- Reference Channel Decomposition：Identity / Costume / Material / Pose / Style / Lighting / Environment
- Reference Fidelity Matrix：0 ignore / 1 weak / 2 strong / 3 strict
- 单参考图预设：asset / style_asset / restoration / 银发案例 / 赛博案例

### Completion Control
- C0–C3 Completion Levels
- C1 Conservative Completion 作为角色资产默认
- 不可见区域只作为 designed extension

### Complexity Control
- Design Density Preservation
- Wear State W0–W4
- 扩图不自动增加装饰、机械、刺绣、破损等级

### Human Presence
- H0–H3 Human Presence
- H2 默认：soft tissue / regional skin / subtle asymmetry / camera response
- Camera Realism 独立规则

### Render Mode
新增 `style_asset`：白底/中性背景仍保留参考的材质、色彩、人物气质和适量灯光语言，不复制原环境。

### Iterative Director
新增命令：
- `fidelity-plan`
- `completion-level`
- `human-presence`
- `density-plan`
- `style-asset-plan`

新增 Repair Rounds：
