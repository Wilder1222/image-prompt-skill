## 版本主题

**参考忠实度与人物生命感控制**

v0.7.3 在 v0.7.2 风格恢复与真实感融合的基础上，进一步处理单参考扩全身时的参考越权，以及真人感仍偏计算机渲染的问题。

## 当时已实现

### 参考控制
- 参考通道拆分：身份、服装、材质、姿态、风格、光线、环境。
- 参考忠实度矩阵：0 忽略、1 弱、2 强、3 严格。
- 单参考预设：`asset`（资产）、`style_asset`（风格资产）、`restoration`（恢复）、银发案例与赛博案例。

### 补全控制
- C0–C3 补全等级。
- 当时以 C1 保守补全作为角色资产默认。
- 不可见区域只作为设计延展。

### 复杂度控制
- 保持设计密度。
- 磨损状态 W0–W4。
- 扩图不自动增加装饰、机械、刺绣或破损等级。

### 人物生命感
- H0–H3 人物生命感。
- 当时 H2 默认包含软组织、分区肤质、轻微不对称与相机响应。
- 将摄影真实感列为独立规则。

### 渲染模式
新增 `style_asset`：白底或中性背景仍保留参考的材质、色彩、人物气质和适量灯光语言，不复制原环境。

### 迭代指挥工具
新增命令：
- `fidelity-plan`
- `completion-level`
- `human-presence`
- `density-plan`
- `style-asset-plan`

新增修复轮次标识：
- `reference_fidelity`：参考忠实度。
- `completion_guard`：补全边界。
- `human_presence`：人物生命感。

新增失败标识：
- `reference_channel_leak`：参考通道越权。
- `reference_fidelity_conflict`：参考忠实度冲突。
- `completion_overdesign`：补全过程过度设计。
- `design_density_inflation`：设计密度膨胀。
- `wear_state_inflation`：磨损程度膨胀。
- `human_presence_undershoot`：人物生命感不足。
- `camera_cg_render`：相机表现仍像计算机渲染。
- `uniform_skin_response`：皮肤响应过于均一。
- `symmetry_rendered`：对称表现显得僵硬。
- `style_asset_environment_leak`：风格资产混入原环境。
