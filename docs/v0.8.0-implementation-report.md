# image-prompt-skill v0.8.0 Implementation Report

## Theme

Style Intent & Reference Authority

## Implemented

- Style Intent Router with four intent classes
- `cinematic_hybrid` render mode
- `oriental_epic_painterly` and `clean_asset_studio` style profiles
- Reference Authority Matrix
- Style Preservation Guard
- Style / Face Compatibility
- explicit background-vs-style resolution
- style-intent and style-target diagnostic routing
- two new repair rounds: `style_intent_alignment`, `style_target_restoration`
- provider adaptation notes for OpenAI, Gemini, Seedream, FLUX and Midjourney
- black/red/gold → Image 4 style validation example

## Real-test conclusion

The silver test confirms Face Mode remains useful. The black/red/gold test confirms Face Mode alone is insufficient: final-output style needs an independent authority layer.

## Compatibility

All previous v0.7.x tests remain green. Legacy `render_modes` validation remains backward-compatible while v0.8.0 exposes `render_modes_total` for the new fifth mode.

## Important boundary

Style profile names, authority levels and intent routing are project heuristics, not native parameters of image providers.
