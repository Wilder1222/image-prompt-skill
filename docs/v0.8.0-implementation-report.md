## 主题

风格意图与参考权限。

## 已实现

- 四类意图的风格意图路由。
- `cinematic_hybrid` 渲染模式。
- `oriental_epic_painterly` 与 `clean_asset_studio` 风格方案。
- 参考权限矩阵。
- 风格保持约束。
- 风格与面容兼容处理。
- 明确的背景与风格冲突解析。
- 风格意图和风格目标诊断路由。
- 两个新修复阶段：`style_intent_alignment`、`style_target_restoration`。
- OpenAI、Gemini、Seedream、FLUX及Midjourney适配说明。
- 黑红金角色向图4风格转化的验证示例。

## 当时的实测结论

银发测试表明面容模式仍有用。黑红金测试表明仅靠面容模式不足，最终输出风格需要独立参考权限层。

## 兼容性

此前v0.7.x测试当时全部通过。旧 `render_modes` 校验保持向后兼容，v0.8.0另提供 `render_modes_total` 表示新的第五种模式。

## 重要边界

风格方案名、权限级别与意图路由都是项目经验规则，不是图像厂商原生参数。
