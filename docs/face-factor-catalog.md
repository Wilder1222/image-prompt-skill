# 人物面容完整因素目录

由 `node scripts/build-face-factor-docs.mjs` 从权威JSON生成；不要手改下列派生列表。版本2.0.0，15组、205项。

本项目自建定性因素模型，参考游戏工作流而不复制游戏精确滑杆或编码；只选择本轮有效的参数，不自动填满。稳定结构139项、软组织12项、个体表面18项、当前表情12项、呈现条件24项。

[选择与观察规则](../references/core/face-factor-system.md) · [官方调研与版本范围](game-face-system-research-2026-10-11.md) · [原始目录](../resources/face_design_catalog.json)

`catalog`可查看全量定义；`catalog --group philtrum`只查询人中组。中文候选值只是可调起点，开放的value仍由当前人物与观察决定，没有通用默认数值。
