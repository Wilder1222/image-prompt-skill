# v0.7历史实施报告

本文件为历史报告中文整理，原有“当前”和分轮建议只对应当时案例，不是所有任务的默认。未新增图像或重新验证当时结论。[不可变原文](https://github.com/Wilder1222/image-prompt-skill/blob/861084f7e612f7e69ab1b9ea07df7cc6753569dc/docs/v0.7-implementation-report.md)与[译文来源](历史报告译文来源.json)可追溯。

## 版本目标

把image-prompt-skill从生成完整提示词升级为管理图像从生成到定稿的多轮迭代。

## 当时新增能力

- 参考职责解析。
- 可见与推断内容识别。
- 编辑范围约束。
- 优先级编译器v2。
- 分区皮肤光学。
- 材料对比协议。
- 受控不完美。
- 迭代修复路线。
- 分辨率与放大规则。
- 三轮资产精修模板。

## 核心思想

生成 → 诊断 → 锁定 → 修订 → 锁定 → 精修 → 放大。

随着图像逐步成立，提示词应越来越短，编辑范围越来越小。这是原报告的迭代方向，不表示仅缩短文本就能保证效果。

## 当时角色资产建议

- 全身图作为V1资产母图。
- 原始半身肖像作为面容身份参考。
- 第一轮处理脸、肌肤和发丝。
- 第二轮处理服装材料、刺绣和重力。
- 第三轮处理棚光、白底分离和摄影完成度。
- 最后进行真实像素放大。

## 边界

本地脚本不会识图。可见或推断状态及失败标识由宿主视觉模型或人工依据真实图像先判断；工具只验证职责、锁定范围并建议下一轮。
