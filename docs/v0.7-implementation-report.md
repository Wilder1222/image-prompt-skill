# v0.7 实施报告

## 版本目标

把 image-prompt-skill 从“生成完整 Prompt”升级为“管理一次图像从生成到定稿的多轮迭代”。

## 新增能力

- Reference Role Resolver
- Visible / Inferred Detector
- Edit Scope Guard
- Priority Compiler v2
- Regional Skin Optics
- Material Contrast Protocol
- Controlled Imperfection
- Iterative Repair Route
- Resolution / Upscale Policy
- 三轮资产精修模板

## 核心思想

> Generate → Diagnose → Lock → Patch → Lock → Polish → Upscale

随着图像逐步成立，提示词应越来越短，编辑范围越来越小。

## 当前角色资产建议

- 当前全身图：V1 Asset Master
- 原始半身肖像：Face Identity Reference
- Round 1：脸 / 肌肤 / 发丝
- Round 2：服装材质 / 刺绣 / 重力
- Round 3：棚拍光 / 白底分离 / 摄影完成度
- Final：真实像素放大

## 边界

本地脚本不会识图。Visible / Inferred 状态与 failure code 由宿主视觉模型或人工根据真实图片先判断，工具只负责验证职责、锁定范围和推荐下一轮。
