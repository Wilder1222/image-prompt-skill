# 同人多造型实际执行与本轮优化

证据来自本聊天2026-10-15的内置图像工具请求、实际输出及非盲人工复核。一次调用产生一张独立肖像；18次调用保留18个不同输出，选定日韩5张、中国5张浏览候选。各次均直接输入同一用户原图；模型、种子和费用未知。原图及图片保存在本地，不随插件发布。摘要与选定版本见[证据记录](portrait-look-execution-2026-10-15.json)。

## 实际观察与不能推出的结论

主发型、开怀笑、闭唇、忍怒和含泪已有可见区别；薄平与姬发式刘海仍部分压眉，多套浅妆沿用相近的粉颊和润粉唇，惊喜、释然与单侧俏皮动作偏弱。仅有文字查重通过不能证明这些部位已经分化。

改写重点段落后，`jk02-v3`退回原图的双辫，保留`jk02-v2`卷发候选。`jk05-v3`修正闭唇时回到古装，`jk05-v4`恢复现代衬衫。`cn01-v3`减少长颊前碎发；`cn03-v3`修复高马尾顶部裁切。这些是已观察的结果，不能单独归因于某句强调、提示词长度或模型能力上限。

十张选定图按当次冻结标准为9张`needs_revision`、1张`needs_review`，完整通过0；没有用户接受记录或用户分数。第三组下脸轮廓仍有身份疑问。衣下肌肉量与画外身体不可判断，不能用胸像补足全身证据。选择便于浏览的候选不撤销这些失败和不确定。

## 已实施的优化

| 执行问题 | 当前改动及检验范围 |
| --- | --- |
| 原身份图的妆发与甜笑被过度继承 | 多造型路线明确保留身份维度、替换获准呈现维度；补入身份图后撤掉旧原创面容和年龄假设 |
| “薄刘海”仍被画成长细丝 | 明确厚度、主发片边界、相对眉毛的发梢落点，分别验刘海结构与自然细发 |
| 修表情时丢回原发型，修嘴时回退衣装 | `revisePortraitLookPlan`从当前完整方案更新指定通道；`focus_channels`移动原栏目而不叠加第二份摘要，其他造型与基底保持原样 |
| 单张失败被浏览候选名称掩盖 | 新增成组复核器，回验快照、实际输出摘要及原逐项回执；有关键失败或不确定的图片不能标为成品 |
| 文字声明和主轮廓变化代替全部实图差异 | 将选定版本的人工两两比较独立绑定到图片；缺失、相近和不确定不计作完整差异验证 |
| 提示词改写后丢失失败计数 | 用稳定问题键关联连续父版本和冻结检查项；两轮未变或退步返回停止当前路线，目标摘要变化不清零 |

规则的唯一维护位置为[多造型路线](../references/routes/portrait-look-variation.md)，不将十套配额、人物五官、具体妆色或本次高马尾款式设为其他任务的共同默认。规则不新增模型、遮罩、参考强度或自动人脸识别能力。
