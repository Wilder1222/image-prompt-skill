# 八张比例正例的实际生成核验

本轮按用户提供并认可身材比例的八张图，执行了七次真实图像生成。选定的单人基准、五套换装和正侧背三视图通过代理逐人物视觉评审；这是三张图片、九个全身展示单元，不是九次独立生成，也不是用户已接受新图。全部运行摘要见 [证据索引](body-proportion-validation-2026-10-18.json)，来源图观察见 [八图记录](user-approved-body-references-2026-10-18.json)。原图、成片、正文、冻结快照和完整回执仅保存在本地 `output/body-validation-20261018/`，不随 Git 或插件分发。

## 查到的问题及证据范围

- **“有比例文字”不足以得到目标。** 首轮同时输入身份近景和比例卡，第二轮编辑失败候选，第三轮直接沿用认可短裙全身的关系，仍未充分获得精巧头肩、紧凑上身与整组长腿的平衡。三个实际结果均保留 `needs_revision`，没有用无畸形或姿态改善判通过。
- **身份保持可能被执行成旧头身保持。** 第四次使用已回查身份的完整候选作单一编辑输入，明确完整头部、躯干、上下腿和手臂共同调整，得到清楚改善。此次同时改变了输入组合、提示表达及相对尺度指引，不能证明某一种语言、单个短语或百分比独立有效，更不能变成所有年龄的固定公式。
- **旧审核单位不能覆盖五人板。** 原工具每个 run 只能选择一个成员；现在增加生成前冻结的 `body_plan.figures`，六区检查与对比绑定 `(run_id, figure_id)`，同图逐人复核。缺人、缺区、冲突回执、遮挡未决不再被整图通过覆盖。
- **安装包可能落后于工作区。** 本轮更新前，已启用的个人插件仍标 0.17.2，安装源与缓存缺少工作区已有的身体契约及组审核脚本。版本字符串相同不能证明字节相同。此本地事实不证明用户分享的 ChatGPT 运行用了该缓存；共享对话没有提供完整原始工具请求与冻结记录，不能倒推其唯一失败原因。

另有 baseline-v2 在派发前发现图号引用不匹配，记录为 `interrupted / not_started`，未调用图像生成，不计入七次生成。所有数字式编辑方向仅作当张设计指引，没有被认证为准确执行的量测值。

最终组审核覆盖五套换装和三个视图，共 48 项分区观察及 48 项对共同基准的比较；基准自身另有六区检查。程序验证照片摘要、冻结目标、实际基准输入、身份来源连续性和逐人物覆盖。身体描述与判定由代理实际看图完成，程序不自动识别人体、测量头身或判断美感。

## 落入当前规则

新全身生产声明位置与视角，共享身体目标、逐人验收；近景不扩大范围。身体校准先达到目标，再派生换装及转面。已经核验身份的候选可承担编辑输入，但每次还要回查身份与保护项。联动编辑允许完整头部相对身体调整，保护的是面部内部结构；不会把完整躯干误写成旧躯干长度不可变。

服装松量、发髻、鞋跟、轻姿态与投影分别判断。长裤和裙下只认证可见轮廓与穿着支撑，不从袜口、裙摆或裤褶伪造骨点。自然遮挡允许存在；当它挡住当前已冻结的必要检查时，保留未决，本轮仅在授权范围内调整手臂完成核验。

当前结论仅覆盖这一人物、五套现代衣装与三个展示视图。没有准确黄金分割或头身数字认证，没有其他年龄、指定体型或供应商的稳定性结论。后续新图继续使用同样的实际出图与逐人检查，不能凭本轮通过免检。
