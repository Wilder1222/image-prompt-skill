# v0.8.4 定妆照优化计划

## 目标与证据

用户提供的两张既有全身成图是本次审美标杆：青金织锦与银白灰紫。它们分别保留自己的脸、发色、配色和服装；不能把两张合成一套通用人物模板。实际文件、最终提示词和生成回执保存在本次 `dist/visual-tests` 测试目录。

上一轮青金提示词明确写了「自然垂手」「简洁束带」「内裙少量露出」「不增加大面积披纱」「无长拖尾」。这会主动压低服装展示的空间与层次。旧资源中的「控制裙宽」「鞋履完全可见」又容易把长裙处理成直筒。现有证据足以说明提示词目标与用户偏好不一致；不能凭这一次对比断言模型、种子或参数是唯一原因。

用户标杆的可见优势：

1. 双手在腰前自然叠放，袖布随手臂形成下垂弧线，脸、腰、手构成明确的视觉中心。
2. 完整躯干、清楚腰线与前中长衣片形成修长感；裙摆逐渐展开，轻微铺地，鞋尖交代落地。
3. 主锦、薄纱、内裙与结构边缘的厚薄不同。局部密集花纹与安静的浅色内裙相互衬托。
4. 脸保持柔和、精致的角色感；没有为了真人感加重年龄、凹陷或粗糙皮肤。

## 执行顺序

| 工作 | 改动 | 验收证据 |
| --- | --- | --- |
| 分离展示目标 | 增加可选 `costume_showcase`；保留兼容的 `neutral_asset` | CLI 可选择，显式手势优先，局部修复不重排姿态 |
| 保住优质全身图 | 增加 `full_body_anchor` 编译分支与标杆参考权限说明 | 不混入扩身、年龄、九头身和默认手势；冲突覆盖明确报错 |
| 改善提示词落地 | 具体写出本套衣服的腰、中央内裙、衣片、袖布与材质关系 | 生成文本与输入图对应；新增下半身标记为设计延展 |
| 真实出图 | 原半身参考重做；青金全身标杆引导；银紫全身保留 | 各自保存输入、输出、完整提示词、已知/未知参数和目视问题 |
| 项目回归 | 同步入口、工作流、示例、行为测试、发布清单和压缩包 | 测试与发布验证通过；不把代码通过等同于审美通过 |

## 对比与停止规则

- 原半身重做仍只用上一轮的原照片 8，检验新的构造描述是否有用；这不是固定种子的严格对照。
- 使用全身标杆的结果单独标为「全身参考约束测试」，不能拿它证明纯文字改动的效果。
- 检查脸的方向与辨识度、颈肩腰的连贯性、袖摆轮廓、长衣片、厚薄关系、可见手部与落地；被遮挡的结构不强行判定。
- 两张优质原图继续作为用户偏好的候选母图，生成候选不能自动替换它们。若新图不及原图，记录退步并保留原图，不靠多加形容词宣告成功。
- 只对具体可见问题做一次有范围的修正；一轮样本不能证明批量稳定性。
