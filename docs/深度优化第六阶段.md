# 深度优化第六阶段：资源正文与历史笔记

本阶段处理 21 份资源正文、两份历史研究笔记，并修复命令输出丢失适用范围说明的问题。没有新增图像调用，不改变历史评分。累计十六次真实出图均分仍为 **9.16875**，完整第二轮六案均分仍为 **9.2167**；9.5 分目标未达到。

## 实际改动

- 真人感、面部模式、风格兼容、细节、高光、原画边缘、摄影焦点与白衣材质等资源正文改为中文；字段和兼容标识保留。
- 微小不对称改为保持实际已有差异，不主动挪动眉眼或嘴角；肤质表现以精致妆容与当前景别为基础。
- 旧年龄、P9、宏大场景和轮次方案明确属于案例；不会仅因摄影化或原画标签授权换脸、增龄、换装或新增物件。
- 白衣摄影补光由旧的较弱补光改为充分正面柔和补光，与面部清楚、均匀且有体积的要求一致。
- 风格资产的背景和动作按当前任务决定，不能从旧目录自动继承白底、固定站姿或宏大环境。
- 面部模式、风格、细节、高光、背景、边缘和焦点查询输出现在携带其资源适用范围；嵌套计划也能看到这些限制，不只在源文件中注释。

两份研究笔记采用中文整理，记录原提交和文件 SHA-256，并链接到保留的原文。原核对日期、案例状态、项目推论与当前适用边界分开说明，不把历史厂商额度或旧案例通过状态冒充当前证据。本阶段没有重新核验这些笔记中的全部外部研究。

## 检查结果

相关资源与命令回归共 **297 项测试通过**。测试包括嵌套计划保留旧年龄适用范围、白衣摄影补光和不新增衣层；原有中文化相关断言改用对应中文语义，其他结构和路由检查保留。程序检查不计入图像分数。

当前扫描为 **127 文件、1822 条英文候选**。知识目录与资源目录均未检出英文长段落候选；这不等于已证明所有短语都中文化。剩余主要为历史实际提示词、旧计划快照和其他研究说明，逐项列表见 [中文化核对进度](中文化核对进度.json)。
