# v0.12.0：站姿、真实执行记录与独立调用验证

日期：2026-09-29。实施依据为 [下一阶段计划](../next-milestone.md)。本轮完善了生产工作流，并完成有限实测；尚未证明任意参考都能一次生成合格资产。所有测试使用宿主内置 image_gen，实际模型与种子未提供，保持未知。

## 本轮规则变化

- 参考观察 → 设计判断 → 中文语义标签 → 语义复核 → 实图评审 → 限定范围修订。标签是组织和修改单位，不是固定人物模板。
- 常用站姿按用途、身体/头部方向、重心、腿脚关系、手势及衣摆联合设定。支持并立、错步、丁字步、重心偏移、轻交叉、开立、允许条件下的转身等；未列举的动作仍按身体关系分析。
- 用户已明确：双脚露出不是必须。完整全身指自然轮廓完整，允许服装遮住一脚或双脚；仅明确要求鞋履展示时才约束其可见范围。生产入口、验收、兼容素材和派生示例均已同步。
- 同人主要身份图与辅助视角分组，服装/风格/评价参考不因此获得身份权限。按标签修改保留其他章节和来源；脚本检查范围，代理检查语义。
- 生成前冻结参考摘要、实际图序、最终中文全文、目标和验收；生成后绑定真实输出。目标更改、中断、派发未知、工具错误和重复图片分列。

## 独立调用和局部修订

独立代理在无本会话上下文的起点，仅读取打包插件与指定参考，完成银白、现代及现代改色三份提示词；另追加三种独立站姿请求。六份正文均经编译且与保存文字一致。改色稿只改变一条衣装颜色语句，其余 12 个章节逐字保留。这是文字范围证据，不能代替图像锁定效果。

追加站姿测试覆盖：正面重心偏移、三分之四回看与轻交叉、改为古风长裙且允许丁字步遮脚。语义复核发现并清理了材质段旧“搭手”描述，说明修改不能只检查构图标签。独立测试发现 `partially_visible` 与生产字段 `partial` 名称不一致，文档已统一说明。

独立现代提示词实际出图后，可见的朝向、交叉步、现代织物和自然成人比例成立。其提示词任务验收中仍含“未生图”等文字状态，升级出图前未迁移，故保留为协议缺陷、不追溯删除关键项制造成功；当前流程已明确文字预检与视觉验收分开。之后的改色测试事前更新目标，成功后也被统计脚本排除出原目标修复数。

## 执行记录的限制与处理

用户指出浅蓝开衫候选“面部有些光影斑驳，白底应该使用摄影灯光”。旧背景检查只判断白底、接地与原场景移除，遗漏了脸部残留的碎发硬阴影。保留旧观察记录，另附用户反馈；新增面部均匀受光与自然体积的关键项，事前冻结新目标后执行一次仅改灯光的编辑。结果中额前条状投影明显减轻，双颊曝光更均匀，鼻下与下颌仍有柔和渐变。人物、站姿、衣装和画幅未见明显变化，但不声称像素级锁定或用户已接受。

该反馈已落实到主入口、专项布光知识、生产流程、视觉验收及中英文兼容素材。旧“较弱补光”和“no_flat_even_light”默认被替换为充分补光与柔和体积并存；厚涂媒介仍保留。新的布光目标更严格，不追溯修改旧成功率。

之后用户允许发型自动适配，并要求大幅减少碎发遮脸。新目标不再锁死每一缕头发，保持发色与总体束发方向，允许分缝、侧发束及固定位置调整。一次编辑后额头和眉眼更完整可读，原眼周和面颊前的长碎发显著减少，保留少量轮廓外细发与自然蓬松。人物、站姿、衣服与摄影柔光未见明显退步；保存独立前后对照，不将该新增目标记为先前目标的修复成功。

早期队列复制脚本误将工具说明中的目录前缀包含进路径；原生成文件仍在，后续已校正复制并核对 SHA-256。十二份最新输出通过工具返回的任务标签恢复对应，另两份标签在工具输出截断时遗漏，结合唯一剩余案例、完成时间和实图核对恢复，已在本地记录注明来源，不冒称完整原始回执。后续三个检查及改色已改为先保存明确返回路径，再检查复制成功。

普通文件哈希用于检测相对于已保存记录的变化，不证明模型确实服从提示词，也不是第三方不可伪造审计。完整原始文件保留本地；公开账本仅保留必要摘要、来源类型与视觉结论，不含用户附件绝对路径。

## 下一步边界

本轮完成规则、记录、固定样本重复验证、局部修改和隔离插件调用。还不能宣称稳定生产：身份保持仍需更可比的参考或明确用户判断；取景要求在复杂造型中需要后续编辑；隐藏脚位不能强行验明；新参考迁移与真实多视角生成仍待新一轮验证。现有测试结果足以支持这些有限规则和具体改进，不支持“仅靠提示词保证每次效果”。
