# v0.9.3 新衣装方向与衣片分配实测

2026-09-29，延续“服装、造型可以适度优化”的授权，新增三张真实生成图：原图 8 的黑金造型两版，以及原图 7 的浅蓝针织短裙一版。每次只将对应原始头像作为图像输入；用户新一组优秀图 4、5 用于观察、编写方案与评审，没有送入生成工具。

这次检验的是同一人物在新衣装方向下的表现，旧衣服和配色不是硬约束。身份与表情仍取自原图，黑金或短裙设计属于明确的再设计，不能描述为半身原图中已存在的下装。

| 输出 | 实际观察 | 决策与限制 |
| --- | --- | --- |
| a-08-black-gold | 黑纱、象牙白袖里、金纹侧片与中心裙面能区分；身体、衣摆和鞋尖在画内；中部整片深色裙面积大，肩饰外展，顶部留白紧 | 保留为造型基线；没有把它评为达到标杆 |
| b-08-layered-black-gold | 改写衣装段后，浅色内层从侧片之间露出，前中深色区域变窄，肩饰更贴合，裙身长线更分明；图中衣摆与鞋尖完整 | 当前黑金候选。发髻仍高、顶部仍紧；中心布料仍有纹理与柔亮反光。不能声称压低发髻或严格哑光要求已成功 |
| a-07-blue-short | 浅蓝针织、碎花内搭、两层浅色短裙、包与兔挂件、袜鞋均可读；保持闭唇微笑和侧垂低马尾，双脚在画内 | 当前现代短裙候选；手指相叠部分、服装遮挡的骨盆不可全面判断；人物相似度和最终审美待用户判断 |

黑金 A 到 B 保持原始图像输入、身份段和取景段不变，改写衣装段中的衣片、肩饰、发饰与裙摆组织。这是组合造型修订，无法将改善归因于某一个短句；同时发髻目标没有达成，不能将整段评为完全遵循。两次都从原始头像重新生成，B 不是 A 的局部编辑，因此局部细节与脸部也可能改变。

工作流据此新增“花纹疏密与衣片分配分开判断”：留白不是要求一整块宽大单色裙面；出现沉重裙面时，按具体设计调整衣片宽度、长短、开合和内层露出位置。现代款作为不同材质与长度的检查样本，没有混入长袍拖尾、金纹或铠甲。
