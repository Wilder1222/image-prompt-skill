# 舞者局部衣片编辑实际提示词

以下为本轮实际执行的两次中文标签提示词。第一次只改上衣遮盖性，第二次只改腰带纹饰；不是供所有角色套用的模板。两次均保留原评分与最终目标，仍有取景关键项未通过。

## 1. 上衣与双袖遮盖性

【编辑任务】
编辑输入的这张舞者照片，只调整象牙白上衣本体、左右两只短袖的面料遮盖性。沿用原先纯文字设定生成的这个成年人物，不另换人，不重新设计舞衣。只输出一张完整照片。

【保持人物与身体】
保持这位约25岁东方成年舞者的同一张脸、回望目光、轻扬嘴角、珊瑚色唇妆与细腻底妆。保持深棕黑低髻、小型哑金簪。保持头颈肩、完整胸腰骨盆、修长上下臂及腿段，保留可见肩臂小腿的自然肌肉和柔和软组织，不瘦身、不拉腿、不缩头；皮肤仍是精致写真妆容下的真实质感。

【本轮材质修复】
将从领口到腰带的整个象牙白上衣、左右肩部和两只短袖统一改成细密哑光弹力丝绸：薄、柔软、有弹性，但是织物本身完全遮盖下面的肤色。上衣与袖子采用相同的紧密织法和象牙白色；胸肩与短袖不呈透明纱，不能隔衣看出皮肤色块、内衣边界或皮下细节。通过袖口的薄折边、腋下细褶和提臂受力体现轻薄，而不靠透视皮肤体现轻薄。保持原领口、斜襟边缘、袖长、合体轮廓与自然腰线，面料仍随举臂拉伸和旋转受力，不能变厚重僵硬。

【保持其余衣装】
腰带、低调金色领腰装饰、两条青色细腰带及下裙保持原形。浅青绿外裙继续是轻透绡纱，象牙内裙继续稍厚不透；保持原裙长、展开范围、层次、转动褶皱和肉粉色舞鞋。仅上衣及短袖改变透光率，不把不透的材质扩散到下裙，不增加饰物或道具。

【保持动作与摄影】
保持旋转将停的瞬间：画面左侧前掌承重，另一腿向侧后伸展且鞋尖触地；抬起的手臂弧线、侧伸手臂、手指分组、头部转向和裙摆惯性完全沿用。保持3:4画幅、当前人物位置与大小、全身动作轮廓、浅暖灰无缝棚景、地面接触影和柔和摄影灯光。本轮不移动相机、不裁切、不缩放人物；原最终目标中的上下约6%留白仍需独立验收，不通过改动身体比例来凑边距。无字、无水印。


## 2. 腰带纹饰简化

【编辑任务】
编辑输入的这一张舞者照片，本轮唯一改动是腰带的金色纹饰分布。保持原成年人物、身体、妆容、舞衣剪裁和摄影画面。只输出一张完整照片。

【保持人物与身体】
保持这位约25岁东方成年舞者的同一张脸、回望目光、轻扬嘴角、珊瑚色唇妆与细腻底妆。保持深棕黑低髻、小型哑金簪。保持头颈肩、完整胸腰骨盆、修长上下臂及腿段，保留可见肩臂小腿的自然肌肉和柔和软组织，不瘦身、不拉腿、不缩头；皮肤仍是精致写真妆容下的真实质感。

【本轮腰带纹饰修复】
只在浅青绿色腰带范围内编辑：去掉腰带中央成片的金色花朵和枝蔓，让腰带中部恢复为原浅青绿色织物；沿腰带上缘和下缘各保留一根细而低调的金线。保持腰带原来的宽度、高度、缠绕角度、褶皱、固定位置及两条青色细飘带。领口原有细金边保持，不添加新配饰，不把腰带改为金属腰封，不削细腰部。

【保持其余衣装】
保持已经修好的象牙白斜襟上衣和左右短袖：细密哑光弹力丝绸、薄而柔软、织物遮盖下面肤色，肩袖受力褶皱清楚。浅青绿外裙继续轻透，象牙内裙继续稍厚不透；原裙长、展开范围、纱边、转动褶皱、肉粉色舞鞋保持。仅减少腰带中部金纹，不改其他衣片的颜色、透明度或形状。

【保持动作与摄影】
保持旋转将停的瞬间：画面左侧前掌承重，另一腿向侧后伸展且鞋尖触地；抬起的手臂弧线、侧伸手臂、手指分组、头部转向和裙摆惯性完全沿用。保持3:4画幅、当前人物位置与大小、全身动作轮廓、浅暖灰无缝棚景、地面接触影和柔和摄影灯光。本轮不移动相机、不裁切、不缩放人物；原最终目标中的上下约6%留白仍需独立验收，不通过改动身体比例来凑边距。无字、无水印。
