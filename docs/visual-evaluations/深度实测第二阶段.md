## 得到的改进依据

1. 取景偏满在有参考、无参考、静态和动态案例中均出现。将“上下约 6% 留白”放在长提示词末尾尚不能可靠控制构图；这不是仅由近景参考裁切造成的问题。下一次在相同验收目标下试验将取景要求前置并具体描述主体边界与环境空间；若仍无改善，转为独立局部扩画实验，保留生成失败。
2. 真人转换应单独检查面部表现。青橙图的衣料和场景较接近摄影，但面容仍有原画平整感；材质通过不能推定面容转换通过。下一次只加强同一身份的真人妆面、眼睑体积和光学呈现，不重新设计五官。
3. “动作生动”与“指定动作正确”不同。舞者与时装人物都自然好看，但脚部接触和手势被替换。下一次把受力脚、接触点和手与衣服的关系放进同一动作句，删除可能触发另一动作的表述；保留现有目标，不事后把悬空或插袋改成通过。
4. 资源库仍有与主入口冲突的旧文本。本阶段中文化人体比例、比例保持、身体生命感、手足、眼睛、头发、妆肤、皮肤光学、软组织和棚光共十份资源，同时修正强制露鞋、五指全露、全动作接地、统一棚灯眼神光和缩头捷径。接口标识保持兼容，明确要求英文时的兼容输出由脚本处理。

上述是本次观察与待验证假设，不宣称已经形成稳定通用规律。没有把八次主代理评分当成独立评委或用户验收。
