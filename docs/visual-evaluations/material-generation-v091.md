R1 与 R0 使用完全相同的原图、补全说明和编译选项。图像工具没有公开种子，所以这不是严格的固定噪声因果实验；记录的是可见样本差异。H1 是不同服装下的方向检查，不是与 R0 的严格 A/B。R2 保留在证据中，未选最好看的图来假称所有规则有效。

相对两张用户标杆，青金候选仍较宽重、发髻相对显大，白衣候选的层次节奏仍较单一。标杆的银发、金肩饰、额饰、丁香灰配色属于另一个完整造型，不能为追求相似构图而移植到原图 2。仅凭材质改善不能声称已达到标杆品质。

## 写回 skill 的变化

用户追加造型优化授权后，新增 `--design-freedom moderate`。此模式释放服装构造、配色比例、袖腰与饰物的硬锁，保留人物辨识度和表观年龄；与保留式全身母图和局部编辑隔离。适度再设计不是只给旧衣服增加纹理。

追加的 D1 三张是真实造型设计测试，不是旧补全方案下的单变量 A/B：蓝白款出现雾蓝腰封、侧衣片、白花枝与流苏，层次更接近新标杆；现代款改成长裙与柔和低位合手，闭唇微笑恢复；青金铠甲完成甲靴和完整裙片，但要求两条龙却出现四个龙首，并且翼尖被裁切。以上候选均未获得用户最终验收。

- 生成允许参考中可见的材料与补全说明明确授权的衣层；局部编辑继续禁止新增衣层。
- 明确素面范围包括同色提花，纹样只属于指定衣片；各层通过褶皱尺度、织物重量、透叠和光泽区分。
- 不把主衣统一替换成厚锦缎；保留粗布、棉布和针织等原材料。
- 当前生成示例移到不带历史版本号的文件；v0.8.4 示例和计划保留为历史快照。
- 新增生成与编辑隔离、全身母图隔离及材质字段缺失的回归检查。
