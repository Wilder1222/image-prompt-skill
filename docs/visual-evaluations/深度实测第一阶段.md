## 本轮提示词优化结论

1. 妆容优先与材料分区在首批图中有可见支持：面部干净，织锦、纱层或针织有区别，但不能由两案推断其他媒介与角色同样有效。
2. 只把“相机后退、占画高约 88%”加入白底全身正文，未修复贴边构图。该假设在当前两张中未获支持，不推广为有效规则。下一步单独测试取景编辑，保留原始失败。
3. 具体说明承重脚、后脚阶段和空手手势，第二轮未再出现挎包；步态仍有细微偏差。可将具体动作阶段作为候选方法，需在舞者等新案例验证。
4. 评审不精确测量裙下腿部或裤下肌肉；它们仍按可见轮廓与整体结构判断，不能写成黄金比例已被数学证明。
