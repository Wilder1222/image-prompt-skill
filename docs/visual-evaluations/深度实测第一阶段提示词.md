# 深度实测第一阶段提示词

## 01-floral-r1

【任务与参考】
以唯一参考图中的年轻成年女性为人物与衣装来源，制作一张3:4竖幅的正面全身白底定妆照，单人。保留人物辨识点，半身未见的衣服下部按可见设计自然延展。

【表现方向】
精致古风写真摄影，人物好看、真实、有生命力；九头身时装观感，真实高级织物，柔和真实边缘。

【人物面容】
保留参考的柔和面颊与下颌、眼尾走向、鼻唇关系和唇峰特征。气质温柔清冷，脸型自然，五官精致，不统一改成尖下巴大眼脸。

【妆容与肌肤】
精致贴肤底妆，柔和眉形与棕灰眼妆，清楚的睫毛根部，柔润豆沙珊瑚唇色。肤质细腻，面颊缎光、鼻部细小柔光、嘴唇润泽彼此不同。真实感建立在完整妆面上，纹理低对比，在全身画幅中不强行显示毛孔。

【发型与饰物】
黑发保持高盘束与蓬松轮廓，保留青绿橙色细小花饰、簪饰和垂坠耳饰；整理跨脸碎发，让双眼鼻口清楚，仅脸廓外有少量细发。

【服装设计】
延续青黛、灰绿、浅金与暖金花卉织锦语言。保留领口的交叠与肩部花卉层次，延展为内外层古风长裙，宽袖顺重力垂落。腰部青黛束带配少量暗橙细带，裙身花纹沿衣片分布，局部留出安静素面；饰物精巧。

【材质与衣料】
主体织锦有细密厚度和柔和丝光，花卉织金随衣褶转折，内裙象牙色细密丝绸，局部薄纱罩层轻透。衣片连接、收腰受力与裙摆落地堆叠可信，金饰小而有厚度。

【动作与神态】
身体正对镜头，头端正，安静看镜头，唇部放松。重心稍落一侧，双肩自然松开，双手在下腹前轻覆，手指分组清楚、轻微弯曲不紧绞；体现舒缓呼吸与专注。

【身材比例】
高挑匀称的成年女性，约九头身时装观感，头与肩宽相称，完整胸廓、腰腹和骨盆，腰部自然收束、臀部有适度体积。上下臂和上下腿长短、粗细协调，颈部自然，可见肩臂有柔和肌肉与软组织；不用极小头、超长颈或抬高骨盆凑比例。

【构图与完整性】
平视的完整全身棚拍，人物居中。头饰、双袖及完整自然裙摆全部入画，上方与下方各留约6%空白，左右不切袖摆。长裙可自然遮住鞋，不缩短衣裙来露鞋。画面不含字、边框或水印。

【背景与布光】
纯白无缝棚背景，只有柔和接地阴影。大面积前上方柔光与正面补光，让双眼、面颊均匀受光且保留柔和体积；中性白平衡，保留青黛色与织金的真实色差，面部清楚。移除原图花枝、散景、斑驳光影。

## 02-modern-r1

【任务与参考】
以唯一参考中的成年女性为身份与主要穿搭方向，生成3:4竖幅完整全身的高级生活方式写真。地点改为清简庭院步道，人物有自然迈步动作。单人。

【表现方向】
精致真实摄影，妆容完整、人物温暖自然，光线干净，日常穿搭质感高级；身体修长匀称，有真实活人感。

【人物面容】
保留参考柔和面颊、圆润流畅下颌、眼鼻唇关系和温和气质，保持同一成年女性的辨识度。自然微笑，目光看向镜头旁的近处，脸部轻微转向镜头。

【妆容与肌肤】
精致轻薄底妆、柔和棕色眉眼和自然珊瑚唇色，腮红与肤色干净过渡。真实肤质服从妆面美感，面颊、鼻部和润泽嘴唇反光细腻有区别，保留自然眼睑体积，不靠毛孔、锐化或疲态制造真实。

【发型】
深棕长发低束，发束自然蓬松，侧后方发尾轻微随步态摆动。大幅收拢遮挡眼鼻口的碎发，保留少量脸廓外细发。

【服装】
灰粉色细密针织开衫，奶油白圆领内搭，浅燕麦色高腰直筒长裤与白色简洁低帮平底鞋。下装为参考未见区域的协调设计，腰位自然。开衫不过度宽大，袖口和纽扣有清晰结构。

【材料】
开衫针织柔软有厚度，肩肘处有自然受力褶皱；内搭细棉布哑光；长裤面料垂顺但有骨感，裤管在膝踝处形成自然褶皱；鞋面干净、不发塑料光。

【动作与神态】
捕捉平缓迈步的一瞬：前腿承重，后脚脚跟轻抬、脚尖即将离地，步幅适中，骨盆与双肩轻微反向转动；双臂自然摆动，一手轻触开衫边，另一手放松。眼神温暖专注，笑意轻盈，动作与衣料响应一致。

【身材与肌肉】
修长匀称的成年女性时装体型，头与肩宽自然协调，颈部不过长，胸廓到腰腹再到骨盆结构完整。腰臀线条流畅，上下臂和大腿小腿长度协调，腿部有适度柔和肌肉体积与自然膝踝，衣下不刻画分块肌肉，不制造极细腰或超长腿。

【构图】
平视完整全身，人物位于画面中部略偏一侧，为前行方向留出空间。头顶、摆动手臂及双鞋全部入画，上下各留约6%边距；相机不过度广角，不俯拍压短双腿。

【场景与光线】
