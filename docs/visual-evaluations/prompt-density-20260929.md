# 简洁与详细提示词实图对照

2026-09-29，基于 v0.9.6，新增四张真实图。此轮检验“是否限制过多”，结果不足以支持全面缩短提示词，因此保留编译器行为和版本号，仅更新评审说明与证据。

## 实际比较

选原图 8 的灰青织锦与原图 1 的象牙白素布，覆盖不同材质和装饰密度。每一对采用相同原图、相同英文参考专属造型段和相同 3:4 白底全身任务。优秀织锦全身图仅用于评审，未送入模型。

- A 为手工按参考驱动原则组织的简洁通用段，加参考专属说明：原图 8 共 1251 字符，原图 1 共 1297 字符。
- B 为当前 CLI 编译全文，加同一参考专属说明：原图 8 共 5601 字符，原图 1 共 5647 字符。
- CLI 选项：`--presentation costume_showcase --design-freedom moderate --maturity-guard none --format text`，通用输出 5032 字符。没有修改或截断编译正文。

两套通用段的语义、姿态细节、材料描述和篇幅都不同。这不是严格“只改字数”的实验，没有固定模型或种子，不能推断某个长度阈值会提升质量。

## 四张输出

| 输出 | 观察 | 决策 |
| --- | --- | --- |
| a-08-concise | 全身、鞋尖和衣摆完整；青灰与锈红延续原图；织锦与浅色袖里都较密，整体偏厚重，浅色中部较窄 | 可用的简洁方案候选；未显示优于详细版或优秀图 |
| b-08-compiled | 全身与衣摆完整；浅色内裙范围更清楚，金色花纹形成较分明的集中区域，叠手与袖布关系可读 | 当前这对中更适合展示分层；不据此宣称长文本普遍更好 |
| a-01-concise | 侧向面容、松散黑发、素布交领、干燥褶皱和鞋尖可读；粗布感更明显，背景偏浅灰、侧向投影较重 | 简单材料可由较少文字传达，但白底与柔光表现没有全面优于详细版 |
| b-01-compiled | 保留侧向头部、素布与无花纹设计，叠手和袖摆更收束，背景更接近白色；材料表面较平顺 | 未发生金纹或华服污染。粗布质感与简洁版不同，没有统一绝对胜者 |

本轮既没有证明简洁版全面更好，也没有证明详细版应覆盖所有任务。保留按参考具体编写、按可见问题补条款的方式。服装与造型允许适度优化，不意味着把所有结构说明删掉；文字越多也不等于约束更可靠。
