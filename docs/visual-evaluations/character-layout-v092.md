# v0.9.2 复杂造型与原图覆盖实测

2026-09-29，延续用户授权：人物保持可辨认，服装与造型允许适度优化。本轮新增 7 张真实图，所有生成调用只输入对应原始参考；优秀效果图用于提取设计语言与评审，没有直接作为生成输入。

## 从实际问题修改工作流

补齐原图 3、4、6 的独立全身输出后发现：原图 6 的 A 图裙尾被左右画框截断，肩甲与后方龙颈、鳞片在视觉上拥挤。原图 4 的 A 图虽然身体与靴履完整，近肩和前臂后方的细节仍多。不是所有问题都能靠继续追加“保持、完整、不得裁切”来修复。

因此把旧的概念清单式角色资产流程改成参考驱动的造型与空间描述：前景人物需要完整展示哪些部位；后景守护形象在哪里；哪里需要可见白色空隙；肩甲、臂甲、腰甲如何附着；裙尾的落地轮廓是什么。手工整理最终提示词，合并已被具体方案覆盖的通用条款。保持 CLI 对长袍的原有功能，不声称手工精简文本是未经修改的 CLI 原文。

## 全部八张原图的证据覆盖

[覆盖清单](reference-coverage.json) 为当前来源与候选索引，记录已实测、候选位置、用户验收和剩余问题。此前原图 1/2/3 混作一次输入的旧结果不算独立覆盖。现在原图 1 至 8 均有至少一次只输入自身原图的真实全身生成，但独立覆盖不等于身份、解剖、服装和审美都已经验收。

优秀效果图的新黑金造型与现代短裙方向尚未进行对应独立测试；没有把用户的新一组效果图全部算作已验证。下一轮可在既有身份上检验这两个方向，以及跨衣装之后的表情和人物辨识度；已有好候选应保留，不为凑测试数重复重做。
