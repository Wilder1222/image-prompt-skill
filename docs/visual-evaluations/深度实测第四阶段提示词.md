# 深度实测第四阶段实际提示词

两次独立局部编辑，均保留原始验收条件，不替换完整第二轮。以下正文与实际提交内容一致。

## 03-blackgold-r3

【编辑对象与目标】
编辑唯一附图的画布取景。保留东方幻想概念原画媒介与3:4竖幅，人物和衣装整体作为一个不可分割的完整主体。

【保持人物与场景】
保留现有人物面容、妆面、黑发古金冠饰、身体比例、基本正面的重心变化、左手提袖和右手下垂、所有黑金凤凰衣甲与象牙暗红裙片。保持灰色墙地、前上方柔光、原画笔触和原有接地影。不要改脸、改姿势、修瘦、拉长身体、换衣或变成摄影。

【唯一改动：完整取景】
把附图整体等比例缩小至原来约88%的尺寸，居中放入最终画布，周围自然延续已有的低对比灰墙与地面。最终冠顶与画面顶边之间约6%空场，最低自然裙缘与画面底边之间约6%空场，左右所有衣发也保留清楚余量。人物、裙尾和影子同步缩放，不变形、不重画服装局部；不裁掉新增加的空场，不自动放大人物填满画布。

## 04-teal-r3

【编辑对象与目标】
编辑唯一附图，将人物的绘画式表现转换为真实成年女演员穿着同一套古装的专业写真摄影。输出仍是原图3:4完整全身庭院画面，本次只改变人物皮肤、五官与头发的成像表现。

【锁定人物辨识与其余画面】
保留此人物柔和轻扬的眼形、自然唇形、柔和下颌和年轻成年气质，不换成通用网红脸。保留头部与身体大小、位置、朝向、现有手搭腰和另一手下垂的动作、整体体型、青绿米白锈橙衣片、腰封、金纹、耳饰和庭院构图。保持黑发半束与侧后辫发结构；衣装、背景和画幅不重设计。

【面容与精致妆面】
将画中的眼睑、眼球、鼻翼、嘴唇、面颊和下颌表现为真实女演员的立体软组织，在相同位置保留五官辨识关系。精致薄底妆，柔和棕灰眼妆，自然睫毛与豆沙裸唇。眼睑包住眼球，睫毛从睑缘生长，虹膜有细微深浅和匹配庭院柔光的眼神反光，鼻尖与唇面的反射各不相同。妆面干净完整，肌肤透光与微纹理克制，不添加粗大毛孔、斑点或疲态。

【摄影表现与光线】
成片应当像真实镜头拍摄的精致古装人像。脸部不保留二维描边、笔刷色块、瓷偶平滑表面或统一发亮眼球。发束有真实根部密度、细发反射与层次，保持原发型并让眼鼻口清楚。遵循画面已有柔和自然光方向，面部曝光均匀、五官立体，肤色与手部相同；无需把脸锐化成与全身景别不符的大特写纹理。不要用增加噪点冒充摄影，也不要改变现有取景与姿态。
