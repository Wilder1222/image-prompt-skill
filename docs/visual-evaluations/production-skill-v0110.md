# 参考图与描述驱动的生产流程实测

2026-09-29。用户明确目标是成熟的 Skill：提供参考图与描述，由技能产出有效生图提示词；不是建立更多固定模板。v0.11.0 据此调整主入口，并执行三套独立提示词与五次真实图像调用。

## 原短板与改动

旧 `asset-prompt` 主要接收预设选项，同样的选项会得到同样的正文，缺少逐图观察与本轮需求的编译输入。现将它标为 `scaffold_only`，不能直接冒充生产提示词。

新的主流程要求代理实际看图，提取有区别的身份、发型、衣片、材料与遮挡事实，解析描述后决定保留、改变和补全，再独立写中文分类正文并做语义审查。新 `prompt-build` 消费这次观察和决定，检查声明的参考权限、不可见信息假锁定、必须要求覆盖、遗漏验收项与未完成文本；它不自动理解图像，也不把声明正确当作语义或画质保证。

`prompt-review` 绑定实际提示词摘要与输出文件摘要，要求各检查项写可见证据。关键失败、不确定和观察者通过是不同状态，不自动等于用户接受。

## 实测设计

- 青黛花卉：原近景参考 6，用户第一份美感和材质方向。仅输入原图；优秀全身结果用于观察对照，没有作为生图输入。
- 黑金幻想：原近景参考 5，结合第二份原画方向与白黑古金暗红服装方案。服装改造属于本次明确写下的测试设计，不冒称全部来自原图。
- 现代留出：最初八图中的现代针织肖像 7，单独编写开衫、圆领 T 恤、奶油长裙和帆布鞋方案，使用自然成人比例。未复用古风生成正文，用来检查默认衣装与比例是否串入。

工具为内置 image_gen，未返回的具体模型和种子记录为未知。五张实际结果均为 1086 × 1448，即 3:4。图片及包含本机路径的完整输入、实际提示词和回执保存在本地 `dist/visual-tests/production-skill-20260929/`，不进入 Git 或插件包。

古风两例的身份相似度仍待确认，幻想款下半身偏长的观感也未宣称通过。裙下另一只脚、部分指节的遮挡记录为不确定，不能因没有明显缺陷就假定全部正确。现代例是观察者对单张结果的判断，未获得用户验收，也不证明批量可靠性。

实际生成正文在每次工具调用前保存。部分结构化回执随检查器升级补录；没有改变已提交文字或把局部修复当成原始提示词一次成功。源文件和最终文字的 SHA-256 用于核对实际调用与记录一致。

## 本轮验证的能力与边界

已跑通“逐图观察与描述 → 设计判断 → 专属提示词 → 检查 → 实图 → 定位问题 → 小范围修订”的路径。首轮失败被记录并修复，代码测试没有把它们冒充视觉通过。

可推广的规则是：白底必须检查输出本身是否不透明；完整人体入画也要检查最外层衣摆是否触框；不同服装需要独立观察，不能全局注入古风元素或 P9；身份不确定时保留候选与原始证据，不反复重塑脸。

这些样本尚不能证明任意输入、任意模型都稳定产出。未来要在更多留出角色和重复调用上积累结果，分别统计首次满足要求与经修订满足要求的情况，而不是只报告最终挑中的好图。

自动化回归：263 项通过，覆盖来源权限、未知部位、缺失要求、语义标签完整性、精确文字摘要、文件绑定、局部锁定、插件独立运行及发布完整性。它们证明流程与数据约束，不证明审美效果。
