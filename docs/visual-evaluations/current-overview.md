## 保留下来的优化

- 分离人物身份、服装设计、呈现风格与编辑母图的权限，允许明确的服装和造型改案。
- 按衣片描述材料厚薄、透光、纹样分布和内外层关系，避免所有层都变成同一种亮面织锦。
- 区分长袍、现代装和铠甲路线；复杂守护组合分别描述前后位置、人物完整取景与装饰裁切。
- 面部疑似变化注明视角、光线和脸部像素大小的影响；修改收益不明确时保留旧候选。
- 实图对照未证明短提示词全面更好，保留当前编译器；删除冗余应以冲突和失败证据为依据。

## 核对结果与边界

[机器可读总账](current-overview.json) 记录 33 份输出的提示词与图片 SHA-256、来源报告、候选选择和检查范围。已核对请求正文、归档输入与实际输入的顺序和摘要、仅评审参考、输出 PNG 摘要与尺寸，以及全部八张原图的独立测试覆盖。两份旧基线的 `.prompt.txt` 比请求正文多一个末尾 LF，分别保存两种摘要，未覆盖历史文件。HTML 的图片和链接目标均存在；这不代表浏览器外观验收。

这些检查确认产物可追溯，不证明视觉质量。人物身份和审美仍为用户验收 pending；单次随机生成不能证明稳定成功率。黑金双参考出现额外腰饰，复杂组合顶部偏紧，面部一次修复收益不明，均在对应记录保留。没有将这些问题隐藏或宣称全部质量通过。本次实测改进工作已交付，后续可依据用户选择继续细化具体候选。

各轮报告中的 active/partial_progress 是当时状态快照，不回写历史结论；本总览记录当前交付状态。
