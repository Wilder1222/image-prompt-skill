# 中文标签与自然比例纠错

2026-09-29。用户明确指出上一批应为带标签中文提示词，且人物比例不对。上批的“正面、全身、材料可读”检查不能替代比例验收；此前将其作为完成交付存在遗漏。

## 已查证的问题

- 旧示例保留 `【P0 人脸身份】` 等中文标签，但主工作流改成英文编译，实际送入图像工具的也是英文，并非用户预期格式。
- 默认成年古风预设使用 P9。上批使用的 `costume_showcase` 则覆盖了 P9 条款，**没有直接发送九头身数值**，但仍强调高挑、长衣片，缺少独立自然比例约束。不能把上批问题全部归因于显式九头身指令。
- 评审过度集中在全身入画、裙摆、服装材质，漏掉整体头小身长、长裙造成的下半身拉长感。长裙遮挡膝髋，不能虚构精确测量；也不能因此将比例问题视为通过。

## 实施的规则修正

`asset-prompt` 默认中文标签输出；明确选 `--language en` 才返回英文。生成、母图保留、面部、结构、材料和光线修复都有中文范围说明。程序库旧调用默认英文保持兼容，中文消费者显式传 `language: 'zh-CN'`。

默认比例改为 `NATURAL_ADULT`，约七至七点五头身是设计指导，不是对原图人物的测量。发髻、头饰、拖尾和鞋跟不参与人体长度计算。衣装展示与骨架比例分开；`--proportion-profile P9_FASHION_ASSET` 仅供明确的时装比例请求。完整全身母图仍保留自身比例，不受新默认重设。

生成用中文正文与用户交付一致；每张追加实际观察到的人物、衣片与材料，不用同一套脸或衣装覆盖多图。批量执行前先检查小样比例，失败时不继续按同一方案铺开。
