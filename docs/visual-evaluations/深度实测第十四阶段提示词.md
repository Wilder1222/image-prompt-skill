# 几何布局框辅助实验实际提示词

仅为本次已执行实验，不是默认模板。身份图与几何框图职责分开，原始冻结输入、输出和评审保存在本地。输出未通过原取景要求，不能将本提示词标为已验证成功。

【任务与参考】
生成一张单人3:4竖幅古风白底全身定妆照。第一张图A是唯一人物身份、发型与衣装来源。第二张图B是无人物的布局示意，只规定全身主体占据的位置，不是场景或装饰参考。最终只保留人物、白底和接地影，不画蓝色框线。以唯一参考图中的年轻成年女性为人物与衣装来源，制作一张3:4竖幅的正面全身白底定妆照，单人。保留人物辨识点，半身未见的衣服下部按可见设计自然延展。

【表现方向】
精致古风写真摄影，人物好看、真实、有生命力；九头身时装观感，真实高级织物，柔和真实边缘。

【人物面容】
保留参考的柔和面颊与下颌、眼尾走向、鼻唇关系和唇峰特征。气质温柔清冷，脸型自然，五官精致，不统一改成尖下巴大眼脸。

【妆容与肌肤】
精致贴肤底妆，柔和眉形与棕灰眼妆，清楚的睫毛根部，柔润豆沙珊瑚唇色。肤质细腻，面颊缎光、鼻部细小柔光、嘴唇润泽彼此不同。真实感建立在完整妆面上，纹理低对比，在全身画幅中不强行显示毛孔。

【发型与饰物】
黑发保持高盘束与蓬松轮廓，保留青绿橙色细小花饰、簪饰和垂坠耳饰；整理跨脸碎发，让双眼鼻口清楚，仅脸廓外有少量细发。

【服装设计】
延续青黛、灰绿、浅金与暖金花卉织锦语言。保留领口的交叠与肩部花卉层次，延展为内外层古风长裙，宽袖顺重力垂落。腰部青黛束带配少量暗橙细带，裙身花纹沿衣片分布，局部留出安静素面；饰物精巧。

【材质与衣料】
主体织锦有细密厚度和柔和丝光，花卉织金随衣褶转折，内裙象牙色细密丝绸，局部薄纱罩层轻透。衣片连接、收腰受力与裙摆落地堆叠可信，金饰小而有厚度。

【动作与神态】
身体正对镜头，头端正，安静看镜头，唇部放松。重心稍落一侧，双肩自然松开，双手在下腹前轻覆，手指分组清楚、轻微弯曲不紧绞；体现舒缓呼吸与专注。

【身材比例】
高挑匀称的成年女性，约九头身时装观感，头与肩宽相称，完整胸廓、腰腹和骨盆，腰部自然收束、臀部有适度体积。上下臂和上下腿长短、粗细协调，颈部自然，可见肩臂有柔和肌肉与软组织；不用极小头、超长颈或抬高骨盆凑比例。 腰部收束与臀部体积连续，上臂至肘再至前臂、髋至大腿再至小腿的长短与粗细共同协调，肌肉轮廓随承重松紧变化；服装覆盖处用布料支撑和褶皱表现，不穿透面料雕刻肌肉。

【构图与完整性】
以图B整张白色画布作为最终画幅。将人物连同最高花饰、宽袖和最低自然裙摆完整放入蓝框所示范围：最高花饰对应框的上沿，最低自然裙边对应框的下沿，左右衣袖与裙摆不超过框的侧边。保留框外已有的上下白色空场，不放大裁切画布。完成后不显示参考框线；蓝色仅是定位辅助，不进入人物或背景配色。平视的完整全身棚拍，人物居中。头饰、双袖及完整自然裙摆全部入画，上方与下方各留约6%空白，左右不切袖摆。长裙可自然遮住鞋，不缩短衣裙来露鞋。画面不含字、边框或水印。

【背景与布光】
纯白无缝棚背景，只有柔和接地阴影。大面积前上方柔光与正面补光，让双眼、面颊均匀受光且保留柔和体积；中性白平衡，保留青黛色与织金的真实色差，面部清楚。移除原图花枝、散景、斑驳光影。
