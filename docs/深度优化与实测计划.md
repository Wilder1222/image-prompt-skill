# 深度优化与实测计划

目标：多轮分析并优化 Skill，检查项目一致性，将脚本以外的自然语言内容统一为中文，并以真实图像测试验证平均分达到 9.5 分以上。当前基线为提交 `e1d042f`，下列标准在新一轮出图前确定。

用户已将目标由超过 9 分提高为 9.5 分以上，按至少 9.5 分执行。十项等权评分、分值锚点、原始评分与全部尝试统计不变；旧阶段汇总保留为当时记录，当前报告使用新门槛。

## 完成条件

1. 主入口、知识文档、资源中的说明与提示词、示例、交付报告均使用中文；脚本、命令、路径、接口字段和兼容标识按其语法保留。逐项审查英文残留，不以给英文段落加中文标题冒充中文化。历史原文的译文注明来源，原始执行证据不可静默改写。
2. 至少完成两轮提示词与图像测试，固定测试要求、评分维度和权重，保留每次尝试、失败与修订关系。
3. 本次所有已完成图像的平均分和最终完整测试轮平均分都至少达到 9.5 分；缺图、未评审或关键证据不足不能视为达标。该结论仅适用于本次测试集，不代表任意输入均获 9.5 分，也不代替用户验收。
4. 当前规则、中文正文、资源与派生文件一致，校验和相关测试通过，安装后的插件内容与发布来源一致。
5. 发布优化方案、逐图评分依据、测试汇总与剩余风险；完成后提交、推送并更新本地插件。

## 实施顺序

第一轮分析：盘点英文内容、规则冲突、旧预设泄漏及实测证据空缺，生成清单；先完成两案真实基线。

第二轮分析：按图像缺陷修改提示词策略，逐批中文化知识与资源，保持接口兼容；完成其余基线和第二轮实测。

第三轮分析：复核中文覆盖、编译与插件一致性、逐图评分和统计分母；未完成项继续推进，不提前宣告达标。
