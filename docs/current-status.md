# 当前项目状态

当前版本：0.15.0。只维护现行技能、脚本、资源、测试、示例与当前证据，历史报告可从 Git 历史追溯。

## 当前人物比例硬规则

自 2026-10-06 用户确认起，人物资产统一执行黄金九头身；生成、扩身、全身母图、多视角与换装均适用，比例列为关键验收项。旧自然比例选项不再用于生产。此变更不追溯修改历史快照、评分或图像；此前三视图按旧目标生成，不能当作新九头身规则的达标证据。

生产编译入口已补齐同一要求：新 brief 明确主体范围，人物必须关联九头身数值目标、必需比例正文和关键验收；遗漏、降级为可选、改成其他头身数或仅在无关类别挂引用会被拒绝。局部编辑不扩大修改范围，比例未决仍阻止整体合格；非人物任务不增加人体要求。新范围写入冻结目标摘要，旧快照可按旧标准核验，新生产须显式迁移。结构检查不代替语义审查或真实图像验收。
