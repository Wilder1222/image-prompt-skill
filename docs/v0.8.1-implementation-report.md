# image-prompt-skill v0.8.1 Implementation Report

## Version
Detail Budget & Visual Hierarchy

## Why this version exists
The latest black-red-gold queen test successfully restored the desired oriental epic painterly direction, but remaining differences from the target were no longer about render mode or subject identity. The result was still too uniformly complete: background architecture, highlights, hair, ornaments and fabric all competed at similar visual intensity.

v0.8.1 therefore freezes the successful v0.8.0 decisions and adds a hierarchy-only refinement layer.

## Implemented
- Detail Budget Controller
- Highlight Hierarchy Controller
- Background Submission Controller
- Painterly Edge Controller
- Combined `oriental_epic_concept` hierarchy profile
- `concept_art_hierarchy_refine` repair round
- 12 hierarchy-specific diagnostics
- Iteration Director commands for each controller and combined plans
- Provider-specific hierarchy notes
- black/red/gold queen regression prompt

## Validation
All previous tests remain enabled. v0.8.1 adds tests for all four hierarchy controllers, repair routing, priority ordering and black/red/gold integration.

## Boundary
This version does not claim that the visual result is validated until the new hierarchy prompt is run against the approved black-red-gold result. Automated tests validate routing and configuration, not image quality.
