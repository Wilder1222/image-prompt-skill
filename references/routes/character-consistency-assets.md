# 人物多视角与成组验收

用于同一人物的多视角、表情组、换装组与后续镜头参考。按用户用途决定所需资产，不默认六视图、白底、站立、闭嘴或建模姿态。单张任务仍走 [提示词生产流程](prompt-production.md)。调研来源和未证实假设见 [研究记录](../../docs/character-asset-research.md)。

人物统一按 [协调修长的身材目标](../core/fashion-proportion-system.md) 检查；基准、派生视角和换装继承已认可比例。表情近景按可见范围验收，不承担隐藏全身的证明；完整母图另验。各图按景别安排占比与留白，不强行统一人物像素高度。

## 先明确资产用途和基准

| 用途 | 需要保持 | 可变部分与验收重点 |
| --- | --- | --- |
| 定妆展示 | 人物辨识点、当前造型 | 姿态与表情可服务展示；不冒称可直接建模 |
| 服装转面 | 人物、同套衣装、身体比例 | 视角改变；检查前后衣片连接、同一侧饰物、衣长与层次 |
| 建模三视图 | 设计、姿态、共同尺度 | 精确正交与弱透视展示分开约定，不互相替代；统一头顶和人体足底基线，生成图不自动具备测量精度 |
| 表情组 | 人物、年龄、造型 | 眼睑、眉、唇和面颊可随表情运动；不锁死嘴角坐标 |
| 换装组 | 人物与本轮要求的发型等 | 新衣服使用独立设计版本，不能要求同时保留旧衣片 |
| 场景应用 | 人物及选定造型状态 | 光线、动作、景别按场景改变，另验身份和可读性 |

表情组进一步读取 [中性基准与动作变化](../core/identity-vs-temperament-diagnostics.md#表情资产的基准与变化)：身份保持不等于冻结嘴角与下颌，头肩表情通过也不证明完整身体协调。

已有合适母图就使用它；纯文字任务先产生候选并看图，不能将文字档案记为已观察的身份。记录基准图路径、内容摘要、角色与造型版本、选择人和理由。代理选择的测试基准不是用户认可的最终定妆。用户换身份或改造型时开新版本，不覆盖旧依据。

辅助身份图与完整人物母图分开记录。头肩图可以提供已核对的脸部依据，但不证明隐藏身体或下装；比例仍不可判断时保留 `needs_review`，只声明本轮可用的身份通道。若身份本身不确定，不能把它升级为已确认身份来源。生成式重新取景可能重绘五官和皮肤，必须与原图比较，不能称为无损裁切或原图细节恢复；程序裁切仍按用户已有授权执行。

[白蓝汉服近景微笑实测](../../docs/user-aesthetic-portrait-evidence.json) 保留了可辨认面容与柔亮妆肤，并形成自然的少量露齿微笑；首饰连接及领肩花绣的细部保持仍未确认。原全身图中的小部件在近景变得清楚，不等于它们已被原图证实。分别记录可比较的大体布局、尚不能核实的细部，以及事前允许的补全；例如新露出的牙齿可作为本次表情设计，不能回填为人物原有牙列。后续若使用这张近景，按已核对的身份与表情用途取用，不能仅因更清晰就让它覆盖原衣装和首饰设计。

使用派生身份图时，保留原图、派生图的生成记录和输出摘要，再核对下游实际输入摘要确实指向这张派生图。上一轮修订父记录与某张参考图的来源记录是两种关系：全身修订继续关联原全身目标，头肩来源另行记录，不能为串成一条链而混改任务或目标。完整母图中的衣装可观察后改用文字传递，但必须明确它是否实际送入模型，不能声称未发送的图像在直接控制输出。

## 分开记录不变项与每张变化项

- **身份**：从可见证据写本人的眉眼、鼻口、脸颌关系、表观年龄和有辨识度的特征；不要为了便于识别新添疤痕，或把所有角色改为同一套美人脸。
- **造型**：发束与固定位置、服装衣片和开合、材质分区、附件连接。左右始终以人物自身为准，再写当前画面投影。例如“人物自身左肩的铜扣；正面图位于画面右侧，背面图位于画面左侧”。若该处背面不可见，允许遮挡，不为显示扣子移到后背。
- **可变项**：当前视角、表情、动作、光线和明确授权的衣装变化。先清理与变化冲突的旧条款，例如侧面任务不保留“左右眼同时清楚、直视镜头、两侧肩甲都展开”。
- **未知项**：正面照片不证明背缝、后领、后发束和衣服内部结构。可在允许范围内设计衔接方案，标为“本轮设计延展”，不能称为原图复刻。左右视图不能互相镜像代替有不对称设计的角色。

内部记录按当前 `prompt-build` 的 `requirements`、`references.facts` 和 `sections` 表达：可见继承用 `retain`；未见补全用 `design` 并附理由；实际未看到的图不写 `inspected: true`。最终正文仍使用无编号中文语义标签，内部角色和版本标识无需进入画面。

转面前先处理影响轮廓或附件位置的连接歧义。对每个有歧义的部件写清：属于哪件衣服、接在哪个身体部位或衣片、终点在哪里、哪一面朝外，以及当前视角会被什么遮住。依据可见图继承；缺失处另写设计延展，不能把新增挂环、接缝或背片叫作原图恢复。该方法用于本次有歧义的部件，不要求所有人物都新增结构说明。

把设计声明与观察计划配对。选能看见目标连接的视角，必要时在任务允许范围内小幅调整手臂等遮挡物，并把姿态变化写入本轮目标；不要为展示近侧附件把远侧披片搬过来。若目标只是外观转面，检查可见轮廓、边缘和挂点，把不可见内侧连接单列为设计信息；若下游明确需要内部装配证明，应另设结构详图或可检查的源模型，不能用普通穿着图冒充。结构详图也属于新设计表达，不是从单张照片恢复隐藏真相。

### 配色设计与画面颜色分开记录

成组任务需要稳定配色时，沿用当前角色的部件与颜色关系：哪一件上衣、哪一段滚边、哪一侧发饰使用什么颜色，主辅色分别覆盖哪里。颜色记录可直接写入已有身份、头发、衣装或背景要求，不增加用户必填表；只在交付确需色板时制作配色表，不给每次定妆额外生成一张图。[角色设计师 Julio Robledo 的设定图教程](https://www.clipstudio.net/how-to-draw/archives/164740) 将颜色表与转面、表情和姿态表分别处理；这里采用用途分工，不继承示例人物、头身比或固定张数。

| 已有依据 | 如何表达和复核 |
| --- | --- |
| 仅有受光的人物图 | 写可见的部件色相、深浅关系与颜色分区；高光、阴影或环境色中的单个像素不是已知材料本色 |
| 已确认的配色色板或明确色值 | 保留部件对应、原值及已知色彩空间；未指定空间不自行补成测量事实。色值是设计要求，不能承诺普通生图入口逐像素精确复现 |
| 换光照、背景或媒介 | 分别声明保持的配色设计和获准变化的受光／笔触表现；不可同时要求所有旧明暗像素保持，又要求重新布光或水彩洗染 |

先在可比部位核对颜色分配，再判断是否出现未经授权的改色、颜色互换或新图案。水彩的浓淡叠色、厚涂的冷暖笔触和金属的环境反射不直接等同于新增服装花纹，也不能以媒介变化为由放过明确改色；难以区分时写明具体区域与不确定性。仅凭两张成片不能断言色差由灯光、材料或色彩管理单独造成，也不能从中反推出精确本色。若任务明确要求数值色彩一致，另行约定可比较的输出条件与核验方法，不能以“整体相近”判该项通过。

上述比较只判断配色。衣片连接、身份、媒介、比例及本轮编辑保护仍分别验收；配色关系保持不使候选自动成为合格母图。

## 选参考并生成

默认从已检查的基准派生所需视角。可用同人物、同造型且视角更接近目标的已检查图片补充细节，但仍回看基准，避免把上一张的小错误沿链传递。支持多图的入口使用一个主要身份来源，补充视角明确同组及权限；姿态图或衣装图不获得身份权限。只有一张输入时，依据当前任务选择信息足够的单图或清晰图谱，并说明无法同时传入的参考，不能静默丢图。

### 合并参考前先处理部件分歧

“属于同一组”只说明来源关系，不能让相互矛盾的细节同时成为设计依据。逐部件核对当前设计版本、生成前要求与实际图像，不按最新图片、最大清晰度或整图相似度自动决定谁覆盖谁：

| 所见关系 | 下一轮如何使用 |
| --- | --- |
| 同一部件在一图可见、另一图被遮挡 | 从可见图借用对应信息；不把遮挡当成部件消失，也不为显示它而搬位置 |
| 某图按预先声明补出了原先未见的结构 | 标明这是该版本的设计延展及其局部观察结果；不回填为原基准已经证实，也不因此升级整图 |
| 生成图出现未预先决定的口袋、扣件或接缝 | 先记录为候选细节。允许本轮设计时可明确采纳或移除并形成新版本；不能因为模型画出了它就自动继承，未见也不自动等于禁止存在 |
| 两张图对同一可见部件的连接、数量或位置不兼容 | 回到已确认设计决定取舍；依据不足时保留未决。影响本轮关键结果的矛盾进入 `unresolved`，先解决再编译；不得把两个方案一起写成“全部保留” |

把取舍落实到现有 `references.facts`、正文和验收项：写明哪张图提供哪个部件，哪些只供观察，哪些不得借用。`authority: costume` 是类别权限，不代表授权继承该图所有衣装细节；只列局部事实也不会给图像模型自动加蒙版。实际送入整张图时仍可能误借其他部位，输出要检查；若只把观察转成文字，明确该图没有实际送入。不能通过删除冲突事实、继续引用整图“完全一致”来假装冲突消失。

[现有正背面图的取舍示例](../../docs/character-multiview-reconciliation-review.json) 区分了预先声明的中央背缝、未决定的裤后贴袋、仍不清楚的腰下衣片，以及自然遮挡的前铜扣。它只说明这两张旧图可为哪些设计决定提供证据，没有新增出图、修改旧回执或证明整组可用。

普通多图输入与专用多视角管线分别记录。[MV-Adapter 的方法](https://arxiv.org/html/2412.03632v1#S4) 使用相机或几何条件编码及跨视图注意力；文字中的“同一角色、正交三视图”不等于当前宿主执行了这些控制。若以后接入专用管线，需核对实际条件、视图约定和输出；现有技能不由论文名称自动获得相机、几何或身份保证。

逐图和拼板是交付选择，不是跨模型定律：

- 需要脸部细节或独立生产资产时，优先逐图生成和检查。每张回连基准，完整保留失败尝试。
- 用户要一张三视图时可以直接生成拼板，明确各格视角、共同尺度和间隔；逐格检查面容、衣片、附件和镜像问题。格数越多，每格可用像素越少；拼板通过不等于所有细节已清楚。
- 审阅拼板可以来自已检查单图，保留单图路径和真实来源。展示排版不能改变原图后再冒称原始生成；程序裁剪、拼接或补边按用户已有授权执行。
- 模型只能文生图时，不承诺参考身份锁定。固定种子、身份文字重复、相似度分数都不能代替实际身份检查。按 [模型适配](../providers/provider-adaptation.md) 明确入口限制。

借用设定表模板时，把分格安排写入 `layout`，把每格视角写入 `composition`，各自验收。模板中的人物、身材与衣装不随布局继承，线条媒介也需独立授权；详见 [来源权限](../core/reference-authority-matrix-v080.md)。文字标注若属于正式交付就检查内容和可读性，不能套用第三方“伪文字仅装饰”的方案；未要求文字时不自动加手写标记。风格与版式变化仍须保持协调比例及适当留白。

先做能暴露本任务风险的代表变体，再决定是否批量扩展。例如不对称造型先测转面，面部资产先测侧面或指定表情。不要为了把不合格项藏起来而改变所需景别或遮住脸。生成与修订次数沿用 [主流程](prompt-production.md) 的本轮范围。

## 整组检查与交付

生成前为每张图固定目标与检查项，使用 [执行记录](production-execution.md) 保存实际输入顺序、提示词和文件摘要。换视角是新目标，不计作正面失败的修复成功。

把整组需要覆盖的结构分配给能看见它的视图：正面验前扣、侧面验厚度与挂点、背面验背缝。不把“中央背缝完整可见”同时设为严格侧面和背面图的必过项。侧图可以声明背缝设计以保持一致，但验收仅判断其实际可见部分；整组仍需由背图补足证据。已经生成后发现检查项本来不可观察，保留该次 `not_assessable` 并说明目标设计问题，不能把失败回填成通过。

同理，不把“灰蓝护片下缘可见”“护片内部接在外套上”“右髋皮袋挂环可见”合成一个模糊的结构通过项。前者是外观证据，第二项可能完全遮挡，第三项可以通过视角与避让观察；在生成前按实际交付拆分。冻结后发现其中内部连接不可见，原条款仍未解决，不能出图后删除条件换取通过。[右侧连接诊断](../../docs/character-connections-evidence.json) 中袋挂点变清楚，但内侧布带仍未确认，身份与九头身也待审。

逐张检查当前用途，再与基准及相邻视角交叉检查：

| 检查项 | 判断依据 |
| --- | --- |
| 身份 | 比较视角下可见的脸部结构；只看发色或服装相同不算通过 |
| 视角与姿态 | 头和躯干是否都到位；正侧背不以只转头替代身体转面 |
| 服装连接 | 领口、肩线、开衩和带子的来路是否在新视角成立；新增背部结构与声明方案一致 |
| 左右与附件 | 同一身体侧、数量、连接点和遮挡关系；不能把画面左直接当人物左 |
| 体型与尺度 | 相近取景下头肩、躯干和四肢关系；裙下关节不可见不编造测量 |
| 表情与材质 | 表情改变不必换人，光线改变不必换材料；分别判断设计与受光变化 |
| 可用性 | 用户要求的部位实际可读、可用于下游；缩小拼板里的模糊脸需要标记不确定 |

背面任务的面容不可见，记为不适用的观察限制，不凭后脑勺宣布面部身份通过；若交付本来要求可判断面容，则这张不能满足该项。区分 `fail`、`uncertain` 和 `not_assessable`，不得自动当作通过。成组结论说明哪些视图合格、哪些待审、哪些失败，以及是否覆盖完整请求；一张漂亮图不证明整组可用。

拼板还要区分调用数、图片数与格内视图数。一张三视图是一次输出，不能当作三次独立成功；背景修订后的第二张仍是第二次输出，不凭保留三格就增加三个已验收资产。[两次拼板诊断](../../docs/character-sheet-evidence.json) 中三格版式、朝向和左臂布标关系基本成立，但比例与身份未决，背景编辑又改变内部色面，整体仍未通过。

不对称服装还要看连接与朝向：皮袋仍在右边，不代表挂点没有从侧腰滑到后腰；披片颜色正确，不代表腰下延长片仍与同一件外套连接。按实际图写衣片终点、前后包覆范围、附件袋盖朝向及与腰带的关系，别用“保持全部细节”替代空间说明。当前个案能维持左右但连接仍待审，不能将这条写成已证明能修好的提示词诀窍。

交付用户所需单图或拼板、可复制提示词，以及影响后续使用的未解决项。正式资产记录保留基准、各图目标、实际输入与输出摘要、检查结果、设计延展和版本关系。只有提示词时交付文字即可，不强制附内部记录。
