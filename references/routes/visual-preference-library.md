# 分类管理与按用途借鉴视觉偏好

2026-10-19用户明确指定的[八图妆肤与光线](reference-makeup-lighting.md)由独立主卡目录维护，属于相关设计的必须要求；不计入下文旧46项统计，也不经本路线的 prefer 投影降级。其余视觉偏好继续按本路线处理。

用于用户提供审美参考、补充满意图片、整理已有视觉偏好或从偏好库选择本轮参考。分类库不是统一脸模板，也不是新的默认题材。人物、场景、生物、衣装、呈现方式分开管理；一张图可以同时属于多个维度与合集。

## 索引和原图

[分类索引](../../resources/visual_preference_catalog.json) 是本项目的分类权威；[来源记录](../../docs/visual-preference-sources-2026-10-12.json)保留用户原话、逐图观察、上传与去重关系。源图存在项目本地 output，不随技能发布包分发。SHA绑定到原始文件内容；完全相同文件合并并保留别名，不用相貌相似、重编码或同款衣装合并来源或确认同人。未知文件摘要的外部样本独立留作指针。

用户指定一整张图为视觉偏好，不等于逐项确认观察所得的妆色、骨相、材质、服装或构图。具体属性标注 visible/partial/unknown 和观察来源，保留正常取景下的可用性边界。不能从图片推真实年龄、族群、拍摄设备或制作管线，不补造分数。旧标准化实验的 fail 只针对当时冻结目标，不能改成对原图审美的拒绝；原用户反馈和旧评审保持原记录。

当前索引包含2026-10-12两次补充的10图、此前25文件的24份RP原图、十二图历史标杆和两份外部样本记录。按精确SHA合并后46项档案，其中44项有文件摘要、34项原图在本地可核对；10项仅有历史图像摘要与观察，2项外部指针没有本地源文件。数量不代表46个不同人物。只有原24份RP关联已有肖像预设；新10图仅登记视觉偏好，不自动赋予身份权威。C09记录暖光生活近景、轻笑与蓬松发束；C10记录精细妆肤近景、眉睫唇面及局部亮光，两种呈现按用途分别选择。

## 三种分类轴

| 分类轴 | 内容 | 用法 |
| --- | --- | --- |
| 借鉴维度 | 面容、神态、妆肤、发型、服装、材料、姿态、光线、配色、构图、环境、生物、媒介，13维 | 为每个本轮需要的维度选一个主来源，逐项决定继承、适配或不使用 |
| 主题合集 | 现代时装、古风衣装、精细幻想CG、柔亮古风肖像、自然现代肖像、神态表达、暖金电影感、妆肤近景与微距、白狮幻想、荷塘柔光、蓝赭黑红绘画肖像，11组 | 多归属，快速找同类用途；不是把整图所有属性自动叠入提示词 |
| 内容与可用性 | 主体类型、题材、媒介观感、取景、源可用状态、整体反馈与RP指针 | 区分有原图、历史记录、外部指针和被拒样本；不同题材和媒介不互相覆盖 |

具体面容结构继续由[全面捏脸因素](../core/face-factor-system.md)及[人物捏脸路线](character-face-design.md)负责。偏好库的面容维度只迁移协调关系与完成方法；固定某人的脸仍使用真实原图和RP绑定，不能用新风格图取代原身份。

## 按用途形成当前选择

1. 明确本轮是新人物、人物入景、原人物保持、正面统一测脸、衣装设计还是媒介转换，再检索适用合集与维度。
2. 从正常尺寸实际查看可用原图。历史观察可作有来源的文字依据；外部指针、没有SHA或只有record_only的条目只能检索，不作为可投影主源。unknown不投影为可见保持，partial只处理实际可见部分。
3. 每个维度指定一个主来源。换主来源时替换该维度，不能自动混合两张脸或把相反暖冷灯光叠加。借鉴方法写进 transfer；可执行视觉保持条件写进 visual_limits。limits保留源不确定性、测量边界与证据说明，不机械塞入生图正文。
4. 使用 `visual-preferences.mjs select/apply` 将当前选择投影到 authored brief。所有偏好是 prefer 与非关键复查；原 must、critical、参考输入和身份权威保留。编辑必须显式给出允许通道，偏好即使只是建议也不能越出本轮范围。已有偏好派生brief不能叠加新选择，须从author brief重新构建，保留旧计划与快照。
5. 选择摘要、源摘要、观察与边界冻结在要求的审计字段里。只观察的图按文字方法使用；系统不自动将库中图片送入工具，不将整体偏好批准写成新输出的用户接受。

### 情境中的区别

暖金逆光、风中细发、紧裁切或动态构图可以是场景创作偏好；正面统一测脸则按独立的灰底、柔光和取景目标执行。portrait_standardization禁止借用库中的光线、配色、构图、姿态、环境、生物与媒介去替换测脸条件，需要改变目标时先明确另建目标。面容方向只可用于new_character；已有身份任务继续保留本人结构。

人物与白狮、环境同框时按本项目人物入景规则声明character；scene_creation允许character或scene，仍不会借用另一参考的人脸。白狮数量、体量、荷花和黑红衣饰不是通用默认。样本级拒绝只对被拒样本生效；“短发皮衣不满足需要”不变成短发、皮衣或摄影媒介的普遍禁令。

## 工具和本地预览

```text
node scripts/visual-preferences.mjs list --collection warm_cinematic
node scripts/visual-preferences.mjs list --dimension makeup --search 青粉
node scripts/visual-preferences.mjs select --input examples/visual-preference-selection.json
node scripts/visual-preferences.mjs apply --brief authored-brief.json --input selection.json --out new-brief.json
node scripts/build-visual-preference-gallery.mjs
```

网页可以筛选档案、阅读原图和按维度导出引用规划，选择只是本地计划，不修改原图、反馈或身份。导出的选择尚须经过模块校验并投影到具体brief；网页不会执行生图。缺源文件时展示历史记录；摘要不符的本地文件必须查明，不能改用同名候选。新增来源先保存原始文件并核对SHA，再观察分类、记录用户范围、检查别名及调用边界；接受或拒绝新输出仍绑定它自己的生产记录，不改旧图。
