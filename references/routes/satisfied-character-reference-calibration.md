# 本轮满意人物图的审美校准

用户于 2026-10-11 提供 A 批10个、B批15个参考文件，原话分别为“我提供一些我比较满意的人物图作为参考”“这些也是参考”。逐图来源、摘要、观察与边界见 [参考记录](../../docs/satisfied-character-references-2026-10-11.json)。本组补充此前十二图及蓝衣长发示例，不覆盖当前人物要求，也不是捏脸目录十个文字起点的原图。

A/B编号按各批上传顺序，显示名称相同仍分别定位。原文件的项目查看副本存于 `output/satisfied-character-references-2026-10-11/`，不随插件包分发。参考默认只观察，不自动作为生成输入或其他人物的身份来源；需要复刻时重新查看实际原图并分配身份权限。

## 共享完成度，独立建立面容

本组常见浅肤、黑长发、柔和椭圆轮廓与清楚眼睛，属于选样特点，不是所有人物的必选结构，也不证明每个编号代表不同身份。原创人物先写自己的颊颌体积、眉眼距离与眼形、鼻部和上下唇关系，再选妆肤与神态；已有身份对自己的参考核对辨识点。不能复制示例脸，再用头饰、发型和服装区别人物。

精致落实到本人的五官衔接、眉睫眼睑、鼻唇体积及妆肤完成度。圆颊、宽鼻、薄唇、窄眼裂、有转折的下颌和不同年龄都可有协调美感，不统一削成窄脸、大眼、高鼻、丰唇或提白。自然轻妆和浓妆各顺应自己的结构；摄影、CG与绘画使用对应的表面、明暗和边缘语言。

神态写具体视线、眼睑、眉部、唇口及面颊动作。A01/A03的轻微笑意、A04/A10的安静、B02/B07的回望、B05的画外关注、B06的凝视张力各选协调组合，不统一成闭嘴正脸或疏离。头倾、转身属于构图姿态权限；仅改眼神嘴角时不能借表情示例改头角、镜头或身体朝向。

## 发丝、受光与衣装

细发按主要五官是否可读判断。A04、B02、B03、B06中细发经过脸部，眼神与鼻唇仍可辨，支持有组织的松弛感；不为了整洁清空全部细发，也不靠满屏飞发体现生命力。关键辨识点被遮断时调整局部发束及受光，已指定刘海或身份保护要求优先。

白棚柔光、暖亮边缘、较冷自然光、胶片观感与戏剧性原画受光都可成立。选定与任务协调的一套方案，保留鼻侧、眼睑和颊颌体积；柔亮不等于整脸提白或让皮肤、金属与衣料同样高亮。图像观感不证明真实胶片、具体镜头、渲染器或三维技术。原画不强制摄影毛孔、均匀棚光或静态站姿。

衣装保持本款完整设计。A05/B11的丰富织锦、A07的密绣边条与疏花衣面、B10的黑金华服、B12的银灰细纹、B13的金属玉饰幻想造型均可满足审美。精细材料与新增装饰分别决定，不普遍清空花纹，也不将肩饰、高颈饰、开裙、珠串或腰前叠手套到所有人物。

## 证据与验收

- 面容美感、本人辨识点、妆肤、神态、媒介和衣装材料分别判断。不同原创人物共用表现方法时，在可比角度、表情与脸部尺寸下检查各自结构差异，不能只比较造型。
- 全身图检查可见头肩、轮廓、姿态和造型，长裙、宽裤、动态透视与鞋跟不提供隐藏关节或精确头身证据。近景只验可见范围；B07不能证明腰裙鞋履，B14不能证明近景微纹理或三维拓扑。
- A02与A06文件摘要一致，保留两次上传但仅算一个内容。A05与B11视觉高度相近、摘要不同，按相关图或重编码候选保守处理，不增加独立身份或稳定性证据。相近脸不直接认同人，也不为图区分强认不同人物。
- 选作审美参考不等于裁切、手指、隐藏身体或文字执行全通过。记录实际观察与用户原话，不补分；本轮没有新出图，不累计生成成功数，不回写旧评分。
