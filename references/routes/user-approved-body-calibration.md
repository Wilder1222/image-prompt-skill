# 用户已认可的身材比例校准

用于用户提供“人工核验符合要求”的身材图，及已有比例生成偏离后重新校准目标。2026-10-18 的八张正例见 [首批记录](../../docs/user-approved-body-references-2026-10-18.json)，随后十张见 [补充记录](../../docs/user-approved-body-references-2026-10-19.json)：四张原文件重复、六张新增，合计十四份不同图像。用户只确认身材比例，记录为来源图的 proportion 接受；不扩展成面容、年龄、衣装、妆发、版式或所有细节的接受，不替新输出获得认可。

## 从正例确定身体关系

首批含六张单造型多视图卡和两张各五造型的展示板，共十六个主要全身展示单元。近景与同款小转面不重复计为独立成功样本。首批八份原文件摘要各不相同；相似面容或衣装不证明同一身份、同一身体或相互独立的生成运行。人物年龄没有由用户逐张指定，不从制服、图名或脸部风格补造岁数。

| 身体关系 | 本组可见的正向目标 | 判读边界 |
| --- | --- | --- |
| 头肩与肩颈 | 全身视图内头部与肩带相称，肩线舒展，颈部顺接胸廓，头部不压住整体纵向感 | 左侧或上排放大的肖像不参与全身头身比较；发髻、帽子不当作颅顶 |
| 胸廓、腰腹与骨盆 | 上身完整而紧凑，腰部收束后自然过渡到有宽度和前后厚度的骨盆，侧面仍有躯干体积 | 紧凑不等于压扁胸廓或缩掉腹部；衣腰、腰带、短上衣边缘不等于骨点 |
| 手臂 | 肩、上臂、肘、前臂与手顺接，手臂和躯干、腿部共同协调 | 插袋、交握、屈肘和衣袖遮挡按实际投影判断，不要求手腕固定像素高度 |
| 双腿 | 相对头肩与中段有清楚的纵向延展，上下腿共同连贯，膝踝转折和鞋脚支撑自然 | 裙摆和袜口不当作髋膝；宽裤、长裙下的隐藏腿长不作精确认证 |
| 体量与承重 | 修长同时保留胸廓、腰胯和四肢的自然厚度，侧面和背面不扁塌，站姿有稳定支撑 | 这是图像内可见的体量依据，不是三维网格或生物力学测量 |
| 整体轮廓 | 正面、轻姿态时即成立的协调修长；不同衣装松量下仍保有同方向的身体观感 | 服装类别、姿态与版式会影响观感，但不能单独解释或抵消身体目标失败 |

图 4、8 的短裙、袜子和小幅姿态仍获得用户认可；图 1–5、8 的资产站姿也能成立。因此不能把被拒图的问题概括为“正面站立必然矮”“短裙或长袜导致失败”，也不能靠改成大幅扭胯、换成喇叭裤掩盖身体问题。图 3、5 的长裙和宽松上装同样获认可，表明合格目标不要求裸露腰腹、紧身衣或可见全部关节。

## 按用途选择一份主要依据

本表是代理根据可见范围做的使用建议，不是用户对八张图的排名。

| 当前要解决的问题 | 主要依据 | 补充用途 |
| --- | --- | --- |
| 现代全身的头肩、躯干与腿部关系 | 图 2 中间偏左的主要正面全身 | 肩颈、双臂、上身到腰胯的关系较清楚；牛仔裤下膝部骨点仍未知 |
| 侧面厚度、腰胯衔接 | 图 1、2 的侧面全身 | 检查正面美化后是否将躯干、骨盆削成薄片；不复制胸臀形状到不适用的人物 |
| 可见腿部与轻姿态 | 图 4、8 的主要全身；图 7 左起第一套 | 观察大腿到小腿的延展与膝踝轮廓；分别扣除裙摆、袜子和鞋履造成的视觉分段 |
| 长裙或宽松衣装 | 图 3、5 | 观察头肩、上身体量、长轮廓与落地关系，保留隐藏关节未知 |
| 多套换装与拼板 | 图 6 中排、图 7 上排，各从左到右五套 | 按套比较，底部小转面只补可辨认的轮廓；不能用其中一套代替整板审核 |

选定主要依据后，才将补充视角用于可见关系复核，不把八张同时叠加、平均出一张新身体，也不强制它们具有完全相同的头身数。用户当前的身体保持、年龄与指定体型优先；本组外观不成为所有年龄、性别或体型的统一模板。中性站立的修长方向可以迁移，具体成熟程度和身体体量须重新适配。

| 用途 | 选取依据 | 可迁移的关系与限制 |

| 古装可见肢段与侧面体量 | 补充图6（BODY-10） | 观察肩颈、胸廓腰胯、露出的腿段与侧面厚度；高发髻、金属肩饰、靴筒和鞋跟分别剥离，不用饰件外轮廓量肩宽或腿长 |
| 动作中的舒展与体块连续 | 补充图7、8（BODY-11、12） | 举臂、转身时肩胸腰胯仍连续，长衣与头发响应动作；图8有扭转、近大远小且下肢被遮挡，不把裙形当站立长腿标尺，不推断藏在衣下的支撑姿态 |

新增正例加强的是“精巧但不极端小的头部、自然舒展肩颈、完整紧凑上身、有厚度的腰胯、成组修长的四肢”这一关系。古装的长衣轮廓和现代可见腿部是不同证据，不能取各图最小的头、最窄的腰、最长的裙拼成更极端的人体；不用“再高一点、再瘦一点”逐轮累加美化。

这些来源中的倾头、侧身、垂发或相近淡妆只描述原图，不覆盖[多妆造的差异要求](portrait-look-variation.md)。选中身体来源后，在输入说明里同时指定主要全身位置与只借鉴 proportion；同一个人换妆造仍独立设计头位、手势、发型、神态与妆面。同一造型转面则保持该套设计。

## 落入本轮生产与验收

1. 分开记录用户对来源图的认可、代理观察和新任务的设计目标。对本组记录 `scope: proportion`，评分未知；正例认可不覆盖之前候选的失败，也不把旧 `reviewer_qualified` 改成用户接受。
2. 用户明确以本组作为新图身体目标时，在 proportion 通道写成具体 must 要求与 critical 检查。按 [共同身体路线](full-body-baseline.md) 建立六区目标；已有条款必须重新对照本轮目标，不能只调用补全函数后继续沿用弱描述。
3. 需要按图生成时，实际提供选中的比例来源及清楚的图内人物位置，身份另用本人物来源。复用多视图卡必须说明哪一幅全身承担身体依据，近景只承担获准的可见信息。若裁切，记录源摘要、矩形、输出摘要并保持等比；若只文字归纳，明确未传图，不声称模型已看过正例。源图仅存本地，发布包内的观察文字不等于像素输入。
4. 本人物的第一份身体候选须对所选正例检查头肩、躯干腰胯、手臂、双腿、支撑体量及整体轮廓。保持当前服装与姿态要求，必要的协调修改不能被“保持身份”误锁；比例合格后才沿用该身体方案扩展。
5. 一图多套按每套、每幅可见视图分别判断。生成前声明 `body_plan.figures` 的位置与视角，六区回执和比较分别绑定 `run_id / figure_id`；近景不计作全身成员，小转面看不清时保留未决。`body-set-review.mjs` 会拦截漏选已声明人物、遗漏分区比较及同 run 的冲突回执，不自动识别人像或判断审美。详见 [共同身体路线](full-body-baseline.md)。
6. 相似取景下比较身体内部关系，再单独判断光影、衣装、站姿和布局。未见结构继续未知；不给没有测量依据的九头身、黄金分割值、统一缩头百分比或膝位坐标。文字、文件校验和本组用户认可均不证明新规则已稳定复现。

当前分类偏好工具只有整图反馈，且没有 proportion 维度。本组以独立比例证据记录，不伪装为 whole_image 接受，也不通过 prefer 投影弱化本轮明确的身体目标。它不是已实现的新偏好 API。

按本组执行的 [2026-10-18 实图核验](../../docs/body-proportion-validation-2026-10-18.md)已有单人基准、五套换装及三视图的逐人物评审；前三份身体候选和一次手臂遮挡未决均保留。新图的代理评审合格与本组来源图的用户认可分开，不宣称所有年龄、体型或模型已稳定复现。
