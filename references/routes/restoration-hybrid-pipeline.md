# 风格恢复与资产融合流程

先按任务绑定来源：可用 A 提供风格、B 提供人物资产、C 仅提供获准神态。图序只是一个方案，实际提交顺序必须与正文一致。

1. 确定当前输出媒介、背景和动作，不能默认继承旧白底。
2. 选择必要的风格强度和真实感范围；历史 `hybrid + S2 + R2` 不覆盖本轮要求。
3. 保持母图仍有效的身份、体型、衣片、标志饰物与配色，授权改案另行列出。
4. 从风格图提取具体氛围、运动、灯位、空间与媒介表现，不整图复制。
5. 将真实感落实到精致妆面下的软组织、发束、已有材料及光线一致性。
6. 按 [冲突消解](../core/conflict-resolver-v2.md) 去除相互矛盾的锁定与变化要求。
7. 根据 [工具适配](../providers/provider-adaptation.md) 提交中文分类正文，内部强度不当作厂商参数。
8. 查看结果，分别记录人物连续性、风格不足或越界、真实感不足或抹掉媒介、统一油亮、光线失真与过量雾气，再处理失败层。

不因进入混合路线就重做所有部位，保留每次候选与真实失败记录。
