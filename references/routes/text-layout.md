# 文字与排版

用于招牌、海报、标签、包装与信息画面。实际图中文字和提示词标签是两种内容：标签帮助组织指令，画面中文字必须逐字准确。

## 编写前确定内容

记录全部需要出现的字词、标点、数字、大小写与换行。用户已给内容不改写、不添加 slogan；文字内容影响核心用途而尚未提供时才询问。多段文案分别决定主标题、说明和标签的层级，不能仅写“文字清晰”。

按用途决定位置、行数、方向、对齐、相对字号与文字区留白。字体描述采用可见特征，例如清楚的黑色无衬线汉字、适度字距；不假定供应商有指定字体或自动文本图层。文字区避免透视过斜、强反光、低对比和关键主体遮挡。产品标签随表面弯曲，但仍须完整可辨。

用户要求文字直接进入图片时，正文引用准确文本并说明位置；不能因为生图文字困难而偷偷只生成空白区。用户明确选择后期排版时，背景与文字层可分开交付，说明组合方式。生成图片不等于可编辑矢量或字体文件。

## 验收与修订

逐段、逐字核对拼写、笔画、数量、标点与行序，再检查层级、对比度、裁切和与主体关系。大意相同、看起来像汉字或装饰性伪文字都不能通过准确文本要求。内部OCR可辅助定位疑点，不代替查看原图。

一个关键字错误就保留该项失败；只修文字时冻结其他主体和版面，修改后重新检查全部文本和保护项。两轮仍未收敛时说明模型限制，提出用户可审阅的排版路线，不删除关键文字来判通过。

建议使用【画面主体】【主标题与说明】【构图与文字空间】【材质与光线】【限制与最终目标】；不同任务按实际需要组织。出图前将准确内容、可读性和版面关系分别设为关键验收。
