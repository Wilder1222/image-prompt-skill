# 人物风格选择与适配

风格决定如何表现人物，身份决定是谁，衣装决定穿什么，九头身决定身体比例。分别记录，不以换风格为由换脸、改年龄、换服装或取消 [黄金九头身](../core/fashion-proportion-system.md)。本页服务所有人物题材，不默认古装、成年女性、白底或静止站立。

## 从用户描述选择

明确指定的风格优先于参考原媒介；未指定时沿用已确认媒介。用户只说“CG”且无其他线索，按精细电影数字角色理解；只说“3D”时结合参考判断写实或风格化，仍无法判断可先按写实三维说明取舍，不让用户填模式参数。列出多种风格表示能力需求，不代表每次生成九套。

| 用户方向 | 编译选项 | 可见表现与检查重点 |
| --- | --- | --- |
| 真人、真实人物质感、摄影 | `photographic_character` | 眼睑与软组织、克制肤质、真实毛发与光学受光，妆容精致；不靠粗糙毛孔证明真实 |
| 电影级 CG、数字人 | `cinematic_cg_character` | 精细曲面、皮肤透光、毛发与电影光影统一；防止蜡皮、过度辉光和低模感 |
| 写实 3D、三维资产渲染 | `realistic_3d_character` | 空间结构、衣片厚度、附件连接、材料反射与干净资产布光 |
| 风格化 3D、动画电影造型 | `stylized_3d_character` | 概括的立体大形、雕塑发束、简化表面和柔和光影；九头身不变 |
| 三渲二、三维动漫、卡通渲染 | `anime_3d_character` | 三维体积与分层阴影、可控轮廓线结合；保持空间关系 |
| 二维动漫、赛璐璐设定 | `anime_2d_character` | 干净线稿、平涂与有限阴影层，面容头发衣料统一为绘制媒介 |
| 厚涂、绘画人物 | `painterly_character` | 色面和笔触塑造体积，焦点清楚、边缘有取舍，不继承旧案例造型 |
| 水彩插画 | `watercolor_character` | 透明色层、纸白、干湿边缘，面部和衣片连接仍清楚 |
| 水墨设色 | `ink_wash_character` | 勾线、墨色浓淡、干湿笔触与克制设色，不自动改古装或隐藏肢体 |

这是本项目对可见结果的分法，电影 CG 与写实三维可有交集，不冒称供应商有同名模型或原生参数。三维风格生成的是图像，不等于网格、骨骼、贴图或可编辑模型。原 `material_realistic_asset` 和 `dark_fantasy_asset` 保留为兼容案例；新增九类加原两类共十一条可编译路线，不代表十一种互斥艺术门类。

## 分通道编写

- **面容与妆肤**：先保留脸型、五官关系与年龄，再按媒介处理软组织、曲面、线稿或色层。风格化不自动变大眼幼脸，写实不默认加龄。二维妆面用色块表达，不强塞毛孔、角膜光学或次表面散射。
- **发型与材质**：设计保持，表现可由细发、雕塑发束或笔墨转变；二维用线条与亮形区分布、皮革和金属，三维用厚度、粗糙度和反射区分。不为展示风格新增原设计没有的材料。
- **光线与边缘**：摄影柔光、三维体积、赛璐璐阴影、厚涂虚实、水彩湿边和水墨留白不能不加区别地叠用。混合媒介须明确主媒介及各通道分工，检查整体统一。
- **身体与构图**：黄金九头身始终是硬要求，头饰、鞋跟与拖尾不计入；二维和风格化三维也保持协调头肩、胸腰臀及四肢。背景和姿态按用途处理，“电影 CG”不自动加战场，“水墨”不自动换山水背景。

照片转动漫或绘画转三维时，新媒介替换旧表现条款，身份与衣装观察保留；新细节是授权转换或设计延展，不能称原参考已有。只修手、材质或灯光时保留当前整体媒介，不顺带转换整个人物。

明确要求整体换媒介时，在开头写出本次可见转换，并同步重写相关类别：例如照片细发变为有厚度的雕塑发束、密集衣料微纹变为简洁色面与主要褶皱。保留的是发型外轮廓、衣片结构、连接与身份关系，不能同时锁死原照片的每根细丝、织纹与高光。不要只在末尾追加“风格化三维”。局部编辑仍只处理授权范围，不能借这条规则扩大修改。

平涂赛璐璐转换中，先区分指定设计与材料微纹：印花、条纹、标记、缝线和发际线可能是需保留的特征，照片颗粒、密集发丝和微织纹则可按本轮目标概括。若脸和大形已转换，仅局部材质残留照片感，可保留当前候选并针对对应表面修订，不重做整张身份或姿态。带纹理的二维作品本身不是错误，只有与本轮明确的平涂目标不符时才修；此做法目前有 [单案例两次输出](../../docs/character-anime-evidence.json) 支持局部改善，不能宣称批量稳定。

厚涂目标检查笔触是否实际塑造体积：脸部冷暖色面、成组发束、衣料主褶与肢体转折应属于同一绘画表现，不能仅在平滑写实图上覆盖画布纹理。焦点五官可细，次要部分可概括；背景遵循本轮用途，不强制添加纹理。[单案例两次厚涂输出](../../docs/character-painterly-evidence.json) 中，首次仍偏写实，第二次按部位明确重绘后媒介项通过；这支持该次修订的改善，不证明某句提示词单独有效，也不代表比例通过。

绘画转CG时，重新建立脸颈、四肢与手足的连续受光曲面，身份五官关系与衣装设计保持；原笔触边界不作为骨骼棱面锁定。皮肤、头发、布料及布光分别验收，不凭背景变干净就判整体转换完成。[两次CG诊断](../../docs/character-cinematic-cg-evidence.json) 中，局部修皮减轻了部分硬边，腕踝等处仍有残留，均未通过媒介验收。此规则是对目标和失败的澄清，尚无稳定修复成功证据，不继续重复相同措辞。

三渲二分别检查可见体积、明暗分档和轮廓：领袖裤脚的厚度、脸颌与关节转折要与阴影协调，不能只在柔光三维上添黑边。发体按原发长适配，极短发保持贴头薄体，不强套长发大束。[两次三渲二诊断](../../docs/character-anime3d-evidence.json) 中，首次偏平滑三维，第二次明确分档与轮廓后媒介项通过，比例仍失败。单幅效果可与二维绘画重叠，不能凭一张图确认生产方式，更不能声称已验证转台或动画连续性。

水彩的透明色层是画法，不自动把原不透明衣服变成薄纱；水墨的勾线与浓淡墨层也不自动要求古装、长发、山水或纯黑白。两者都按冻结目标检查人物自身的笔墨、边缘和结构，纸纹只是一项表面表现，不能单独证明媒介。[水彩与水墨各一张诊断](../../docs/character-wash-evidence.json) 中，现代衣装和身份基本保持；水彩媒介项通过，水墨的墨层组织仍待审。若表现重叠，记录不确定项，不在看到结果后增加黑色面积或留白比例门槛。

## 文生图与媒介转换

分别记录新人物文生图、已有角色换媒介和局部修复。新人物可以没有图像输入，验收其设计与风格；换媒介则保留已授权身份、发型和衣装参考，并单独验收这些内容是否延续；局部修复遵循已冻结编辑范围。三者的通过状态不互相替代，九头身始终独立检查。

当转换连续失败时，可另建无参考的新人物诊断，检查目标媒介能否成立，但不得静默丢弃用户要求保持的身份参考。[一次电影CG文生图对照](../../docs/character-cg-direct-evidence.json) 的连续曲面、肤质、毛发和衣料通过，而旧厚涂人物的两次转换仍未通过；新图九头身也待审。该结果不能证明绘画输入是唯一原因，不能当作旧人物修复成功。[完整文字示例](../../examples/character-cg-text-brief.json) 保留本次目标与关键检查，角色细节仅为案例，不成为通用默认人物。

## 身份图与风格图共同输入

同时使用人物图和另一个人的风格图时，按实际输入顺序在正文明确分工：人物图负责身份、发型和衣装；风格图只负责获准的表面、材料或受光，不自动提供五官、体型或衣服版型。参考权限是本项目的提示词与审查约束，不等同于生成接口提供独立适配器权重。先看身份是否保持，再分别审查脸颈、腕踝、毛发和衣料的媒介，不能只凭背景变平滑就通过转换。

[一次同目标双参考CG修订](../../docs/character-cg-fusion-evidence.json) 保留了原厚涂人物的可见身份与发型，衣料和背景更趋写实，踝腕仍有硬色块残留；媒介与肤质失败，九头身未决。该组合不继续重复，也不能据此宣称双参考必然有效或必然混脸；换了参考与提示词且种子未知，结果只支持本次观察。

## 编译与交付

```bash
node scripts/iteration-director.mjs asset-prompt --style-workflow photographic_character --format text
node scripts/iteration-director.mjs asset-prompt --style-workflow cinematic_cg_character --format text
node scripts/iteration-director.mjs asset-prompt --style-workflow realistic_3d_character --format text
node scripts/iteration-director.mjs asset-prompt --style-workflow stylized_3d_character --format text
node scripts/iteration-director.mjs asset-prompt --style-workflow anime_2d_character --format text
```

其他选项使用上表标识。各路线独立配置面部、妆肤、头发、材料、灯光与最终目标；输出仍为无编号中文分类正文，内部代号不进入最终提示词。明确要求英文时使用 `--language en`。权威配置见 [风格目录](../../resources/asset_style_workflows.json)，自动生成的完整正文见 [九类编译示例](../../examples/character-style-current-prompts.md)。

编译器只提供素材，不代替真实参考观察。新增路线不默认把人物设成十八至二十二岁；明确年龄写入本轮生产要求。编译器三比四白底检查构图只是示例，实际场景任务按 [生产流程](prompt-production.md) 独立撰写；新增风格不改变模型适配或参考输入能力。

不兼容的面部、细节或边缘选项会报错，避免二维线稿与照片皮肤静默并存。明确要求混合媒介时按通道撰写生产 brief，不强用单风格预设。`full_body_anchor` 保留当前媒介、不接受换风格参数；风格转换按新目标重建生产 brief，保留母图与历史输出。

目录中的常规面部表现与生成时的转换说明分开维护。电影CG的“绘画曲面按新媒介重建”只用于经授权的生成转换，不进入同媒介面部修复计划或中英文局部修复正文；局部修复仍保留CG本身的曲面、妆肤要求。不能在末尾补一句“保持媒介”来抵消前文相反的转换指令。

## 验收边界

生成前记录媒介目标，生成后检查脸、发、衣料、光影和边缘是否统一，再验身份、年龄、九头身及衣装结构。风格准确不能抵消身份或比例失败。三维检查空间厚度与连接；二维和绘画检查线条色面与关键结构，不以缺少毛孔否决二维图。

编译与回归测试只证明路线、分类输出、冲突拦截和局部编辑边界，不能证明模型出图稳定。2026-10-06 已实测真人摄影和风格化三维各两次，见 [四次实图证据](../../docs/character-style-evidence.json)。首次风格化图仍保留较多照片纹理；第二次提前具体转换并同步改写材质，发束和衣料概括改善，但身份与九头身仍待审，四张均未整体通过。这是单角色、多个提示词变量共同改变的诊断，不能证明仅靠顺序调整就稳定有效。

正式批量派生前先解决候选比例和身份的不确定项。不同风格的单张诊断可另建目标进行，保留未决项，不将诊断图称为已验收母图。旧照片和上一轮三视图不能充当新九头身规则的通过证据。

九类路线的证据分开查看。下表列代表性实测及其原冻结媒介项，不把局部通过称为整张通过，也不把后一次自动视为最佳母图。

为防止路线文档与实图记录漂移，`resources/character_style_evidence_catalog.json` 固定每条路线使用的报告和筛选条件，`node scripts/character-style-evidence-audit.mjs` 生成 [结构化覆盖审计](../../docs/character-style-evidence-audit.json)。审计只汇总真实输出数量、媒介检查、九头身检查和人工整体结论；没有逐图 `reviewer_qualified` 时，路线保持未解决，不会因媒介项通过而升级。

九条新增路线均有实图诊断，完整人物仍未通过；专项总数以 [当前状态](../../docs/current-status.md) 为准，避免与比例、表情或换装实验重复汇总。这不是九类风格的稳定性认证，图像表现不能证明存在底层可编辑三维模型。
