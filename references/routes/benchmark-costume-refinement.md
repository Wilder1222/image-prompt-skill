# 优质标杆对照与服装定妆展示

适用：用户认为旧图、独立生成图或参考图明显更好，希望查因并改进当前定妆照。实际查看标杆、失败图和最终执行提示词，分别记录观察与推断；不能只根据提示词判断画质。

## 先明确标杆能控制什么

| 角色 | 可以控制 | 不自动获得的权限 |
| --- | --- | --- |
| 审美标杆 | 构图节奏、材料层次、袖摆关系、疏密、光线；转成具体描述 | 换脸、换发色、改配色、复制整套服装 |
| 经授权的服装设计参考 | 本轮明确借鉴的服装构造、配色、材料层次与选定饰品 | 面容、年龄、发色、身体比例或未指定的发冠额饰 |
| 全身造型母图 | 该人物完整造型、比例、姿态、服装、发饰和材料关系 | 证明这些设计来自更早的半身图；自动成为其他人物的身份 |
| 身份细节参考 | 明确指定的脸部细节，主要用于母图局部不可读处 | 同时接管手势、服装或全身比例 |
| 当前编辑图 | 本轮直接编辑对象 | 自动覆盖用户更喜欢的旧母图 |

每个属性只给一个主来源。如果用户只是说「效果更好」，先将图片当作审美标杆；要直接保留这张人物和衣服时再在本轮记录中写明它是全身母图。原图保留，生成候选不能覆盖或自动升级为已验收母图。

用户进一步允许服装与造型适度优化时，标杆可以指导具体造型方案：在同一人物身上重新组织衣片、腰部、花饰疏密、配色占比和姿态。不再把原图可见服装当作不可改变的结构；保留人物辨识度并写明再设计即可。此授权不等于要求与原图逐项一致，评价时区分“有意改善”与“模型未按所写方案执行”。例如设计稿指定两条龙但输出四个龙首仍是执行偏差，换成长裙则可能是已授权的造型选择。

若仅靠文字无法充分传递具体衣装结构，可将指定标杆作为服装设计参考实际输入，采用 [Identity A / Wardrobe B 权限](../core/reference-authority-matrix-v080.md)。先说明图序与职责，再保留本轮具体改案；不要直接把标杆升为整个人物母图。加入视觉参考可能同时带来更贴近的层次和多余饰物，属于需实图验证的可选方式，不默认优于原图加文字。

## 分开选择用途

- **中性资产检查**：复用既有 `neutral_asset`，服装结构和姿态由实际任务决定。自然垂手只是可选姿态。
- **服装定妆展示**：`costume_showcase` 仅供流动袖摆与长裙层次的造型参考。具体站姿和手势按需求选择，腰前叠手只是其中一种；见 [站姿决策](../core/standing-pose-direction.md)。腰部收束和前中长线维持修长感，裙摆可以适量展开和铺地，允许自然遮住一脚或双脚，不强制鞋尖可见。
- **已有好母图**：直接保留最省损失。只有用户要求出图或有明确待修处时才生成候选；使用 `full_body_anchor` 保留全身设计，或者使用具体 编辑阶段与焦点 修局部。不要为了走完流程重做脸、年龄和身材。

```bash
node scripts/iteration-director.mjs asset-prompt --presentation costume_showcase --maturity-guard none --format text
node scripts/iteration-director.mjs asset-prompt --reference-mode full_body_anchor --format text
node scripts/iteration-director.mjs asset-prompt --stage structure --focus hands --passed fashion_asset_proportion,asset_framing --format text
```

`full_body_anchor` 是保留式生成文本，不是批准记录；与脸、手、年龄、比例或展示型预设的显式覆盖冲突时会报错。要改变其中一项，用有范围的编辑，而非混入相互矛盾的保留和重做指令。

## 从图中写出构造，避免形容词堆叠

1. 写脸部方向与参考辨识度，不用另一个角色的「统一美人脸」。精致柔和的风格不必被最大真人感替代。
2. 写颈肩、腰位、手臂与袖布的支撑关系，保留完整躯干，避免靠缩头、拉腿制造修长。
3. 按这套衣服实际存在的主层、外层、内层写出轮廓与长短。不是每套衣服都有薄纱或复杂腰封。
4. 写主锦如何垂、薄纱在哪里重叠、内裙哪里较哑光、花纹在哪里集中。增加材料层次不等于给全部面料加金纹。
5. 半身扩全身先列出设计延展。没有明确设计目标时仍应克制；用户明确希望更丰富的层次时，可给出具体扩展方案，不能称其为原图可见事实。
6. 负向约束只针对实际风险。避免同时要求宽袖、收窄全部轮廓、复杂长裙、双鞋完全露出等互相挤压的目标。

深色长装若出现大块沉重裙面，先看素面区域的形状与占比，再决定是否减少花纹。黑金实测中，窄前中片、错落黑色侧片和间歇露出的象牙白内层比一整块宽黑前裙更有层次；这是该套造型的组合改案，不是所有长裙都必须加白色开衩。相关案例不作为通用配方。

## 用实际结果决定下一轮

至少保留原始基线、标杆、最终提示词、图像输入列表和输出图，逐项比较：脸的方向与辨识度、颈肩腰连贯性、袖摆轮廓、长衣片、材料厚薄、可见手部、完整取景和落地。对遮挡项记 `not_assessable`。

把两类证据分开：同一半身输入加新提示词，能显示这套提示词的一个实际样本；加入全身母图，则检验额外视觉约束下的保持能力。模型、种子或参数不可得时明确写未知；单次结果不能归因全部变量，也不能证明稳定性。

每次测试保存实际发送的完整提示词，不能只保存通用模板而漏掉追加的服装方案。材质扩展规则和局部修复规则分别评估；先保留原图、补全方案和其他条款，仅替换一个规则，再查看输出。数值留白、更多否定词或更长提示词不自动视为改进；没有实际改善就撤回，并记录这次失败。除华服样本外，用素衣、针织或铠甲检查是否发生风格同质化。原图中的闭唇与露齿、表情强度也是身份连续性的可见检查项。

在 [回归记录模板](../../templates/benchmark-comparison-record.json) 中记录观察者判断与用户验收两个独立状态。看起来更丰富也可能带来脸部漂移、袖口粘连、花纹过密或裙摆失重；如有退步，以用户标杆为上限保护，保留原图，只修明确问题。
