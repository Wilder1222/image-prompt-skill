# 肖像扩身与共同全身体型基准

用于同人肖像扩身、连续换装与成组全身资产。近景、不同人物独立设计和窄范围局部编辑不自动套用。比例方向仍按 [年龄与指定体型](../core/fashion-proportion-system.md) 决定；本路线补足共同身体来源和证据，不新增统一九头身。

## 身体来源与派生顺序

头肩肖像只提供可见身份与头颈肩依据，不提供隐藏的腰腹、骨盆和腿部比例。每套重复“修长协调”不会建立共同身体。首次扩身将未见部分标为设计延展，具体确定头肩、胸廓腰腹骨盆、上下臂、上下腿、支撑体积及整体轮廓。

有同人物、同年龄体型且实际评审合格的全身图就复用；没有时，先检查请求中的第一张代表性全身候选，作为候选基准。不默认在用户数量外增加标尺图、裸体图或多视图。基准有关键比例问题时先修；若用户要求继续批量，可以保留候选，但不能称为已认可身体资产组。代理选定测试基准和用户接受分别记录。

| 来源 | 权限与边界 |
| --- | --- |
| 身份肖像 | 稳定五官、表观年龄与身份；发型妆容神态按授权变化，不将刘海或分缝自动锁成身份 |
| 已检查全身基准 | 身体尺度、体量与共同身体方案；不自动冻结基准图的衣装、发型和姿态 |
| 每套衣服鞋包素材 | 对应衣片、材质、配色和穿着连接；不借用模特、人台的脸和身材 |

后续每套实际送入同一身体基准，记输入顺序和摘要，正文引用 proportion 观察；原肖像可继续提供 identity，身体图单独提供 proportion，避免无意混脸。入口不能容纳这些输入时明确限制，调整可执行方案，不能仅在文字中声称引用未传入的图。普通参考图不等于骨架、深度或参数锁定，出图后仍需核对。

换装时头肩尺度、躯干与四肢关系及体量保持同一方案。衣服高腰、外套下摆、蓬袖、喇叭裤、发顶和厚底鞋影响观感，不能直接作为人体腰位、关节或头身测量端点。保留自然遮挡，不为证明比例掀裙、紧身化或改变指定衣长。

## 分区目标和证据

“没有明显畸形、没有纸片腰、站得住”只支持部分结构判断；审美通过还要说明身体关系怎样达到年龄、体型与修长方向。生成前用 `scripts/body-proportion-contract.mjs` 的 `withBodyRegionChecks(brief, {targets})` 添加六项必须目标、正文与关键验收：

| targets 键 | 代理必须针对本人物填写的关系 |
| --- | --- |
| head_shoulders | 头肩与肩颈 |
| torso_pelvis | 胸廓、腰腹和骨盆 |
| arms | 上下臂、肘腕和手 |
| legs | 上下腿、膝踝和足 |
| support | 肌肉软组织与承重 |
| silhouette | 年龄、指定体型与整体修长感 |

目标只要求当前衣装和姿态能判断的关系，不预设衣下关节必可测。不能把一段泛称复制六次。函数不观察图片、不自动选择体型、不允许窄范围编辑新增全身设计。

每项回执除原有 `evidence` 外，增加 `body_observation`：

- `visibility`：`visible / partial / not_visible`，指冻结目标的可判断程度，不指人物是否裸露。
- `visible_relation`：本图本部位实际可见的结构、轮廓或受力，说明衣装与透视干扰。
- `target_comparison`：观察相对本轮目标的符合、偏离或未知；“整体自然”不能替代具体比较。

只部分可判断时用 `uncertain` 或 `not_assessable`，不能以 pass 认证未见结构；可见明显偏离用 fail。程序检查字段和同图重复证据，不会辨认一句具体描述是否真实。必须实际看图，也不能简单改写同义词绕过重复提示。

## 整组复核

逐套对共同基准比较六个区域。分开判断取景远近、鞋跟、发型体积、衣装轮廓、透视缩短和真实身体变化，不直接比较画面绝对像素高度。每张通过不代表整组一致。

调用 `node scripts/body-set-review.mjs --input review.json`，输入字段为：

- `expected_ids`：本次要交付的成员 ID 数组，用于发现漏图。
- `baseline`：包含实际冻结记录 `snapshot` 路径及完成回执 `receipt` 路径。
- `members`：每项含成员 `id` 和该成员的 `snapshot / receipt` 路径。请求中的第一张可以同时作为 baseline 和一个成员，使用同一快照与回执；它无需与自己比较，不重复算独立观察。
- `comparisons`：每项绑定成员实际 `run_id`，其 `regions` 数组逐项包含 `region / verdict / evidence / body_observation`。这里的 target_comparison 对照共同基准。
- `rejections`：可选数组，每项为被用户否定的实际 `run_id` 与原话 `evidence`，工具会绑定对应输出摘要。

基准和每张成片都须在生成前冻结六项检查。工具验证实际文件、同一身份来源、同一身体目标及实际传入的基准摘要；不允许只引用肖像或改了身体方案仍称同一基准。改方案另建版本。漏图、漏比较、不确定和跨图复用通过证据返回 needs_review；关键失败、用户否定或复用同一输出冒充多套交付返回 needs_revision。重复证据只是复核提示，不直接证明图坏。

基准被否定后，整组不能继续以其资格作为通过依据。旧回执保留，不能事后补标签制造新契约通过；原始记录缺失时只作对话分析。工具不自动测量人体、不认证语义和几何控制，也不认定用户接受。

修鞋、修发等局部通过不能重新认证全身。作为新全身成员时重新观察完整身体与保护范围；原有未决比例不因局部成功而消失。相关 [对话分析](../../docs/full-body-conversation-analysis-2026-10-18.md) 尚未取得五套成片和原始回执，不构成新规则的实图成功证据。
