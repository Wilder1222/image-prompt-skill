# 肖像扩身与共同全身体型基准

用于同人肖像扩身、连续换装与成组全身资产。近景、不同人物独立设计和窄范围局部编辑不自动套用。比例方向仍按 [年龄与指定体型](../core/fashion-proportion-system.md) 决定；本路线补足共同身体来源和证据，不新增统一九头身。

## 身体来源与派生顺序

头肩肖像只提供可见身份与头颈肩依据，不提供隐藏的腰腹、骨盆和腿部比例。每套重复“修长协调”不会建立共同身体。首次扩身将未见部分标为设计延展，具体确定头肩、胸廓腰腹骨盆、上下臂、上下腿、支撑体积及整体轮廓。

有用户已人工认可的身材正例时，先按 [正例校准](user-approved-body-calibration.md) 选定本次用途的主依据，首张候选必须对照它成立，不能仅因无畸形、完整入画或是最先生成就成为合格基准。正例中的身份、衣装和版式不随身体目标自动继承；只有来源人物与本人物明确对应时才可进一步判断能否复用为同人身体来源。

有同人物、同年龄体型且实际评审合格的全身图就复用；没有时，先检查请求中的第一张代表性全身候选，作为候选基准。不默认在用户数量外增加标尺图、裸体图或多视图。基准有关键比例问题时先修；若用户要求继续批量，可以保留候选，但不能称为已认可身体资产组。代理选定测试基准和用户接受分别记录。

| 来源 | 权限与边界 |
| --- | --- |
| 身份肖像 | 稳定五官、表观年龄与身份；发型妆容神态按授权变化，不将刘海或分缝自动锁成身份 |
| 已检查全身基准 | 身体尺度、体量与共同身体方案；不自动冻结基准图的衣装、发型和姿态 |
| 用户指定的外部比例标杆 | 仅提供可见头身、躯干与肢段的审美关系；不提供本人物身份，不直接算同人全身基准 |
| 每套衣服鞋包素材 | 对应衣片、材质、配色和穿着连接；不借用模特、人台的脸和身材 |

用户否定旧全身比例并给出新标杆时，旧图仍可提供身份和衣装，但撤去其身体尺度权威。以外部标杆的可见关系重建候选，将标杆实际列入 proportion 输入；新候选经身份、衣装和六区评审后才可成为本人物身体基准。不能因为标杆身材受偏好就宣称其整张图、五官、服装或姿态也获认可。实际传图不保证参考被模型执行，仍需比较成片。

若旧全身图实际进入生成后持续牵引错误比例，仅修改权限文字或调换输入顺序可能不够。改用只含可见头颈肩的身份输入，分别提供比例标杆与服装来源，使生成入口不再收到被否定的全身轮廓。优先复用已有身份近景；实际裁切需记录原图、区域与新文件摘要。若通过图像生成制作近景，它是可能漂移的派生图，必须记录其生成来源，不能声称无损裁切，最终仍对原身份检查。仅为这一已诊断的问题制作必要中间素材，不给所有任务默认增加出图次数。

重建候选已有改善后，再以该候选作单一编辑起点，明确完整头部、胸廓腰腹骨盆及上下腿需要怎样联动。必要的相对调整幅度只作本张设计指引，出图后按可见关系复核，不升级为通用缩头百分比或所有年龄的头身公式。头部缩放时保护五官内部几何，颈部、肩带、手臂和衣料共同协调。细化时继续保护服装材质与松量，不把针织变牛仔、紧身化或改变姿势当成身体改善。一次候选通过只支持该图，不证明后续批量稳定。

候选的面部已对原身份核验时，可让该完整候选承担下一次编辑的实际身份与编辑基准输入，减少不必要的大肖像、多视图卡同时参与；仍在生成后回看原身份，不能把输入减少解释为自动保持。用稳定 `identity_target_id` 与真实 parent 记录来源连续性；原身份目标未声明该标识时，新来源会被记录为目标变化，不篡改旧快照。连续两轮没有明确改善应换控制策略，而不是再叠加同义词。[本轮实图记录](../../docs/body-proportion-validation-2026-10-18.md)保留了失败、组合校准与逐格修订，不能据单次组合变化推断是哪一句话独立有效。

后续每套实际送入同一身体基准，记输入顺序和摘要，正文引用 proportion 观察；原肖像可继续提供 identity，身体图单独提供 proportion，避免无意混脸。入口不能容纳这些输入时明确限制，调整可执行方案，不能仅在文字中声称引用未传入的图。普通参考图不等于骨架、深度或参数锁定，出图后仍需核对。

换装时头肩尺度、躯干与四肢关系及体量保持同一方案。衣服高腰、外套下摆、蓬袖、喇叭裤、发顶和厚底鞋影响观感，不能直接作为人体腰位、关节或头身测量端点。保留自然遮挡，不为证明比例掀裙、紧身化或改变指定衣长。

## 分区目标和证据

“没有明显畸形、没有纸片腰、站得住”只支持部分结构判断；审美通过还要说明身体关系怎样达到年龄、体型与修长方向。所有新全身生产在生成前用 `scripts/body-proportion-contract.mjs` 的 `withBodyRegionChecks(brief, {targets, figures, baselineReferenceId})` 添加身体方案、正文与逐人物关键验收：

| targets 键 | 代理必须针对本人物填写的关系 |
| --- | --- |
| head_shoulders | 头肩与肩颈 |
| torso_pelvis | 胸廓、腰腹和骨盆 |
| arms | 上下臂、肘腕和手 |
| legs | 上下腿、膝踝和足 |
| support | 肌肉软组织与承重 |
| silhouette | 年龄、指定体型与整体修长感 |

目标只要求当前衣装和姿态能判断的关系，不预设衣下关节必可测。不能把一段泛称复制六次。函数不观察图片、不自动选择体型、不允许窄范围编辑新增全身设计。

`figures` 默认是单人正面；多套或多视图时必须显式传入每个全身的 `{id, view, locator}`，view 为 `front / side / back / three_quarter`，locator 写“左起第二套正面全身”等唯一可见位置。函数生成 `body_plan.framing: full_body`、每人六区 `figure_id` 检查和整图数量/位置检查；近景不列入 figures。已有身体方案的局部编辑继续带全套冻结检查，不重新调用补全函数扩大范围。`baselineReferenceId` 指向实际传入且具有 proportion 权限的来源；整组派生仍须由下述工具验证它确为合格的本人物基准。

同图共享六条身体目标，不为五个人把同一段身体正文重复五遍。声明位置不等于自动检测人物：代理要看整图数量、位置、每幅全身是否完整，不能漏声明人物后冒充完整覆盖。旧的无 body_plan 快照保持历史兼容；编译器不靠关键词自动识别未声明的全身。

例如穿宽松裤装时，可冻结“腰胯到裤腿的可见体量收放、腿部轮廓相对躯干的延展、鞋脚落地”，不同时要求精确隐藏膝位通过。`visibility: visible` 仅表示这一已冻结目标可判断，不代表衣下人体全可见。若前一版本冻结了更强的隐藏结构目标，不能事后改成可见目标来改判旧图；另建目标版本并保留旧未决。

每项回执除原有 `evidence` 外，增加 `body_observation`：

- `visibility`：`visible / partial / not_visible`，指冻结目标的可判断程度，不指人物是否裸露。
- `visible_relation`：本图本部位实际可见的结构、轮廓或受力，说明衣装与透视干扰。
- `target_comparison`：观察相对本轮目标的符合、偏离或未知；“整体自然”不能替代具体比较。

只部分可判断时用 `uncertain` 或 `not_assessable`，不能以 pass 认证未见结构；可见明显偏离用 fail。程序检查字段和同图重复证据，不会辨认一句具体描述是否真实。必须实际看图，也不能简单改写同义词绕过重复提示。

## 整组复核

逐套对共同基准比较六个区域。分开判断取景远近、鞋跟、发型体积、衣装轮廓、透视缩短和真实身体变化，不直接比较画面绝对像素高度。每张通过不代表整组一致。

一张图内含多套或多视图时，先逐格绑定造型与视图；大肖像和重复小转面不算独立身体成功。工具以 `(run_id, figure_id)` 绑定成员，同一张实际图片可以有多个已冻结人物，但每人的六区回执和对基准比较都必须齐全；漏选已声明人物返回 `missing_figures`。图内绑定是人工定位与证据契约，不是检测框、裁切、自动人体识别或几何控制。

调用 `node scripts/body-set-review.mjs --input review.json`，输入字段为：

- `expected_ids`：本次要交付的成员 ID 数组，用于发现漏图。
- `baseline`：包含实际冻结记录 `snapshot` 路径及完成回执 `receipt` 路径，当前必须是单个完整人物的已审图，不能把多人物板冒充单人身体基准。
- `members`：每项含成员 `id`、`snapshot / receipt` 路径及图内 `figure_id`。只有单人物快照可以省略 figure_id。请求中的第一张可以同时作为 baseline 和一个成员，使用同一快照与回执；它无需与自己比较，不重复算独立观察。
- `comparisons`：每项绑定实际 `run_id / figure_id`，其 `regions` 数组逐项包含 `region / verdict / evidence / body_observation`。这里的 target_comparison 对照共同基准，不能用其他人物的比较替代。
- `rejections`：可选数组，每项为被用户否定的实际 `run_id`、可选 `figure_id` 与原话 `evidence`，工具会绑定对应输出摘要。无 figure_id 表示整张被否定。

基准和每张成片都须在生成前冻结六项检查。工具验证实际文件、同一身份来源、同一身体目标及实际传入的基准摘要；不允许只引用肖像或改了身体方案仍称同一基准。改方案另建版本。漏图、漏比较、不确定和跨图复用通过证据返回 needs_review；关键失败、用户否定或复用同一输出冒充多套交付返回 needs_revision。重复证据只是复核提示，不直接证明图坏。

基准被否定后，整组不能继续以其资格作为通过依据。旧回执保留，不能事后补标签制造新契约通过；原始记录缺失时只作对话分析。工具不自动测量人体、不认证语义和几何控制，也不认定用户接受。

修鞋、修发等局部通过不能重新认证全身。作为新全身成员时重新观察完整身体与保护范围；原有未决比例不因局部成功而消失。相关 [对话分析](../../docs/full-body-conversation-analysis-2026-10-18.md) 尚未取得五套成片和原始回执，不构成新规则的实图成功证据。
