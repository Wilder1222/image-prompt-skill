# 面容气质校准流程

用于用户明确表示幼态过强、气质不合适，或要求借鉴另一图的神态与妆容，同时保留原人物的任务。没有此问题时不自动运行。兼容轮次标识为 `trait_calibration`。

可调整指定成熟感、视线稳定度、表情强度、眼睑开合、面颊柔和程度的表现和妆容。保留人物稳定面容、表观年龄、发型方向、身体、服装、构图和背景。不能复制气质图的五官，也不能通过改变体型、衣装或添加衰老迹象制造成熟。

## 兼容规划命令与具体目标

`trait-plan --level <级别>` 读取气质目录中该档独立的中文表现说明，不把所有目标套成“收窄眼睑、削减面颊、更加克制”。级别仅用于内部选择，生产正文写可见动作，不输出级别代号。

| 兼容级别 | 表现方向 | 保持的边界 |
| --- | --- | --- |
| M0 | 明亮活泼、眉眼舒展、目光有回应 | 不放大眼睛，不改变年龄 |
| M1 | 清新温和、眼睑舒展、唇部放松 | 不削瘦面颊，不统一甜笑 |
| M2 | 自然沉稳、眉眼嘴角松紧适度 | 不把平静变成固定冷脸 |
| M2.5 | 从容精致，按实际问题收敛过强表演或妆面 | 不以凹颊、拉长脸或新增皱纹制造轻熟 |
| M3 | 冷静疏离，表情幅度较小 | 不自动增加疲态、悲苦或改变年龄 |
| M4 | 坚定有主见，注视与眉眼张力明确 | 不靠加宽下颌、削薄脸颊或怒视替代 |

这些是兼容案例的表现素材，不是六种年龄、六个固定脸型或情绪控制参数。保留原人物已有的年龄特征；目录中不添加衰老的设置，不表示要擦掉原有皱褶或灰发。唇部和颌面结构的保护指稳定设计，允许获准表情所需的自然运动。妆容变化只适用于原角色确有的妆面，不能给所有人物加相同彩妆；媒介继续沿用原任务。

输出为 `scaffold_only`，没有实际看图或出图证据。A、B 是参考角色占位，不证明本轮已提供两张图；没有气质参考时直接依据用户文字目标编写。实际生产按 [提示词流程](prompt-production.md) 观察输入、选取与当前差异有关的变化并冻结验收，不自动运行六档。此局部计划保持身体，本轮明确的比例未决项仍需独立处理，表情通过不代表完整人物合格。

按实际输入图序说明：A 是直接编辑母图与身份来源；B 只作为气质参考。若使用独立身份照，按 [参考角色分配](../core/reference-role-resolver.md) 明确三图关系。级别是内部设计摘要，正文应落实为具体可见变化。

按【编辑对象】【保留范围】【表情与妆容变化】【参考借用边界】组织中文正文。用三至五条有效变化说明目标，不堆通用负面词。

以下仅为明确要求年轻轻熟的案例：

> 【编辑对象】编辑图 A，图 B 仅供神态与妆容方向参考。
> 【保留范围】保留图 A 的脸型、眼距、眼形核心、鼻唇和下颌辨识关系，以及原年龄、衣装和取景。
> 【表情与妆容变化】眼神更稳定，眉眼与嘴角张力自然，妆面精致协调，减少导致幼态的过强腮红或光泽。保持年轻柔和的面颊，不凹陷削瘦。
> 【参考借用边界】不复制图 B 的五官、头发、衣服、场景、光线或调色。不拉长面部，不缩窄鼻颌，不增加年龄。

生成后分别检查表情是否达成、身份是否保持、原有合格项是否漂移。参考本身不清楚或差异受视角影响时保留待审，不反复重塑脸部。

局部气质修订也检查非面部区域，尤其是已约定保持的衣褶、纹理与颈部受光；衣服仍同款同色不等于表面保持。[年长男性单次诊断](../../docs/character-trait-senior-evidence.json) 中，温和闭口微笑与年长观感可同时成立，但胸腹衣褶及部分表面被重绘，编辑保护项失败，九头身也仍失败。因此只记录该次表情的局部改善，不宣布六档稳定、不算原三维目标修复，也不反复追加“其余不变”重试。
