# 原图绑定肖像的标准化修订

用于用户明确要求中性光、正面肖像对照，并修正该目标下的失败项。若当前要求在原图任务与风格基础上统一标准化，使用[风格保持路线](style-preserving-standardization.md)，不将原暖逆光、倾头、有意紧裁切或场景主体当作自动失败。先逐张看唯一原图、旧候选和旧评审，制作修订矩阵；保留旧文件、目标、哈希、失败与未知项。原图始终是RP身份来源，候选只是展示或编辑对象。

## 修订矩阵

每项记录原图/旧图SHA、实际可见身份组合、来源可判断程度、确切失败/存疑检查ID与证据、对应修订动作、保护范围以及修图不能解除的未知。完全相同文件合并，视觉相近但不同文件不擅自合并，也不宣称文件数等于不同人物数。

| 问题 | 标准化动作 | 必须同时保护 |
| --- | --- | --- |
| 对照目标要求完整头饰，候选裁切或余量不足 | 扩大背景和放松取景，明确已见最高主发束/饰件及上边界之间的连续背景；有意微距不套用 | 发量、盘束、原饰件设计、脸部与头肩相对关系，不靠剪发或缩头解决，不补未知完整冠饰 |
| 明确正面对照目标下倾头或视点不一致 | 调整整个头部与取景方向，按本轮统一正面目标处理 | 原自然不对称与表情，不分别重画两眼/眉毛凑水平 |
| 对照目标指定肩上近景，候选躯干占比过多 | 明确本轮画面下缘及可见肩上范围；半身或环境人物任务不套用 | 不换衣领、不拉颈，不把新显露固定点记为源事实 |
| 明确中性光对照目标下强暖逆光或受光不一致 | 指定中性正面柔光、补齐较暗侧并降低强方向亮缘；保留原任务风格时沿用原暖光方向与空气感 | 原基础肤色、妆色、鼻颊体积和媒介，不以磨平骨相实现均匀 |
| CG/绘画被换成照片或模板脸 | 恢复该原图自己的面容与媒介完成方式 | 自己的五官组合及年龄观感；精细度不等于照片化 |
| 补出原图不存在的饰件、痣或妆饰 | 移除新增项，恢复实际来源组合 | 已存在的局部原细节，不能增加标记强行造辨识度 |
| 小脸、遮挡或未见侧面 | 仅核对实际可见组合，继续标未知/不可判断 | 新生成近景不能倒推原图已提供全部三维结构 |

## 选择实际输入路线

候选与原图双输入路线：上一候选是编辑基准，原图唯一identity；候选authority必须为空。工具实际送入两图，图序按冻结actual_inputs核对，不能依赖修订矩阵原计划。可以用[面容复查计划](../../scripts/face-review-plan.mjs)冻结选定因素、允许变化、保护与未知视角。

单原图路线：直接编辑唯一原图，旧候选只用于比较而不送入工具；edit_scope基准也为原图。若双输入产生额外妆饰或面容混合，不继续使用该结果。单输入不得宣称执行了双输入复查计划；用现有生产契约单独冻结其真实正文、输入及检查。

两条路线都不允许以生成候选替换RP身份来源。修改输入路线、目标留量或基准另建快照，明确goal_changed与实际派发；只准备而未调用的计划单列not_started，不计生成图片。

## 先试产，再展开

先选择一至两张源脸清楚的代表图测试策略。正文突出本次具体变化和原人物保持，减少重复的外观形容词；避免用不存在的装饰词提示模型追加新妆造。明确留白与裁切的画面关系，构图不是人体结构参数或游戏滑杆。

逐张检查原/旧/新三图，先查肖像与保护项，再查本次标准化。脸或妆发退步时不因新灰底、光线或留白通过而选择新图。可以从原图重试另一输入路线，失败记录保留。同一问题连续两轮没有改善时保留较好候选，停止该路径；不能无限重画或改低标准使其通过。

## 分开报告结果

标准化状态：单列视点、完整留白、可见范围、背景、受光、原媒介的检查结果。通过只说明这些呈现目标成立。

肖像状态：按原图实际可见五官、肤色年龄观感与个体组合记录pass/fail/uncertain/not_assessable；不以发冠或衣装一致作为肖像证明。

来源可判断程度：小脸、遮挡、侧面缺失及不清楚衣领固定点独立保留。即便标准化通过，来源未知也不自动消失。

完整编辑保护与用户接受另列。最终预览可以显示改进版，但失败或有退步时保留旧候选；所有版本均可对照，原图身份位置不动。不会将‘已生成’改写为‘已通过’，也不会将‘仍不确定’全部显示成可修图解决的问题。
