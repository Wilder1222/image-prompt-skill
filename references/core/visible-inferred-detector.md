# 可见事实与未知信息

## 为什么需要

“严格保持参考图服装”只有在参考图真正展示该部位时才成立。半身图无法严格锁定鞋履、完整裙摆、背面和腰部以下结构。

## 四种证据状态

### 清楚可见 `visible`
参考图清楚显示该属性。

可以：
> 严格保持参考图可见的领型、胸前装饰和袖口结构。

### 部分可见 `partial`（兼容旧称 `partially_visible`）
只能确认一部分。

应该：
> 保持参考图已显示的袖口和上臂结构；未显示的下部自然延展。

### 未展示 `not_visible`
参考图没有展示。

禁止：
> 严格保持参考图中的鞋履。

改为：
> 鞋履根据已可见服装设计语言自然补全，不引入新的核心设计元素。

### 无法判断 `unknown`
画面分辨率、遮挡或信息不足，无法判断。

不做强锁，不冒充观察。

## 来源标签

每个设计事实还应标记：

- observed：真实看见
- inferred：从已见结构合理推断
- designed_extension：用户授权的设计延展
- user_locked：用户明确指定

## 锁定规则

`strict_lock` 仅允许：
- visible + role_authorized
- partial 的可见子范围（生产 JSON 使用 `partial`，旧称 partially_visible）
- user_locked

`not_visible + observed` 属于逻辑错误。

## 典型半身图

可锁：
- 五官
- 发型可见部分
- 领型
- 胸前装饰
- 肩袖上段
- 刺绣风格
- 可见材料体系

不可冒充锁定：
- 腰带完整设计
- 腰部以下层次
- 整体裙摆
- 腿部开衩
- 鞋履
- 背面
