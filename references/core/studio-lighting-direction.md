# 白底定妆的摄影布光

仅在选择白底定妆或明确要求摄影棚布光时使用；服装采集、角色资产本身不强制白底。先按 [背景与环境适配](background-direction.md) 决定背景。保留或调整场景时以场景照明和用户意图为准，不自动清除合理的环境色与光效。用户明确指定的特殊光效优先。参考的脸、发型与衣装是设计依据，原场景投影和色染不自动成为身份保留项。

## 灯光决定

- 主光为靠近镜头轴线、略高于视线的大面积扩散光源；适度偏向一侧可以保留体积，不能造成一边脸明显变暗。
- 用充分、宽而柔的正面补光照亮额头、眼周和两侧脸颊。不要把“弱补光、强对比”写成白底定妆默认值。
- 中性白平衡，肤色与衣装主色不继承夕阳橙黄或混合环境色染。保留化妆、唇色与正常肤色差异，不把红润一律抹掉。
- 去除树叶、窗框等图案投影与斑驳亮块；碎发本身保留，脸上不保留其锐利条状硬阴影。头发遮挡处可有轻微柔和接触暗部。
- 均匀曝光不等于完全无阴影：眼窝、鼻下、下颌有低对比、宽而连续的渐变，皮肤保留细微纹理与分区反射。不要用磨皮、漂白、改鼻梁或加高光斑代替补光。
- 衣料与金属保留材料各自的反射；白衣边缘不溢出，背景均匀洁白，脚下只留柔和接地阴影。
- 此处是布光逻辑，不是更换媒介。指定厚涂时仍保留笔触和选择性边缘；指定真人质感时采用自然摄影皮肤与材料。

## 编写与局部修复

在中文【背景与灯光】中写明确的光源大小、相对位置、补光作用、白平衡和待移除的环境光，而不是只有“高级棚拍”。仅修灯光时，使用【编辑对象】【摄影灯光调整】【保持不变】【输出】等语义标签，只允许照明、其造成的色染与投影变化，保留人物、表情、造型、站姿、身体比例及衣装本色，不能同时锁定旧灯光。用户同时允许发型适配时，单列【发型与面部展示】说明可收拢的碎发、分缝和束发位置，不再把全部原发丝列为锁定项；检查遮挡减少与光线改善是否都成立。

## 验收

背景和脸部布光分开检查。看整幅接地与衣料，再放大检查额头、双眼、鼻梁、双颊和下颌：没有不必要的硬条影或明暗碎块，双方脸颊曝光协调，五官仍有软体积，原有辨识点没有被重绘成另一张脸。局部修复还要比较姿态、服装和比例是否退步。记录用户反馈，不用此前观察者通过覆盖用户提出的新问题。
