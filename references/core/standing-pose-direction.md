# 按意图设计站姿

仅在本轮选定站立姿态时使用，可按主体调整。动作的上级入口是 [动作与生命感](action-direction.md)，支持坐、倚、行走、跳跃、旋舞及夸张动作；下列静态站姿注意点不作为其他动作的限制。以下是选择与描述站姿的知识，不是要求用户挑选的模板。具体描述或姿态参考优先；未列出的站姿仍按身体关系拆解。

## 决策顺序

1. **先确定用途与朝向**：正面服装采集强调领胸、腰线、袖型和裙片可读；自然形象照允许重心偏移；时装或角色气质可用更鲜明的姿态。身体朝向、头部朝向、视线分别写清。用户只要求正面时不擅自转成三分之四侧身；指定侧身时也不叠加“头肩骨盆全部正面”。
2. **确定承重与下肢关系**：重心主要在哪条腿、另一条腿怎样放松、脚的前后间距与落地关系。保持自然平衡，不用拧腰、缩头或抬高腰线制造修长。左右有要求时统一指人物自身左右。
3. **确定上身与手的动作**：肩颈松紧、胸廓与骨盆关系、手落点和手肘空间服务人物气质。双手交叠、下垂、扶腰、轻搭腕部、插袋、持物或微张都可支持，但须有衣服结构或道具依据，不把所有人固定成同一动作。
4. **推导服装与可见范围**：衣片随站姿受力与重力垂落；长裙可遮一脚或双脚。鞋履可见性是本次姿态和服装的结果，除非用户专门要求展示鞋。完整全身指自然完整轮廓不被画框截断，不等于必须看见双脚、鞋尖、脚踝或所有手指。
5. **联合检查**：姿态与朝向、衣料、手脚遮挡、比例及构图是否相容；已选动作写成明确的一种方案，不在同一张图提示词里堆一串“或”。未指定姿态时依据用途选择稳妥方案，并把此选择视为可调整设计，不冒称用户硬要求。

## 常见姿态的适用与表达

| 站姿 | 适用与可见描述 | 检查重点 |
| --- | --- | --- |
| 自然并立 | 双腿自然接近或小幅分开，肩颈放松，稳定站立；可双手垂落或轻搭身前 | 不强制膝脚粘连或手指全部展开 |
| 小幅错步 / 一脚稍前 | 主承重腿稳定，另一脚略向前，膝部放松，身体仍可保持正面 | 是站定的前后关系，不能误画成迈步或脚悬空 |
| 丁字步 | 一脚承重，另一脚轻靠并略外转，站姿端雅；上身按指定方向 | 不要求两脚机械成直角，不拧膝，不为呈现脚型开裙 |
| 重心偏移 | 一腿承重，另一腿松弛，骨盆小幅侧移，上身自然平衡 | 正面要求下避免转肩；不能把轻松感变成夸张 S 形或窄腰 |
| 轻交叉步 | 双腿在膝下或脚踝附近轻交错，足底支撑合理，肩颈松弛 | 能辨认时检查交叠顺序；长裙遮住时不虚构膝踝坐标 |
| 开立稳姿 | 双脚适度分开，重心稳定，肩膀自然展开，适合自信或武将气质 | 不自动变成战斗蹲姿、极端宽站或健美摆拍 |
| 三分之四转身 | 身体轻转，头可回看镜头；肩、骨盆、衣片随同一空间方向 | 只在朝向允许时采用；不同时声明“身体严格正面” |
| 轻倚 / 支撑站姿 | 有明确支撑物时靠近支点，肩髋与承重相配 | 用户要求纯人物无道具时不自行加墙椅；不能悬空倚靠 |
| 静态舞姿 / 时装姿态 | 用户指定时拆解手臂弧线、脚位、重心与服装展开 | 保持真实平衡；不擅自添加旋转风场或强动态模糊 |

这些姿态可与不同手势组合，但不是任意排列。扶腰不能抹掉腰部结构；插袋须先确认有口袋；持物须服从既有道具要求；衣装采集时减少手臂对关键衣片的遮挡。允许自然不对称，不将“优雅女性”固定等同于并腿、内八、扭腰或暴露身体。

## 写入提示词与修订

- `【构图与姿态】`：写本轮确定的身体/头部方向、承重、腿脚关系、手势、完整轮廓与留白。
- `【服装设计】` / `【材质】`：仅在受动作影响时补充衣摆、袖口、开衩与自然褶皱，不因换站姿重新设计整套衣服。
- `【手部与脚部】`：只约束可见结构连续、自然遮挡和接地。未要求展示鞋时，明确允许符合站姿与裙长的遮挡，不写“必须双鞋可见”。
- 用户只改站姿时保留身份、媒介、服装核心设计与比例目标；检查正文其他标签是否遗留旧手势、旧脚位或旧朝向。修改相关验收项并标记目标变更，不冒称在原条件下修好了旧图。
- 验收先看是否完成指定动作、平衡是否可信，再检查可见解剖与衣料。自然遮住的脚不单独判失败，也不能宣称已验证其内部结构；若用户明确要展示双鞋，则按该任务的特殊要求检查。

例：用户要求“正面自然站立，重心在一条腿，不必露鞋”，正文可以是“身体正面，右腿自然承重，左腿放松略前，双肩平稳，双手自然垂落；裙摆按这一站姿完整落地，双脚可被遮住，保留浅淡接地阴影”。这只是关系描述示例，实际左右、手势与衣摆必须来自当前需求和图像判断。
