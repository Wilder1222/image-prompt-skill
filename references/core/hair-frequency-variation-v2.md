# 头发层次与细节尺度（第二版）

用于人物资产的发型设计、提示词撰写和实际看图验收。自然感与面部可读性同时成立，不用增加碎发数量代替发型完成度。

## 先建立自然发型，再补细发

- **主发量与发根**：按当前发长、发质及造型组织头部体积，分缝、发际线与发根衔接自然；有合理蓬松度，扎束处可收紧，不将全部头发做成贴头皮硬壳或悬浮假发。
- **次级发束**：粗细、疏密、弯曲和前后叠压有变化，顺着梳理、编扎、重力及当前动作延续。发髻、辫子和发饰固定处连接可信，发束不穿过耳朵、面颊或饰件。
- **发梢与少量细发**：发梢自然收束或轻微分叉，少量细发从主束连续生长，优先分布在鬓角及轮廓边缘；避免均匀排线、断裂悬丝、整片胶结或每束都像抛光丝带。
- **反射与媒介**：明暗、高光宽度和边缘清晰度随发束朝向变化，避免等距等亮的金属丝。摄影和精细CG可表现克制的细丝；二维、厚涂和水墨以分组线条、色块或笔触表达同样的自然关系，不强制逐根照片化。短发不强加长发束，卷发不拉直，盘发不自动改披发。

## 人物资产默认保持面容清楚

肖像、定妆照、全身母图、三视图、四视图、表情组及其他人物资产，默认禁止过多碎发遮挡面容。少量鬓发、边缘绒发和原有刘海可以保留，但不能形成跨过眉眼、鼻口、面颊的密集细丝网，或遮断关键五官与身份辨识点。自然感通过上述体积、走向、层次和反射表达，不以风吹乱发、跨脸飞发或碎发阴影代替。

只有用户明确要求遮脸效果、指定会形成遮挡的刘海，或要求严格复刻该遮挡，才在指定区域例外；不把泛称自然、松弛、氛围感、古装题材或参考图已有碎发当成例外。例外仍保留发束来路和自然形态，未要求遮挡的区域继续清楚。已经锁定发型的局部编辑沿用保护范围，不能借默认规则擅自重梳或改发际线；明确的保持要求优先。

整理遮脸碎发时保留获准继承的发色、长度、分缝方向、主要轮廓、编扎与标志性发饰，不为整洁清空全部细发、强制露额或全部油亮后梳。原图被遮挡的眉眼或妆饰仍属未知，露出新区域不等于恢复了已知原貌。

三视图、四视图按共同造型转面，分缝、发际线、发髻或辫子及发饰固定位置连贯；不能每格换一套刘海或靠镜像处理不对称发型。正面核对眉眼鼻口，侧面仅核对实际可见的近侧五官与鼻唇轮廓；背面检查后发束与连接，不要求露出面部，也不凭后脑勺判面部通过。

## 多造型不继承同一套脸前模板

同一造型的转面要保持发型，用户要求同一个人尝试不同造型时则按[多造型路线](../routes/portrait-look-variation.md)重新设计获准的分缝、刘海、鬓角和脸周轮廓。保持身份不等于保留每缕原刘海；只换马尾、发髻、辫子、发夹或地区名称，却沿用相同额前细丝和两侧长鬓发，不能当作脸前已经不同。

自然感不要求每套都有碎刘海。按本人五官与脸型选择清楚的露额、完整短边、侧向发块或其他可见边界，碎发仍只作克制细节。用户明确锁住的发色、头位或刘海继续保持，不靠换脸、偏头或染发制造未授权差异。示例中的具体款式与数量不成为共同默认。

检查刘海时将主发片边界与细发自然度分开：眉上平短边不能靠一排垂到眉间的细长丝替代，齐切侧片不能只因出现两条长鬓发就算成立。具体落点、分区及修订策略由[多造型路线](../routes/portrait-look-variation.md)按本轮要求决定，不将眉上刘海强制所有发型。

## 正文与验收

把所选自然关系和遮挡限制写入最终【发型与头饰】或对应正文，不能只留在内部备注或负面字段。持久化时沿用现有要求与验收字段，分别列出发型自然度和面部可读性的关键检查；局部编辑只检查获准范围。

可按本人物调整的正文起点：

```text
【发型与头饰】
保持本角色的发色、长度、主要发型和标志性发饰。发际线与发根衔接自然，主发量有合理体积，次级发束粗细疏密有变化，顺着梳理方向与重力自然垂坠，发梢轻柔收束。少量细发留在鬓角与轮廓边缘，眉眼、鼻口和面部辨识点清楚，禁止过多碎发横跨面容。发束高光随朝向柔和变化，避免贴头皮硬壳、整片胶结和均匀发亮的细丝。
```

实际看图先按正常展示尺寸判断自然度和五官可读性，再放大查看发根、束间衔接及穿插。拼板逐格检查，脸部太小或发丝遮挡导致无法判断时保留 `uncertain`；遮断本轮要求可见的关键五官时判该项失败，不能用发丝细腻或其他格通过抵消。用户指定的遮挡按其范围验收，背面未见面容记为 `not_assessable`，不能回填未知结构。
