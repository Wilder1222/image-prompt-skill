# 摄影焦点与高光过渡（第二版）

选择白底全身资产方案时可用 `asset_balanced`：脸部最清楚，上身与双手可读，主裙保留结构，外围纱层和次要裙边自然略柔。其他背景与用途按当前任务设定，不自动变成白底。

目的在于光学层次，不是制造模糊。高光自然过渡到中间调，避免数字渲染般硬截断；不靠统一锐化纹理增加真实感。妆容、衣料与指定媒介保持协调。

## 摄影外观与真实尺寸

镜头或相机名仅提示外观，不能代替明确画框、可读景深与清晰度层次；不宣称模型进行了物理镜头模拟。暗发、深色衣料保留层次，高光柔和过渡，避免整圈锐化光晕。真实像素尺寸以实际入口设置和返回文件为准，“4K、8K”正文不构成尺寸证明。主要设计通过后才按需要放大，复查面容、手部和纹样是否被再生成；补白造成主体像素覆盖下降，不称新增真实细节。
