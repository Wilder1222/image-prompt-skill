# Style-on-Asset Mode v0.7.3

## 使用场景

用户要：
- 白底 / 中性背景角色资产
- 同时保留参考图“味道”
- 不希望复制原场景

## 保留

- Identity
- Costume
- Material language
- Palette relationships
- Character temperament
- 适量 Lighting language
- 风格化表面处理

## 不保留

- 原背景
- 建筑
- 山水
- 烟雾/粒子
- 剧情式构图
- 强动态透视

## 与 Asset 的区别

纯 Asset 更中性；Style-on-Asset 允许明显保留色彩、材质、人物气质和光线语言。

## 与 Hybrid 的区别

Hybrid 可以恢复环境与电影化动势；Style-on-Asset 明确保持白底/中性背景，不恢复环境。
