# 人物占比与留白

人物自身的身材比例与人物在画面中的大小分别设计。前者以符合本轮所选体型、协调好看为目标，后者由景别、画幅、服装轮廓和场景用途决定。不能用缩头、拉腿、压窄宽袖或裁掉裙摆来填满画面。

## 生成前选择取景

| 用途 | 取景起点 | 留白与可读性 |
|---|---|---|
| 单人全身、全身白底定妆或服装展示 | 完整人物外轮廓高度约占画高八成至八成半 | 头顶、脚下及左右衣饰均留出舒展空间；脸与主要衣装仍能看清 |
| 人物与背景共同呈现 | 外轮廓高度约占画高六成半至八成 | 按场景叙事调整，让环境有可读结构；人物不能小到失去面容和服装重点 |
| 头肩定妆、面容与妆肤核对 | 从最高主发束或头饰拍至双肩上缘及必要衣领 | 面部承担主要可读细节，关键耳饰与肩颈连接可见；头顶和左右有余量，不套全身比例 |
| 胸像定妆、妆发与领肩造型 | 从完整头顶或主头饰拍至上胸或胸部下方，写清本次下沿 | 兼顾面容、耳饰、领口与上胸衣片；按需要保留肩部轮廓，不用极浅景深模糊关键饰件 |
| 腰上半身、上衣与腰部造型 | 从完整头顶或主头饰拍至腰线下方少许 | 优先上身衣型及层次；微细眼线、唇纹或毛孔按实际脸部清晰度判断，不把腰上半身称作面部特写 |
| 宽袖、拖尾、持物或大幅动作 | 先容纳最外侧轮廓及动作方向，再确定人物大小 | 必要时拉远或加宽画幅，不为达到高度建议挤掉横向留白 |

这些区间是构图起点，不是用户指定的精确验收阈值，也不是新的固定比例。这里的占比指包含发饰、自然衣摆和鞋履的外轮廓高度与画高之比，不等于人物像素面积或解剖头身数。横幅、多人和大场景按实际布局判断，不照搬竖幅单人的数值。

留白是低干扰的视觉空间，可以是白底、地面、天空、安静墙面或疏淡景物，不要求把有背景的图变成空白。平衡不等于左右对称；给视线、动作及重要环境适当空间，避免树枝、柱线、亮斑贴住或穿过人物轮廓。

用户只说“近景定妆”时，按当前核对重点选择具体画框：容貌与妆肤优先头肩，领肩造型可用胸像，腰饰展示采用腰上半身。正文写明上下边界及必须保留的饰件，不仅写景别名称。高发髻和长耳饰按本轮承诺的可见范围容纳，不为保留饰件把面部缩得无法判断；取景存在冲突时先调整画幅或展示重点。用户明确的裁切优先，这些起点不成为固定占比。

近景的比例条款只检查可见头脸、肩颈与胸廓连接；腰上半身再检查可见躯干和腰部。不追加九头身、长腿、完整鞋履或画外手足要求。需要更细的妆肤证据时另设近景目标，不能靠全图锐化或想象补出细节。[三种定妆取景示例](../../examples/portrait-makeup-studio-current-prompts.md) 展示各自的正文与关键验收；它们是不同原创人物，不是同人连续资产或已验证的裁切效果。

## 提示词与验收

生产 brief 在 `composition` 通道写清景别、人物相对大小、需完整保留的外轮廓和留白位置，并关联关键验收。结合 [背景协调](background-direction.md) 检查尺度、透视、光照和主次，不能只写“构图完美”。可参考 [人物入园林示例](../../examples/character-garden-brief.json)。

生成后检查：人物是否挤满或过小；头顶、脚下和最外侧衣饰是否贴边或裁断；脸与衣装是否清楚；环境是否有空间且不抢主体；视线和动作方向是否舒展。数值落在建议范围不自动通过，超出建议也不自动失败，明确的用户构图要求优先。

只修构图时，通过取景距离、画布范围或主体在画面中的统一尺度和位置调整，保持内部身体比例、身份、姿态和衣装设计。只修脸、手或材质时保留已确认占比与构图，不顺带重新取景。近景成片不因看不到下身而自动失败；完整人物母图的证据另行核对。
