# 背景生成与整体协调

背景是本次创作决定，白底只是一种选择。按用户当前要求、同一任务已确认要求、用途与实际参考决定，不要求用户填写模式表，也不把上一张图的背景选择传播为所有新任务的规则。

| 本次意图 | 保持与调整范围 | 验收重点 |
| --- | --- | --- |
| 独立生成背景 | 从文字或环境参考设计地点、前中后景、主要结构、材质和光线；没有人物时不虚构身份。若用于后续放入人物，预留所需活动区域与可匹配的地面、视平线和受光 | 空间自身成立，预留位置有用途；空景可用不等于后续合成人物已经协调 |
| 人物与场景一体生成 | 在同一画面中共同设计人物所处位置、动作、空间关系与照明，按任务保持身份和衣装 | 人物与场景共享空间、光照及媒介，服装不被环境风格擅自替换 |
| 保留原背景 | 保留可见场景身份、主要景物和空间关系；扩画幅时只补足与原空间一致的区域 | 场景没有被清空或换地点，人物尺度和地面关系合理 |
| 调整原背景 | 明确保留的景物与允许改变的杂物、构图、景深、明暗、色调或天气；未授权改变的场景识别点继续保留 | 调整确实解决遮挡、干扰或呈现问题，没有顺带换场景 |
| 替换背景 | 明确目标地点或背景设计，重新匹配视平线、透视、人物尺度、接地、受光方向和环境反射 | 没有原景残留或贴图式人物边缘，人物与新场景处于同一空间 |
| 白底或其他纯色棚背景 | 指定颜色、无缝或有空间的呈现、必要的地面阴影；白底默认采用摄影棚柔光 | 颜色与空间符合要求，边缘与接地可信，脸部布光独立合格 |

仅说“定妆、真人质感、全身、采集服装”不意味着移除背景。参考已有可用场景、又没有移除指令时，通常保留并按授权范围调整。用户只说“允许调整”不等于要求换成一个任意新场景。没有背景参考时按描述和用途做一项克制的设计决定，并在提示词中说明。

## 先共同决定画面，再细化背景

场景先成立，再添加装饰。门窗、墙体、台阶、家具和道路要有连贯的尺度、连接及通行关系；材料磨损、潮湿、反射和阴影有具体位置与原因。不能用统一藤蔓、花盆、复古灯、黑板、暖黄窗光和满地镜面反光堆成每一处店铺的默认模板。这些部件明确符合设计时可以使用，但应服务真实空间和本轮视觉主次。

绘画的色层、笔触与纸纹是表现方式，不豁免建筑和光照逻辑。暖光从具体灯具与开口影响邻近区域，不把室内、墙面和整条道路统一涂亮；雨后区分湿石面、小水洼及漫反射，不把全部地面做成发光镜子。新场景把空间可信、光照因果、材料状态和整体设计完成度分别设为关键验收。

先确定地点、时间天气、整体媒介、视点、人物位置与主要光源，再展开景物。背景独立出图时，若后续人物已经确定，按其站位和视角设计可用空间；尚无人物依据就把占位区作为设计选择，不能承诺适配任何人物。用户没有要求分层交付时，可直接生成完整场景，不强制先出空景再合成。

| 协调关系 | 提示词要落实的内容 | 出图后看什么 |
| --- | --- | --- |
| 视点与尺度 | 人物朝向、地平面、道路或室内线条的退远关系，人物与门窗栏杆等可比物的大小 | 站位是否落在同一地面，景物是否像微缩布景，近远关系是否冲突；不凭“弱透视”文字声称相机已标定 |
| 接触与遮挡 | 脚、裙摆、坐具或扶手的接触点，前景与人物的遮挡顺序，动作需要的空间 | 接触阴影是否贴合受力位置，是否悬浮、穿插或有白边；腾空动作按离地阶段检查投影 |
| 光照与颜色 | 主光来向、软硬、明暗层次与环境反射；明确允许人物受光随新景改变的范围 | 脸、衣料、地面和建筑阴影是否相容，肤色能否读清；协调不等于全图同色，也不要求冷暖光完全相同 |
| 媒介与细节 | 人物和背景采用相容的摄影、CG、三维或绘画表现，焦点与景深服务叙事 | 人物是否像贴在另一种媒介上；焦内背景仍有结构，远景概括有空间依据，不默认浓雾或全背景虚化 |
| 构图与主次 | 景物如何围合、引导视线或交代地点，保留脸、手势和关键衣装的可读性 | 柱线是否穿头、亮斑是否抢脸，景物是否挤掉完整轮廓；场景为主时也允许环境承担主要视觉信息 |

各类人物风格都需要对应的背景表现。真人以可信景物材料与镜头空间组织，精细CG或写实三维使人物和环境的反射、阴影软硬及细节尺度相容，风格化三维协调形体概括与材质，二维动漫、厚涂、水彩或水墨则协调线条、笔触、色块与虚实。具体方案按所选媒介写，不把写实背景固定给所有人物。只有用户明确要求混合媒介时才保留刻意反差，并单独检查空间和光照是否成立。

## 三类任务的生产记录

纯背景使用 `subject_kind: scene`，可只包含 background、composition、lighting、material、style 等实际需要的要求；没有人物就不添加人体比例。人物与场景一体生成或换背景仍使用 `subject_kind: character`，检查本轮所选体型比例与身份衣装要求。按需要将空间、光照、接触和媒介协调分别写为必需要求及关键验收，不用一个笼统的“整体协调”通过项覆盖全部关系。现有编译器验证声明与覆盖，不自动识别视觉协调。

参考权限按用途分配：环境图可提供地点与景物；确需借用视点、照明或媒介时再分别赋予 composition、lighting、style。它不自动提供人物身份、衣装或比例。已有纯背景与人物图分开生成时，记录二者实际输入情况及来源；没有送入模型的图只能作为观察后写入文字的依据。

可编译示例：[园林独立空景](../../examples/background-garden-brief.json)、[人物与园林一体生成](../../examples/character-garden-brief.json)。两者是代理编写的示例，不要求用户填表；已验证生产编译，未分别执行生图。人物换背景的实际输入、正文和逐项结果见 [园林入景实测](../../docs/user-aesthetic-background-evidence.json)。

## 背景与光线分开决定

保留背景不等于必须保留每一道原光影；允许修人物曝光或加柔和补光时，维持场景中合理的光源方向、色温关系、阴影与反射。环境中的夕阳、窗光、虚化、暖色和逆光可以成立，不因历史白底案例自动删除。若用户要求面部均匀清楚，就在场景逻辑下控制面部硬影和碎发遮挡，不把人物打成与环境脱节的白亮贴片。

动作可与背景联合适配。坐倚检查支撑物接触，行走和腾空按阶段处理遮挡、尺度与地面投影；“接地可信”不是要求所有动作的双脚都接触地面。空间需容纳手臂、裙袖及动作方向，不为保留静态构图裁掉已要求完整展示的轮廓。

替换背景可能需要连带调整人物受光、轮廓边缘和接触阴影；把这些写进允许修改范围。只改背景色且原布光仍成立时保持人物照明。不能同时写“保留原背景/原灯光”与互相冲突的替换要求。

修复场景照明时，先写清光源为什么改变，再写各区域应出现的变化。例如目标为均匀天光，可明确太阳被云层遮住、墙地硬叶影消失、衣料直射亮边变柔、脸部得到柔和正补光，同时保留材质纹理和贴地接触影。只写“柔光”不能说明原场景哪些阴影应消失；只让脸变亮也不能证明全景光线已符合目标。现有青橙案例的单次局部编辑支持此方向，尚不代表跨案例稳定性。

## 中文标签与参考权限

按需使用【背景与空间】和【人物与环境光线】，也可在简单任务中合为【背景与灯光】。明确保留、改变、移除和补全的内容；已选择场景时删除旧白底、无景物、仅接触阴影等互斥条款。独立环境参考按上文所述用途分配权限，不因包含人物就获得身份、服装权限。

生产记录可使用独立 background 通道，与 lighting 分开修改和验收。既有记录把背景写在 lighting 或 composition 时仍兼容，不追溯改动冻结记录。背景目标改变时冻结新目标；白底像素或 alpha 检查仅用于明确要求它们的任务，不能作为有场景图片的通用通过条件。

场景协调需检查全画面的可见光照线索。[首次园林入景](../../docs/user-aesthetic-background-evidence.json) 中，人物仍柔亮、空间与媒介基本衔接，但地面出现斑驳日照，违反预先指定的阴天漫射光。主体曝光自然不代表场景天气正确；本例保留为场景候选，光照待修。透明衣料也需单独核对是否透出新背景，不能只看人物外轮廓没有白边就判融合成功。

## 白底与透明底的实图区分

白色背景与透明抠图分别交付。要求白底时明确不透明；查看器用黑、白或棋盘衬底展示透明PNG，不能据显示颜色推断原图背景。先看文件是否含透明度，再查看必要的空白区域；RGB无alpha能证明不透明，不能单独证明白色。视觉白底与逐像素纯白也不同，没有预先定义精确颜色容差时，不把少量近白采样冒充全图数值认证。

只换背景还要重查人物内部颜色和明暗。透明底变白会改变视觉衬托，必要时在同一位置结合原透明度作只读数值比较，区分显示差异与人物重绘；样本不能替代全图检查。[三视图背景修订](../../docs/character-sheet-evidence.json) 中，透明空白变成了不透明白底，但衣料内部变亮，违反已冻结的保持范围。背景成功不等于本次编辑成功；若任务确需同时改人物照明，应在生成前明确授权范围。

人物入画时同时执行 [人物占比与留白](character-framing.md)：按景别决定人物大小，完整全身保留四周空间，入景兼顾环境可读性。将本轮取景目标及关键验收写入 composition，局部非构图修订保留已确认占比。
