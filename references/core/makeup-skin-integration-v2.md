# 妆容与肌肤表现的协调

## 当前妆光来源

新设或获准调整人物妆肤与光线时，先按[用户八图妆光基准](../routes/reference-makeup-lighting.md)选择主卡。2026-10-19的明确要求使本组成为相关设计的必须依据，不能由下文旧满意示例或兼容轻妆控制组覆盖。八图分别保留柔缎、柔雾、润唇、精描眼妆、侧逆光及直接照明的差别；按本人肤色、年龄和角色适配，原妆原光保持及局部编辑保护优先。下文历史示例继续用于写法和证据边界，不是当前自由另选妆光的默认库。

## 审美优先级

先让人物自身的面部结构、妆肤、神态与灯光共同成立，再用适量皮肤细节增加可信度；纹理更多、更锐不等于更好。精致指形体衔接、妆肤完成度和视觉协调，既可呈现适度理想化的美感，也可服务年长、力量、丰润或其他人物特点。保留当前人物的辨识点与表观年龄，通过获准的妆肤、表情和布光提升吸引力，不用统一五官替代本人。

## 从满意示例提取妆肤方法

[蓝衣长发肖像这一审美示例](../routes/user-aesthetic-benchmarks.md) 支持本轮女性肖像的精致、适度理想化方向：颊颌衔接柔和，肤质柔亮且纹理低对比，粉色腮红与润泽唇色协调，面部高光面积克制。可吸收的方法是面容先成立、妆肤色彩相互呼应、分区光泽支持体积；具体粉色、白皙肤色、长发、年龄和女性身份仍是该示例的选择，不作为人物通则。

这张成图使用了人物参考，结果是参考输入、文字与生成过程共同作用的观察，不能归因于纯文字提示词。短发皮衣图已被用户明确判为不满足需求，不能继续作为本轮满意妆肤或人物美感依据。对照示例时先判断本次人物是否达到了相应完成度，再核对其自身身份；不通过收窄脸型、改鼻唇或复制示例的五官达到所谓“同样精致”。

[新增满意人物参考](../routes/satisfied-character-reference-calibration.md) 扩展了呈现范围：A01的现代摄影观感与柔棚光、A03/A04的暖亮发缘与柔和面部受光、A10的暖色和类似胶片的低对比观感，都可以使精致妆肤成立。摄影方向也能满足审美；短发皮衣的拒绝仍针对该具体样本。吸收妆肤、衣料、光线共同协调的方法，按各角色独立选择妆色、光泽和受光关系，不将浅肤、粉唇或同一套柔光强制所有人物，也不从成图反推实际年龄、拍摄或渲染技术。细节观察与来源见 [本轮参考记录](../../docs/satisfied-character-references-2026-10-11.json)。

第二批参考进一步校准浓淡与媒介范围：B06 的较浓暖色眼妆、金色眼下碎饰与华冠可共同形成精致完成度，装饰按布局和反光判断，不当作应清除的皮肤瑕疵；B08 的室内暖光、颗粒观感与红润肤色可支持随性呈现；B15 的轻妆观感保留眉毛疏密、细微肤色变化和面部辨识点，无需追加明显彩妆。B14 的动态幻想原画观感依靠选择性边缘、戏剧光与材料层次支撑理想化人物，应保留这种表现语言。按相应方向选择妆肤与光线，不将这些图统一修成轻妆、摄影毛孔或柔棚光，也不从颗粒、笔触等外观推断制作技术。

## 编写【妆容与肌肤】

- 按角色与参考确定妆容的色彩、浓淡与光泽。精致指完成度和协调性，不强制所有人物淡妆、裸妆或浓妆；已有明确妆容要求优先。
- 先说明本次人物的肤色与底色、可见年龄结构及应保留的个体特征，再选择妆肤表现。冷暖、明度和局部血色随人物与光线协调，不把白皙、粉腮红、粉唇或幼态当作好看的必要条件。雀斑、痣、疤痕和皱褶属于已确认身份时，保留它们的存在与可见范围，不因提亮或精修统一擦除。
- 底妆细腻贴肤、肤色过渡干净，保留柔和体积；眉形、眼影晕染、睫毛根部和唇缘处理完整，腮红、修容与提亮共同修饰五官。避免厚重粉感、浮粉和不必要的斑驳。
- 将“精致妆面”落到本次可见细节：眉形顺应原有眉骨与毛流，眼影和眼线顺应眼睑结构，腮红位置随面颊体积，唇色与唇缘顺应自身唇峰及上下唇关系。允许妆容改变视觉重点，但不能用修容把不同人物都画成同样的窄鼻、尖下巴与相同眼形。
- 肤质通过柔和的分区反射、眼睑与面颊软组织、细微唇纹及局部低对比纹理体现。鼻部、面颊与唇部光泽有区别，但服从妆容的哑光、缎光或润泽设定，不把全脸统一做成油亮或蜡面。
- 需要柔亮肤感时，明确面颊渐变、鼻部与唇部局部光泽以及高光范围；面部轮廓仍由受光面、背光面和软组织体积读出，不用全脸提白或抹平阴影代替通透。哑光、深肤色或较强彩妆也可以精致，按当前角色选择，不强套此示例的光泽。
- 纹理强度随景别和最终显示尺寸调整：全身图优先清楚的五官与干净妆面，不强行让毛孔可见；近景可有细微肤质，仍保持精致、柔和。不能靠锐化、粗大毛孔、随机瑕疵、疲态或老化强化“真人感”，也不把皮肤抹成塑料。
- 写实与厚涂都遵循美感目标，但使用各自的表现语言；原画无需追加摄影毛孔，摄影妆面也不需磨成插画。仅修动作、服装等局部时不擅自重画已确认面容。

### 按部位写清妆面

从本轮实际可见、需要保持或获准设计的妆面选择细节，用“部位、色彩、覆盖范围、浓度、边缘过渡、光泽”组织句子。它是写法，不是六项必填表；无需逐部位堆满，也不要求用户填写。已有身份的妆容以对应原图为准，不能拿示例的色号、眼线或腮红布局替换原妆。

| 部分 | 值得明确的关系 |
| --- | --- |
| 底妆与肤色 | 本人基础肤色与底色、底妆覆盖程度、应保留的年龄和个体特征；均匀肤色仍保留局部血色与面部体积 |
| 眉眼 | 眉妆与毛流的疏密，眼影在眼皮、眼尾或下眼睑的范围及深浅，眼线与睫毛根部的连接；眼线延伸不写成眼睛结构改变 |
| 腮红与修容 | 位于面颊哪个区域、向何处晕开、颜色浓淡及边缘；修容与投影不当作本人骨相 |
| 唇妆 | 唇色与中央、边缘的过渡，唇缘清晰或柔化的程度，哑光、缎光或湿润反射出现的位置 |
| 肤质与提亮 | 面颊、鼻部、唇部及肩颈分别采用的光泽和纹理尺度；亮部范围服从本人的肤色、妆面与媒介 |

例如，ML03可写“暖杏桃棕眼影薄薄覆盖上眼皮，外侧稍深，向眉骨下方柔和消退”；ML04可写“玫瑰豆沙粉唇边柔化但唇峰仍可辨，表面柔雾微缎”。这些句子展示所选参考的空间与光泽关系，不是共同妆色。无明显彩妆的角色也可以只写肤色过渡、眉毛疏密与唇部自然状态。

分开描述本人肤色、妆容颜色和照明呈色。暖妆或红棕发色不要求整幅染黄，青绿色衣装也不要求青色眼影；衣装可产生少量合理的局部反色，但不应淹没本轮应保持的肤色和妆色。白底定妆的光色与反射范围见 [棚光写法](../routes/white-background-reference-cards.md#白底定妆的柔光写法)。

当前设计使用[八图对应完整示例](../../examples/reference-makeup-lighting-current-prompts.md)。旧[定妆写法示例](../../examples/portrait-makeup-studio-current-prompts.md)保留头肩、胸像与腰上取景的写法对照；其中自定铜棕、酒红等妆色只属于旧文字演练，不能绕开当前主卡选择。两组均未出图，不提供共同人物模板或实图效果证明。

## 视觉判断与修订

年龄结构与表面细节分开检查。明确设计为年长者时，眼睑、面颊、鼻唇和颈部的软组织与皱褶可参与人物辨识；“不靠老化增强真实感”不等于擦除已指定年龄。精致妆面可以是无明显彩妆的整洁呈现，不强加眼线、睫毛或唇色，也不默认青年女性。

风格化三维可以概括皮肤微纹理，但仍须交代本轮指定的年龄结构；年长感成立也不等于三维媒介成立。头发、眉毛、短髭和下颌胡须分别核对形状与存在范围，不把灰白配色正确当作毛发设计正确。[一次年长男性实测](../../docs/character-senior-evidence.json) 年龄可读，却偏向摄影并新增下颌胡茬，媒介与九头身均失败。此例支持分开验收，不证明年龄描述导致摄影化，亦未证明某个年龄通用提示词有效。

先看正常展示尺寸下人物是否好看、妆容是否完整协调，再放大核对局部自然度。若新增纹理使人物显脏、显疲惫、粉感重或气质变差，不能因“更真实”判作改善；优先降低纹理对比、调整妆面和光线，保留身份与已成立的神态。局部检查不要求放大后每个区域都有可见毛孔，不用增加清晰度弥补全身图有限的脸部像素。

眉头与眉尾保持自然毛流和疏密，有眼线时使其与睫毛根部协调，睫毛不机械复制成扇形；唇色、唇纹和湿润程度服从本轮妆面，不能用统一锐化制造精致。

修订前区分三种来源：稳定面容结构、妆肤与照明呈现、表情运动。面颊显瘦可能来自侧光或修容，眼形改变可能来自眼线或眼睑动作；原因不清时记录待审，不直接重画骨相。先改授权且有证据的问题，并对照同一人物的辨识点与年龄结构；不同人物同用精致妆肤方法时，也应分别检查各自面容，不能因妆色、发型不同就认为已经避免同脸。

## 软组织与分区反射的补充诊断

保持已选骨相和年龄，在实际可见的面颊、眼睑、鼻翼、唇角及颌颈连接保留柔和体积；表情变化的体积联动与仅修肤质分别处理。区域反射服从妆面和光源：额部较柔、鼻梁鼻尖较集中、外颊偏漫反射、眼睑保留厚度、唇面独立润泽，耳部只在光线支持时轻微透光。全身小脸不强求毛孔，近景也不以斑驳、疲态或随机衰老增加真实感；年轻例子不覆盖其他年龄。
