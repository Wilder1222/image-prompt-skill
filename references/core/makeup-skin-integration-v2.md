# 妆容与肌肤表现的协调

## 审美优先级

人物面容的真实感与肌肤纹理建立在精致妆容之上，最终服务于视觉美感。先让面容、妆面、神态与灯光共同成立，再用适量皮肤细节增加可信度；纹理更多、更锐不等于更好。保留参考人物的辨识点与表观年龄，通过妆容、肤质、表情和布光提升吸引力，不用统一五官替代本人。

## 编写【妆容与肌肤】

- 按角色与参考确定妆容的色彩、浓淡与光泽。精致指完成度和协调性，不强制所有人物淡妆、裸妆或浓妆；已有明确妆容要求优先。
- 底妆细腻贴肤、肤色过渡干净，保留柔和体积；眉形、眼影晕染、睫毛根部和唇缘处理完整，腮红、修容与提亮共同修饰五官。避免厚重粉感、浮粉和不必要的斑驳。
- 肤质通过柔和的分区反射、眼睑与面颊软组织、细微唇纹及局部低对比纹理体现。鼻部、面颊与唇部光泽有区别，但服从妆容的哑光、缎光或润泽设定，不把全脸统一做成油亮或蜡面。
- 纹理强度随景别和最终显示尺寸调整：全身图优先清楚的五官与干净妆面，不强行让毛孔可见；近景可有细微肤质，仍保持精致、柔和。不能靠锐化、粗大毛孔、随机瑕疵、疲态或老化强化“真人感”，也不把皮肤抹成塑料。
- 写实与厚涂都遵循美感目标，但使用各自的表现语言；原画无需追加摄影毛孔，摄影妆面也不需磨成插画。仅修动作、服装等局部时不擅自重画已确认面容。

## 视觉判断与修订

先看正常展示尺寸下人物是否好看、妆容是否完整协调，再放大核对局部自然度。若新增纹理使人物显脏、显疲惫、粉感重或气质变差，不能因“更真实”判作改善；优先降低纹理对比、调整妆面和光线，保留身份与已成立的神态。局部检查不要求放大后每个区域都有可见毛孔，不用增加清晰度弥补全身图有限的脸部像素。

眉头与眉尾保持自然毛流和疏密，眼线融入睫毛根部，睫毛不机械复制成扇形；唇色、唇纹和湿润程度服从本轮妆面，不能用统一锐化制造精致。
