# 按属性拆解参考

即使只有一张图，也要区分哪些内容继承、哪些改变。旧兼容方案分为身份、衣装、材料、姿态、画风、光线、环境；当前生产通道进一步拆出表情、发型、动作、妆容、背景与构图，见 [生产流程](../routes/prompt-production.md)。

身份提供可辨认面容与已确认年龄；发型、体型只在可见且获准的范围继承。衣装提供轮廓、衣片连接与标志饰物，材料提供厚薄和反射。动作负责身体阶段与支撑，构图负责镜头和取景；二者不能混成同一个锁定。画风负责媒介和视觉语言，光线与环境分别确定。

内部继承等级 0 为不使用、1 为借方向、2 为明显继承但可适配、3 为核心保持。数字不是厂商权重，不从不可见部位推导严格锁定。

白底任务可移除原环境，但不自动抹掉指定画风。场景恢复可继承获准的光线和氛围，但不越权换脸或重做衣服。母图加风格图时逐属性指定主要来源；单张参考也可以同时合法提供身份和风格，不需要为了形式强行分图。
