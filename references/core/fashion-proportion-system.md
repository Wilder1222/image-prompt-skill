# 人物身材与年龄适配的比例设计

## 生效顺序

先确认年龄、指定体型和本轮可编辑范围，再设计比例。用户明确的体型、数值比例、Q版形体语言或身体保持要求优先；未指定体型时，默认按年龄适度美化为黄金比例审美下轻盈挺拔、修长舒展的仙侠风格身材。这里的仙侠风格只描述身体的修长与轻盈，不自动改变人物时代、服装、背景、身份或媒介。

此默认适用于各题材的新人物、扩身、换装、风格转换、标准化与人物资产；局部编辑仍只改获准部位。已达标身体保持连续，不每轮继续削瘦拉长。明确丰满、魁梧、矮小、粗壮、纤弱等体型时，围绕该体型协调头肩、躯干、四肢和体积，不能再以默认苗条、高挑或健美为门槛，也不能将符合指定体型的图记作待瘦身。

黄金比例是造型审美目标，不是实测结论或模型精确实现保证。已明确成年且完整全身时，默认明确写 **8.5 头身**，在 **8–9** 内选择具体数值，并写入 `target_head_count`、正文与关键验收；体现修长、细腰、自然饱满且协调的臀部曲线，不编造胸腰臀厘米数据。头长按颅顶至下巴，不含发量、头饰、鞋跟或拖尾。

肖像只写实际可见的头颈肩与上身，不声称展示或验证完整头身比；未成年和年龄未知采用年龄适配、非性化自然比例，不套成人曲线。用户明确的比例或身体锁定优先，冲突要可见：不能暗改原值，也不能为填数值猜参考比例。详见 [实际输出契约](../routes/figure-proportion-fabric.md)。

成年全身默认的美化强度是可见的时装级修长：头部相对全身精巧、肩颈自然舒展、完整而紧凑的躯干、连贯腰胯与明显延展的整组双腿共同成立；手臂同步协调，身体仍有厚度。仅仅无畸形、变瘦或裤腿变窄不满足这一方向。用户已指定比例标杆时，将实际参考提供给生成入口，并写出各图承担的权限；参考只作为关系依据，不抄脸、造型、性别特征、姿态或数值。见 [五图比例校准与失败试验](../../docs/proportion-reference-calibration-2026-10-18.md)。

用户已人工认可的身材图优先作为相应用途的可见目标，按 [比例正例校准](../routes/user-approved-body-calibration.md) 选择清楚的全身视图并逐区域比较。修长要在正面轻姿态及本轮衣装下成立；保留胸廓、腰胯与肢体厚度，不靠改姿势、换裤型或瘦成细杆替代。认可的是身体关系，不自动认可整图、数值比例或同人一致性，也不将某一组年轻女性外观推广到其他年龄和体型。

参考同时含现代全身、古装长裙与动态人物时，按当前用途选择主图：可见腿部用于肢段关系，长裙用于头肩、上身体量与服装下的整体轮廓，动态用于扭转伸展的连续关系。不要取不同图最极端的局部相加；用户认可长裙图不等于已知裙下腿长，认可倾头图的身材也不等于指定所有新造型倾头。身体已经符合所选关系时保持它，不因新增满意图再次缩头、削腰或拉腿。

## 年龄必须落实到身体关系

年龄以用户设定或已观察参考的表观年龄为依据，幻想角色的实际岁数不替代外观年龄。不要为了选参数虚构精确岁数；年龄未明时沿用可见骨架与体量，不无条件套成年模特身材。

| 年龄阶段 | 身体设计与美化边界 |
| --- | --- |
| 婴幼儿 | 保留较大头部占比、短而柔软的四肢与圆润躯干；只整理体块、姿态和轻盈感，不拉成成人仙侠体型 |
| 儿童 | 头部相对较大，肩胸与骨盆未成熟，四肢柔和；适度舒展，不套成人长腿、细腰、成熟胸臀曲线或分块肌肉 |
| 少年 | 保留未成熟的肩胸骨盆关系与自然生长感，肢段清秀舒展，不过分拉长，不套成熟成人体量 |
| 成人 | 默认头肩相称、肩颈舒展，胸廓腰腹骨盆完整，腰身自然收束，四肢修长匀称，肌肉适度紧致有支撑，形成轻盈挺拔的仙侠身形 |
| 中老年 | 保留成熟骨架、肌肉量和软组织的年龄特征，在本人条件内舒展挺拔，不年轻化或统一成青年身材 |

这是视觉设计分类，不是人体测量分龄表。同龄人物仍可有不同身高、骨架、体量与角色特点；儿童或年长人物的适度美化不能仅靠“脸保持年龄、身体套青年模板”。

## 把目标写成可见结构

按【身材比例】写选定的身体关系，禁止只写“完美身材、黄金比例、自动优化”。每个部位服从同一年龄与体型，不叠加互相冲突的极端值。

- **头肩与肩颈**：头部和肩带、身体厚度相称，肩线舒展，颈部与锁骨胸廓连续；保留脸型和五官内部关系，不削窄脸、极端缩头、加宽肩或拉长脖子凑比例。
- **躯干与腰臀**：胸廓、腰腹、骨盆完整连续，有合理长度与厚度；腰身收束和胸臀体量适配年龄及指定体型，不压短腰腹换长腿、不统一沙漏细腰。
- **手臂**：肩、上臂、肘、前臂、腕与手掌连续，上下臂的长度粗细相称，向腕部自然收束；不只延长前臂或缩小手掌。
- **腿部**：骨盆、大腿、膝、小腿、踝与足连续，上下腿成组协调，保留自然膝位与手脚尺度；不单段拉长、不画等粗细杆、不靠鞋跟与拖尾冒充身高。
- **体积与动作**：肌肉、软组织和支撑适配年龄、体型与动作；站立承重与放松不同，扭转时拉伸侧与收缩侧不同，坐姿允许自然压缩。修长不等于纤弱、僵直或无厚度。

衣装按已确定构造贴合身体；衣带、裙片起点不替代人体腰位，不为显高默认上提骨盆、压窄宽袖或缩短衣摆。获准改比例后可按原连接关系重新贴合衣料，不必冻结像素坐标。厚衣下用轮廓、支撑和受力褶皱表现，不穿透面料画肌肉、不要求额外裸露。手脚可自然遮挡，展示鞋履只在明确要求时成为关键目标。

“躯干完整”约束胸廓、腹部和骨盆的连续结构，并不锁定原图中已被否定的躯干长度。“身份保持”保护脸型、五官内部关系和人物辨识，不等于锁定完整头部在全身中的旧尺度。获准纠正比例时，允许头部、躯干、四肢成组重新协调；避免极端缩头不等于禁止一切头身尺度调整。没有比例编辑授权的局部修订仍保持原范围。

面部近景的放大尺度不能传递成全身的大头。全身中的完整头部、发量、肩带与四肢共同服从身体方案；身份图只稳定面部内部关系。将正向身体关系写进生成正文，测量限制、证据边界和“不能靠无畸形判通过”等审核规则留在验收问题中，避免一段身体指令反复堆叠否定句。

无人服装图只提供衣片、缝线、材质、配色与穿着连接。不能从空衣领、袖长、裆缝或悬空裤脚推定身体比例；将设计重新适配已选身体，不把服装图的像素长度锁成身体模板。裤装的修长也不能仅由窄腿、紧身化或改变布料获得。

近景只写可见头颈肩与上身体积，不擅自扩成全身；遮挡的腰臀和关节保留未知。动态屈伸与透视缩短按空间关系判断，不要求画面投影仍凑固定头身数。

## 进入生产正文与验收

生成前按顺序落实：

1. 选定年龄阶段和体型来源。没有明确体型才用年龄适配的修长仙侠默认；有指定体型则直接设计该体型。
2. 在 proportion 通道将实际生效的头肩、躯干腰臀、肢段和体积要求写成 `priority: must`，用同通道正文引用，并关联 `critical: true` 的实图验收。自行选定的细节用 `intent: design` 与 `reason` 标明依据。
3. 使用 `withCharacterGoals` 时可传 `ageStage`：`infant / child / adolescent / adult / older / unspecified`，只为尚缺的目标补充年龄方向，不重写已有正文。必须复核已有绑定中的年龄与体型，不把函数调用当作语义审查。
4. 明确体型与默认 elongated、slender 或 muscle 不相容时，通过 `character_exceptions` 的 `user_request` 记录对应例外，另将实际指定体型写成必须要求、正文和关键验收；不能只豁免却漏写新体型。冻结身体用用户要求，局部操作用实际 `edit_scope`，不可见用 `not_visible`。年龄适配通常直接写进三项正文，不作为漏写比例的理由。

兼容目录的 `BALANCED_ELEGANT` 保留名称；通用档案不假定年龄，新增成年全身默认8.5及范围8–9的明确元数据，实际输出由年龄与取景解析。P7、P8、P9、P9.5、NATURAL_ADULT 与 P9_FASHION_ASSET 只在明确选择时采用。旧 CLI 输出仍是素材，不能代替本轮角色设计。`balanced_locked` 用于保持已确认的身体关系；不能替旧比例问题自动判通过。

## 实图评审与比例偏离的修订

先核对年龄、指定体型和整体轮廓，再分别检查头肩、躯干腰臀、上下臂、上下腿及肌肉软组织。只有未指定体型时才按默认轻盈修长、适度紧致的方向验收；成人默认不套儿童，儿童默认不套成人。任何关键比例失败都不能由服装、面容、长腿或平均分抵消。

按生成前冻结的问题记录 `pass / fail / uncertain / not_assessable`。衣裙遮挡、透视或裁切导致无法判断时保留证据边界；既不能编造隐藏关节，也不能据此认证整身已达标。严格数值的头长为中性状态颅顶至下巴，不计发量、头饰、鞋跟与拖尾；腰臀围比不能用正面轮廓宽度替代。

比例不符合时写明哪一段失衡及相邻关系，例如“腰腹被压短、膝位偏高”，修订这一组结构并复查身份、年龄和服装保护项。不以追加“更高、更瘦、更长、更小头”代替诊断。身体结构整体错误时另建获准的比例版本；局部修手、修肤质或修材料不自动扩大为全身修改。

对用户已否定的全身图，分别记录原图、目标参考、新图的头肩、躯干与腿部相对关系，并排比较整体轮廓。画幅变高、人物放大、姿态倾斜、头饰高度、鞋跟、衣腰与裤型变化均不能独立证明身体比例改善。新图仍复制原比例时，明确记作目标失败；不得以“衣装更精致、瘦了、站得稳”抵消。参考躯干或关节被遮挡时只比较可见关系，不制造量测结果。

同一问题连续两轮无明确改善时停止原方法，只有实际入口支持的姿态、深度、局部编辑或几何控制才作为新变量；普通参考图不冒充这些控制。需要严格数值、投影或几何诊断时再读 [严格比例研究](../research/strict-proportion-evidence.md)。没有执行与审图，不宣称比例实现率提高。

获认可的身体版本用于后续多视角、表情、动作和换装，允许透视、表情和衣料改变投影外形，不每张重新拉伸。目标变更另建版本，历史数值失败和未决结果按原目标保留。编译、测试与标签覆盖只证明工程契约，不证明美感、实际比例或用户接受。

同人从肖像扩身或多套换装时，按 [共同全身体型基准](../routes/full-body-baseline.md) 建立并实际传入身体来源，冻结分区目标和整组比较。仅有统一面容来源、相同提示词或无畸形结论，不足以证明共同身体已成立。
