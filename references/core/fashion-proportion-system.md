# 身材比例自动选择与体型设计

## 当前身材设计规则

所有类型的人物身材均可适度完美化，统一朝舒展、修长、匀称且比例协调的方向优化。由代理根据角色、年龄、体型、媒介、造型与用途选择适合的美化程度；新创作或获准身体优化时，联动调整头肩、肩颈、躯干、腰臀与四肢的长度和体积关系，不只满足最低解剖正确。自然、力量、丰润、矮壮、Q版与不同年龄性别均适用，不再仅限未指定体型的成年人物。保留角色辨识度和原类型特点，不将所有人物改成相同瘦高模板。已认可母图的换装、多视角与局部修复仍按本轮保持范围执行。具体数值仅按明确请求使用，不固定九头身；画面占比另按 [占比与留白](character-framing.md) 设计。

## 完美方向的正向设计

“完美”表示追求更优整体身材的审美方向，不是固定头身数、人体测量结论或自动满分。明确体型决定保留哪些特征，不取消舒展修长的美化：力量型保留肩胸臀腿的支撑量，丰润型保留柔和体积，矮壮型保留紧凑辨识度，Q版保留大头和概括体块，同时适度优化肢段、曲线及姿态，让各自更舒展、修长、协调。儿童和年长人物保留相应年龄特征，不因美化成人化或统一年轻化。具体程度以整体美感和动作可信为准，避免极端瘦削或机械拉伸；纪实、严格复刻和已认可母图的保持范围仍优先。

在本轮允许范围内，将以下关系设计成一套，而非分别叠加极端值：

- **头肩与肩颈**：头脸清楚有存在感，与肩带宽度、身体厚度和全身高度相称；肩线舒展而不僵平，颈部与锁骨、胸廓柔和连续。不通过微小头、长脖子或换脸制造优雅。
- **躯干与腰臀**：保留胸廓、腰腹和骨盆的完整长度与厚度；腰部按体型适度收束，胸腰臀的起伏连贯，骨盆有支撑。正面轮廓和侧面体积共同好看，不把身体压成窄长筒或纸片沙漏。
- **四肢的长度与体积**：上臂前臂、大腿小腿成组协调，肘膝位置和腕踝尺度自然；肢段有收放变化，向手腕与脚踝平顺衔接。需要修长时调整完整身体关系，保留手脚的合理大小和躯干厚度。
- **线条与动作**：肌肉和软组织的体积服务角色与姿态，线条紧致、连贯而不过度硬刻；承重、伸展、扭转和接触时有自然变化。静态轮廓好看还要支持本轮动作，不以僵直站姿或衣服遮住问题。
- **整体与衣装**：先看正常展示尺寸下全身轮廓是否舒展、匀称、有吸引力，再看局部结构。衣服贴合真实身体连接，袖裙、铠甲和鞋跟只服务造型，不能代替身体比例优化。

根据实际角色只选需要的条款，写出具体身体关系与选择依据；不能只交付“完美身材、黄金比例、模型自动优化”。同一方案的头、肩、躯干、四肢和体积共同验收，不凭长腿或一处曲线判整身通过。

## 自动选择的依据与顺序

先执行用户明确的体型、数值与保持要求。已认可完整母图只修手、脸、材质或换视角时保留体型，不重新优化比例；纯风格转换同样不授权改身体。用户本轮要求重新设计身材时才另建方案。参考只到头肩时保留可见关系，隐藏身体需要扩身任务才设计，不将推断写成观察事实。

新设计综合年龄、气质与角色功能、媒介的形体语言、服装轮廓、动作负荷和交付用途。优先看头肩尺度、胸廓与骨盆体积、上下肢长度粗细及其组合；不只调整头的大小。年龄不直接决定胖瘦或头身数，性别、古装、CG和白底也不自动对应某种体型。

| 本轮意图与可见依据 | 可选比例方向 | 具体设计与检查 |
| --- | --- | --- |
| 写实人物、生活场景，强调亲近与可信 | 自然协调的适度美化 | 头肩相称、躯干完整，肢段与线条适度舒展修长，保留自然体积，不极端缩头或抬腰 |
| 高挑优雅、仙侠美人、修长的成人造型 | 轻度修长 | 肩颈舒展、完整腰腹与骨盆，腿部整体稍修长但膝踝位置、手脚尺度相称；服装辅助纵向走向 |
| 时装插画、强调夸张纵向轮廓的设计 | 时装延展 | 根据造型决定延展程度，保留头脸可读性、躯干与连续肢段；不自动变成九头身，摄影或动作任务还检查可信度 |
| 战士、运动、承重或力量型角色 | 舒展修长的支撑与力量 | 保留肩带、胸廓、骨盆和腿部的支撑体积，适度理想化肢段、曲线与姿态，使厚实体型也利落匀称；不改为柔弱窄肩 |
| 明确要求可爱、Q版、卡通夸张，或已认可相应母图 | 角色化体块的适度美化 | 保留头身语言与可爱体块，适度舒展肢段和姿态，使轮廓协调好看；不强改成人时装体型 |
| 丰满、纤细、矮小、魁梧等明确体型 | 保留特点的适度完美化 | 按本轮范围优化头肩、躯干、四肢与体积，兼顾舒展修长及体型辨识度；已认可母图的保持任务不自动重设计 |

表中方向可以组合，但必须写成一套连贯身体。例如“修长的力量型角色”同时保留支撑体积与纵向线条，不能写成既极纤细又厚重壮硕。长袍、铠甲、短装各自按实际构造贴合身体，衣服和鞋跟制造的视觉高挑不充当人体比例证明。

信息足够时直接选定一种方向，不要求用户选择头身数或填写体型参数。只有两个方向会明显改变角色且现有依据不足时，内部比较少量方案，按身份年龄适配、服装轮廓、整体美感和动作可信度取舍；不默认额外生成一组图。仍无法判断且影响核心身份时再澄清。

生产 brief 在 proportion 要求中记录用户的协调美感目标，将自行决定的具体方案写为 `intent: design` 并用 `reason` 说明本轮依据，关联可见的关键验收。默认不填 `target_head_count`，不要把自行选出的数字冒充用户要求。最终【身材比例】交付选定的头肩、躯干、腰臀、四肢和体积关系，不交付“模型自动选择最佳比例”这类未落地口号。近景仅写可见关系。

## 成片比较与验收

先看整体轮廓是否服务这次的角色、衣装和气质，再看局部结构、动作受力与保护范围。自然、力量或可爱方向不以“腿够不够长”作为统一门槛；颈部压缩、关节错位、无依据的纸片腰等可见损伤也不能被漂亮衣服或头身计算掩盖。

有实际出图授权且需要比较比例方案时，尽量保持身份、衣装、媒介、动作、视角和布光一致，明确各方案改变的身体关系，先固定验收再看图。条件同时变化时只能称整体设计比较，不能归因于比例。最优只表示已比较候选中更贴合当前目标，不代表任何角色都适用；文字与编译检查均不能证明图像最好看。

获认可后记录母图与该方案，后续多视角、动作和换装保持同一体型，允许透视、弯曲和衣料改变投影轮廓。更换目标须建立新版本；历史九头身失败和未决结果继续按原冻结要求保留，不回填为新目标下的通过。

## 将方案落实为身体关系

“黄金比例”在这里表达均衡的审美目标，不把 1.618 或任意腰臀数值套到每个身体部位。用户提供具体比例时记录其定义和目标；腰臀围比与正面轮廓宽度比不能混用。参考不足或裙装遮挡时，不编造精确测量，也不宣称已证明达到数学黄金比例。

按【身材比例与体型】或既有【身材比例】明确写出：

- **头身与肩颈**：头部与肩宽协调，颈部舒展，保留人物脸型；头长取颅顶至下巴，不计发髻头饰，人体高度不计鞋跟与拖尾。不通过单独削窄脸、拉长颈部或加宽肩膀凑头数。比例修正保持脸部内部关系，不无条件固定未达标的原头部绝对尺寸。
- **胸廓、腰与臀**：完整躯干和骨盆，腰部收束程度、胸臀体积按所选体型设计，肩腰臀轮廓连续且有支撑，不统一沙漏型细腰。腰线由身体结构决定，衣带不能替代解剖位置；避免无设计依据的细腰突然接夸大臀部或压短腰腹。
- **手臂**：肩、上臂、肘、前臂、腕和手掌尺度一致，上臂与前臂长度互相协调；长短与体积符合所选角色，向腕部自然衔接。放松和屈伸时分别检查关节位置，不能只延长前臂或缩小手掌。
- **腿部**：骨盆、大腿、膝、小腿、踝与足连续；长短和肌肉体积符合所选角色，膝部不过分尖细，小腿有自然起伏并向踝部衔接。大腿与小腿在长度、粗细和关节位置上协调，不把整条腿画成等粗细杆，不单独拉长某一段。
- **肌肉与软组织**：肩臂、腰腹、臀腿可见处的体积和线条符合年龄、体型与动作，保留自然软组织。线条随动作收缩与放松，不默认健美分块、深刻腹肌、凸出青筋或削瘦骨感；明确的力量、丰润或纤细设定分别落实，均衡不等于把左右肌肉画成完全相同的静态轮廓。

肌肉表现不要求额外裸露、紧身化或透视服装。厚衣下用轮廓、支撑和受力褶皱表现身体，不能穿透面料画出腹肌。动态按空间和透视关系判断，屈腿或透视缩短不需要在画面投影里仍凑九头身。

表情变化允许下颌和面颊自然运动，不据此重新拉伸身体或锁死下巴。保持已认可的整体协调关系，具体见 [表情资产](identity-vs-temperament-diagnostics.md#表情资产的基准与变化)。近景只判断可见结构，不声称证明完整下身。

验收时分别检查头肩、肩腰臀、上下臂、上下腿和肌肉量，再看整体是否符合选定方向且协调好看。明显失衡不能被长腿或总体分数掩盖；衣裙遮挡不自动构成比例失败，也不据此编造隐藏关节。保留已认可的体型与妆容衣装；局部编辑不扩大范围。

## 将严格比例要求写入本轮提示词

每个人物任务都在【身材比例】中写出本轮需要呈现或保留的协调关系，并关联关键验收。默认不填数值头身目标；近景按可见头肩与身份保持验收，不擅自扩成全身。

全身设计检查所选轮廓与局部体积是否同时成立：躯干有厚度，臀腿有支撑，上臂和前臂、大小腿均有连续的收放变化；修长方案也不压短腰腹。宽袖长裙下只评可见轮廓和衣料受力，不为验收肌肉而改变露肤范围；近景任务也不擅自扩成全身。用户明确给出数值时保留原值与测量口径，区分设计目标、可见证据和无法判断的部分。

## 按动作落实肌肉线条

- 自然站立：承重腿有柔和支撑感，放松腿不过分绷紧；腰腹与骨盆连续，上臂和大腿保留匀称厚度。
- 抬臂、扭转或舞蹈：肩带、上臂、腰侧和承重腿的张力随动作改变，拉伸侧与收缩侧有差异；不把所有部位同时刻成硬块。
- 坐姿、屈肘或屈膝：允许软组织自然压缩与接触，按空间中的肢段长度判断协调，不能为追求画面中的修长而拉长弯曲肢体。

提示词选用当前动作需要的描述即可。先检查身体整体关系，再检查可见肌肉和衣下支撑；发现局部失衡时明确修复该部位，不同时叠加“更瘦、更高、更长、更小头”等全身修改。

## 工作原则

将“适合角色、协调好看”落实为可检查的整体身体关系，不用一句“腿更长”替代设计。比例是设计变量，不能将数字越大、美感越高写成评分规则。

这套系统是视觉设计规则，不是人体测量协议，也不是图像模型原生参数。

## 比例方案

兼容默认方案仍名为 `BALANCED_ELEGANT`，现在表示随上下文适配的协调比例，没有数值头身目标；主工作流由代理完成选择，素材编译器不观察图片，也不声称自动选出最佳体型。P7、P8、P9、P9.5 与 NATURAL_ADULT 保留为明确选择时的兼容预设，不能自动套用。保持方案使用 `balanced_locked`；旧命令名称不代表默认九头身。

设计依据可参考 [CLIP STUDIO 的人物风格说明](https://www.clipstudio.net/en/characterart/art-style/) 与 [官方三维体型调节说明](https://tips.clip-studio.com/en-us/articles/785)：不同风格和轮廓可使用不同身体关系，头身与身体各段需要一起考虑。上述来源不证明某一比例普遍最美，也不证明本项目已有姿态或几何控制能力；本节的选择顺序是项目设计规则。

## 明确数值任务

用户指定数值或需要端点、投影、网格与绑定诊断时，再读 [严格比例研究](../research/strict-proportion-evidence.md)。历史实验目标和结果不改变；普通审美设计只执行本页选择与协调规则。
