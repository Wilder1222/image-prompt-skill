# 参考来源权限

按实际任务分配每个属性的来源。用户已经授权新衣装时，旧风格恢复流程不能冻结全部服装。当前执行入口为 [提示词生产](../routes/prompt-production.md)。

同一人物多视角指定一个主要身份图，辅助视角放在同一 `identity_group`。分组声明不是自动身份验证，不能因风格相似就合并不同人物。评价标杆默认不作为生成输入；本轮明确赋予其他角色后才按新权限使用。

来源权限是编写与评审约定，不是模型内部的独立控制通道。`primary` 表示本轮身份判断的主要依据，不代表工具自动给这张图更高数值权重；把另一张图限定为风格参考，也不证明模型已分离风格与身份。正文需说明各图作用，输出仍检查误借的脸、发型、衣装与体型。专用角色适配器或风格权重只有在实际入口支持并已执行时才能声称生效，不能由同名字段或一句“锁定身份”代替。

风格参考先按 [入选检查](../routes/character-visual-styles.md#先验收风格参考) 核对实际图像，不凭生成时写过的风格名称赋予权限。非人物静物只能为可见的形面、材料或色光关系提供依据，不能证明人脸表现、身份保持或九头身；生成式样板未达到预定目标时，记录失败与停止阶段，不把样板输出计为人物资产。

| 参考类型 | 允许控制 | 边界 |
| --- | --- | --- |
| 风格目标 | 获准的媒介、运动语言、光线语言、氛围、构图动势、配色关系与环境尺度 | 不默认改脸、体型、衣片构造或标志饰物。 |
| 资产母图 | 人物、发型方向、体型、衣装构造、标志饰物和已确认设计连续性 | 用户新要求高于旧状态；只保护仍有效的部分。 |
| 服装设计参考 | `costume` 中选定的衣片、领袖、开合、层次与配色；表面表现另赋 `material` | 不自动提供模特的脸、发型、体型、姿态或背景；照片未见的背部与内层不得声称复刻。 |
| 背景参考 | `background` 中指定的地点、空间、景物和背景表现 | 光线需另赋 `lighting`，不获身份与衣装权限。 |
| 表情参考 | `expression` 中指定的视线、眉眼张力、嘴部动作和情绪强度 | 不提供脸型、年龄、发型或头部角度。 |
| 身体动作参考 | `action` 中指定的动作阶段、支撑、手势和肢体关系 | 不提供动作模特身份、体型或衣装。 |
| 设定表版式模板 | `layout` 中指定的分格、顺序、间隔、共同展示尺度和标注区安排 | 不自动提供格内人物的身份、姿态、头身比或媒介；这些用途需要另行赋权。 |
| 比例示意或比例参考 | `proportion` 中明确指定的头身与肢段关系；需要站姿或取景时另赋 `composition` | 不获得身份、年龄、发型、衣装或媒介权限；线条粗细不是肢体体积，示意的几何正确不等于输出比例通过。 |

表情和动作可直接根据描述设计，不要求额外参考图。需要联动构图、材料或表情时记录对应范围，夸张动作只要符合任务和受力就可成立。背景按 [环境适配](background-direction.md)，动作按 [动作方向](action-direction.md) 执行。

版式与格内画面分开：三格排成一行属于 `layout`，某格人物正侧背朝向与取景属于 `composition`，线条笔触属于 `style`，九头身属于 `proportion`。模板即使含人物，也只借用明确授予的内容；共同展示尺度不证明人体比例。按实际工具能力与本轮说明提交图序，不把“第一张一定控制结构”当跨模型规则。无模板时可以用文字设计布局，不为凑两张输入虚构参考。

## 人物 A 与衣装 B

仅在本轮指定 B 为衣装设计来源时使用：A 提供人物面容与年龄，发型和表情可按授权适配；B 提供选定衣片构造、配色、层次和材质，饰品按明确范围借用。文字改案决定如何延展、改变姿态与背景。近景 A 不能证明不可见的全身体型，B 的模特身体也不是身份模板。

绑定实际提交图序，并用一句话说明每张图。针对容易误借的特征作明确限制，例如 B 的银发、额饰或大冠；用户明确允许的发型调整仍可执行。不要使用一长串与参考无关的排除词。

```bash
node scripts/iteration-director.mjs reference-authority --scenario identity_A_wardrobe_B
```

此命令仅返回计划与绑定说明，不查看图片、不完成服装设计，也不控制模型权重。具体方案按 [角色资产流程](../routes/character-asset-pipeline.md)。不要把这一 A/B 定义塞进 A/B 含义不同的风格恢复计划。

测试新增衣装参考时保留只用原图的基线，尽量保持文字衣装方案相同，记录新图与角色绑定的变化。脸和头发对 A，衣装对 B，饰品数量与密度对本轮方案分别核对。黑发未变不能证明身份未变，增加视觉参考也不能称作纯提示词优化。新实验仍需保留基线和实际输入记录。

## 绘画身份参考与写实媒介

绘画角色提供可观察的五官关系、脸型、发型与指定衣装，笔触边界和画布颗粒不自动成为皮肤几何或服装结构。换为真人、CG或写实三维时，区分真正设计的疤痕、纹样、衣片缝线与仅表达明暗的色块；不确定的细节不能假装已观察到真实三维结构。新媒介需要重建曲面和受光，仍逐项核对身份，不能借重建换脸。

[厚涂转CG两次诊断](../../docs/character-cinematic-cg-evidence.json) 显示背景和衣料已趋写实时，裸露皮肤仍可能保留原画硬块。局部修订只减轻部分硬边，尚未通过，不能将这个区别写成已验证稳定的转换方案。来源通道、输出媒介与最终验收状态继续分开记录。

## 人物图与比例示意

人物图只提供本轮确认的身份与设计；其身材未通过九头身时，不能同时要求“全身结构完全不动”和“依比例示意重建”。先实际查看示意并检查头长、身高端点、姿态和透视，再给它有限权限。输出仍须独立核对身份、衣装、比例和是否混入无脸头形、骨架线条或标尺，不能把输入示意的通过状态复制到输出。

普通双参考可能仍保留人物图旧体型，已有 [一次失败实测](../../docs/character-proportion-guide-evidence.json)。这不证明比例参考永远无效，也不足以把“加示意图”定为可靠方案。完整人物参考携带体型与构图，调整裁切或改用身份局部参考属于新的输入策略；如要测试，保留原图和新输入摘要，先核对新身份图是否变脸，不静默替换或把生成的新肖像称作原图裁切。专用结构控制还须核对真实工具能力，不能仅凭提供骨架图就宣称启用。

后续 [头肩身份输入实测](../../docs/character-identity-crop-evidence.json) 以生成式头肩图替换全身身份输入，原全身图只用于观察衣装；全身目标和验收摘要保持不变，比例仍失败。因此不把“换头肩参考”写成已验证有效的修复方法。辅助身份图只通过可观察的身份部分，不获得完整人物验收状态；后续采用这类策略时仍需独立测试。

空白比例标尺也只提供校准布局，不提供人物身份、发型、衣装或已成立的解剖。若本轮研究图保留标尺，必须核对人物与线的真实对齐；[标尺复现而人体偏离的实测](../../docs/character-ruler-study-evidence.json) 已说明两者可以分离。带标尺的研究用途写入冻结要求，不能在回执合格后自动改称净版母图；后续移除标尺或重绘均是新的实际输出，保留来源并重新验收。
