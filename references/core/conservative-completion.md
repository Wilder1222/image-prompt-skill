# Conservative Completion v0.7.3

## C0–C3

### C0 Strict Completion
只补必要的几何闭合和裁切外延，不新增可见设计语言。

### C1 Conservative Completion（角色资产默认）
延续已观察语言补齐鞋履、裙摆、背面、机械腿等，但：
- 不新增主色
- 不新增主图腾
- 不新增大型主装甲
- 不新增新的服装体系
- 不提升装饰复杂度

### C2 Creative Completion
允许增加局部次级设计，用于探索稿。

### C3 Redesign
允许明显重设计，只能在用户明确授权时使用。

## Visible / Inferred 关系

可见区域可以 strict lock；不可见区域最多按 C-level 延展。C1 的内容必须标记为 designed extension，而不是 observed。
