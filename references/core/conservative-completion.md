# 缺失部位的保守补全

## C0–C3

### C0：最低限度补全
只补必要的几何闭合和裁切外延，不新增可见设计语言。

### C1：保守延展（未授权再设计时）
延续已观察语言补齐鞋履、裙摆、背面、机械腿等，但：
- 不新增主色
- 不新增主图腾
- 不新增大型主装甲
- 不新增新的服装体系
- 不提升装饰复杂度

### C2：局部创意延展
允许增加局部次级设计，用于探索稿。

### C3：已授权再设计
允许明显重设计，只能在用户明确授权时使用。

## 可见事实与推断的关系

可见且获准保持的区域可以锁定；未知部位按已选范围延展，并标为设计延展而非实际观察。用户明确允许适度衣装优化时，不将 C1 强制套到所有可见设计。
