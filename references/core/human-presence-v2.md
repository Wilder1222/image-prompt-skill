# 人物真实感的六类观察

相对只加表面纹理的旧做法，本规则分别检查软组织、分区反射、自然差异、眼部结构、发束和成像。当前美感要求见 [妆容与肌肤](makeup-skin-integration-v2.md)。

1. 眼睑、面颊、鼻翼、唇周和颈部有柔和体积，保留本人的稳定辨识点。
2. 肤质光泽按实际妆面分区变化，不统一油亮或全脸加毛孔。
3. 自然不对称可以保持，但不为了真实感主动制造五官错位。
4. 眼睑包裹眼球，眼角与睫毛根部连贯，眼白有柔和层次，眼神光符合实际光源。
5. 头发由主发束、次级发束和少量细发组成，反光有层次，碎发不过度遮脸。
6. 高光过渡、阴影细节和焦点符合所选摄影或绘画媒介，不全局锐化成硬边或产生轮廓光晕。

只处理实际未通过的观察项，不把六类全部当成强制改造清单，也不沿用旧案例的白底、年轻年龄或 P9 要求覆盖新角色。
