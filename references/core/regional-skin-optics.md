# Regional Skin Optics

## 原则

真人皮肤来自区域差异，而不是全脸统一“毛孔 + 高光”。

## 区域规则

### 额头
- 纹理细
- 轻微皮脂反射
- 高光弱于鼻尖

### 上眼睑
- 皮肤薄
- 有真实折叠厚度
- 柔和阴影

### 下眼睑
- 有轻微软组织体积
- 不是亮线卧蚕

### 鼻梁
- 较连续但克制的高光

### 鼻尖
- 略强油脂高光
- 不形成塑料亮点

### 鼻翼 / 鼻侧
- 极细微毛孔更明显
- 轻微暖色变化

### 内侧面颊
- 有限细微纹理
- 轻微自然血色

### 外侧面颊
- 更偏柔和漫反射
- 不需要密集毛孔

### 嘴唇
- 独立于皮肤的材质
- 细唇纹
- 柔润但非玻璃唇

### 下颌 / 颈部
- 轻微肤色和明度变化
- 不应与面颊完全同色同光泽

## 年轻肤感

目标是年轻、细腻、真实：
- 不增加粗大毛孔
- 不增加痘印
- 不增加衰老纹
- 不通过“脏”来证明真人
