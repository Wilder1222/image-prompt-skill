# 角色提示词的视觉验收

用户已明确审美标杆时，先确认测试人物、服装与呈现方式能代表其实际用途，再按 [用户人物审美标杆](../routes/user-aesthetic-benchmarks.md) 比较面容与神态、服装与材料、轮廓与姿态、媒介完成度。它们与协调身材、构图留白同为对应任务的关键检查；素装、标尺和几何诊断不能充当审美成片已达标的证据。用户否定的旧样本保留记录，其原技术观察不因此删除，也不再作为此次审美方向的代表。

人物风格按 [人物风格选择与适配](../routes/character-visual-styles.md) 验收：真人、CG、三维、动画与绘画分别检查相应皮肤、毛发、材料、明暗和边缘，不用真人毛孔作为二维或水墨的通过条件。身份、表观年龄、协调身材和衣装结构是跨风格共同要求。

CG或写实转换将皮肤、毛发、衣料和布光分别记录证据；衣料已写实不能抵消颈部、手腕或踝部残留绘画硬边。判断的是当前景别可见的连续曲面、反射与设计关系，不根据单张图声称已验证某个渲染器、散射算法、毛发系统或底层三维模型。布光按可见方向、明暗和分离结果验收，不从一张图反推出已证实的灯具数量或精确位置。

区分诊断与观察：可记录“踝前仍有楔形硬明暗，未满足柔和转折目标”，但不能仅据此声称法线或拓扑错误。反光变弱、细纹减少、轮廓改善分别留证；若光线也改变，不能将所有材质观感变化归因于材料本身。修订范围见 [形状、表面与受光](material-physics-v2.md#先区分形状表面和受光)。

适用于参考图角色定妆、服装采集、扩全身及局部编辑。先按用户任务确定关键项，再生成；不在看到结果后降低标准。每项写图中证据，分别标记 pass、fail、uncertain、not_assessable。评审通过只适用于这张输出，不等于用户接受。

| 维度 | 判断依据 | 不能代替它的证据 |
| --- | --- | --- |
| 身份 | 在可比视角下看眉眼间距与走向、鼻唇关系、面颊下颌、嘴角等多个辨识点；排除光线与表情影响 | 同发色、同衣服、另一张漂亮的脸 |
| 美感与气质 | 是否符合这次明确的年轻感、冷艳/温柔、克制妆容与表情；不以粗糙毛孔作为真人感标准 | 身份近似、细节多、皮肤光滑 |
| 妆容与肤质 | 精致妆面成立，底妆贴肤、色彩与光泽协调；真实纹理在当前景别下细腻克制，整体仍有吸引力 | 更多毛孔、更锐纹理；新增疲态或斑驳却声称更真实；把磨皮光滑当作妆容完整 |
| 表情与眼神 | 所选情绪与任务、姿态、场景协调，眉眼、嘴角、唇部开合自然，指定视线成立；允许合理的表情运动 | 与原图表情不同就判换脸；所有任务统一微笑；用换五官制造情绪 |
| 发型与面部可见性 | 允许适配时，主要发色与盘束方向延续，眉眼鼻口清楚，跨脸碎发明显减少，少量边缘发丝保留自然感 | 只消除投影、仍有发丝穿过眼睛；完全后梳且失去原气质 |
| 比例 | 头身与肩颈、完整胸廓和腰臀、上下臂与手掌、上下腿与膝踝分别协调，整体修长；按姿态排除透视缩短 | 全身入画、标了 P9 或黄金比例、长裙下虚构膝髋坐标、以正面宽度冒充腰臀围比 |
| 体型与肌肉 | 可见肩臂、腰腹、臀腿有适度匀称的体积，肌肉随动作松紧变化，整体紧致自然；衣下轮廓与面料一致 | 只有长腿、等粗细杆四肢、纸片腰、僵硬健美分块、穿透厚衣的腹肌 |
| 衣装结构 | 领口、袖、腰、内外衣片、纹样分区和连接是否延续参考及本轮改案 | 主色正确、装饰更多 |
| 材料 | 不同衣片的厚薄、褶皱尺度、反光、透叠、绣线附着与重力是否一致 | 全部发亮、锐化织纹、写着真丝 |
| 媒介 | 用户指定的摄影/轻写实/厚涂是否贯穿脸、头发、衣料和边缘 | 服装题材、白底、任意写实皮肤 |
| 动作与取景 | 当前动作阶段、身体/头部朝向、支撑或腾空关系及手势可信，轮廓按任务入画；动态透视与遮挡合理 | 只准站直或双脚接地、以夸张本身判错、把透视缩短当成身体缩短 |
| 生命感与协调 | 眼神有焦点，表情与动作意图一致，肩颈手部松紧自然，身体与环境有可信关系，头发和衣料响应动作 | 只有“活人感”字样、统一微笑、堆毛孔或飞发、加模糊掩盖僵硬 |
| 可见手脚 | 可见指节、手腕、脚踝、鞋面与当前支撑/运动关系连续，没有融合或重复 | 藏在袖裙内就假定全部正常，腾空也要求脚落地 |
| 背景 | 按保留、调整或替换目标检查景物和空间；人物尺度、透视、边缘与接地合理。明确选择白底时才要求不透明白背景 | 所有场景都检查四角白色；仅靠背景简洁判断通过 |
| 面部布光 | 人物曝光与本次用途、场景光源协调，五官清楚、有柔和体积。白底定妆默认摄影棚柔光、中性白平衡与均匀面部曝光；场景中允许合理环境色和光效 | 背景合格就算脸部合格；将所有环境都打成脱节的中性白光 |

身份与美感分别判断。不确定时说明是细节不足、视角差异还是具体特征疑似偏离；不要把每个不同视角都判成另一个人，也不能靠发型相同判通过。

衣装评审区分可见结构、指定设计与尚未选择的偏好。新饰件出现时，先定位它是否遮断、替换或破坏了某条明确要求；没有这类证据，就不能只因未提前命名该饰件而判结构错误。需要改变已符合要求的款式时，将其作为下一版设计选择并明确修改范围，不把“更喜欢另一种领口”混成图像证据不足。用户要求严格保留的结构与装饰仍按原范围检查，具体见 [精细度与装饰改动](../routes/user-aesthetic-benchmarks.md#精细度与装饰改动分开)。

成组或跨媒介任务的颜色按 [配色设计与画面颜色](../routes/character-consistency-assets.md#配色设计与画面颜色分开记录) 检查：部件颜色分配、受光变化和精确色值要求分别判断，不能用一个高光或阴影像素代替材料本色，也不从颜色大致保持推断身份或比例通过。

按 [妆容与肌肤](makeup-skin-integration-v2.md) 先看正常展示尺寸下的妆面与整体吸引力，再放大检查自然度。纹理增强若损害妆容完成度或人物美感，不能算改善；全身小脸不设毛孔可见的硬门槛。美感优化保留人物身份与年龄，不用换脸或一味磨皮修复。

表情可独立适配，按 [表情与身份区分](identity-vs-temperament-diagnostics.md) 排除合理的眼睑、嘴角和面颊运动后再评审身份。用户指定的表情优先于自动选择；眼神适配不能覆盖已指定的看镜头要求。张嘴时检查可见牙齿和唇部连接，其余表情不额外要求露齿。

先按 [背景与环境适配](background-direction.md) 确认目标，再分别验收背景与面部布光。白底定妆的均匀摄影柔光标准见 [白底摄影布光](studio-lighting-direction.md)，不外推为所有场景都禁止暖色或逆光。全图检查后实际放大看脸，不能把局部碎发硬阴影误当作必须保留的身份细节。用户明确要求的面部均匀清晰或特殊光效继续有效；原画可保留笔触，但不能以原画为由继承已要求移除的光影。

自然遮挡不是解剖错误。未要求展示鞋时，由动作、裙长与衣料运动决定是否露出一脚、双脚或全部遮住；完整全身不等于双脚必露。按 [动作与生命感](action-direction.md) 检查可见解剖连续性、支撑或腾空阶段的身体关系与接触/离地投影，不为露鞋改变服装。若明确要求双鞋完整展示，则按该特殊要求检查。生成前写清这一范围，不能出图后改口。未知结构不作成功证据，非必需的隐藏关节可以列为非关键的 not_assessable，不另设一个必须通过的“隐藏双脚正确”条目。

人物身材以协调、修长好看为关键目标，不强制固定头身数。不叠加极高腰、极小头、长颈与长腿来实现修长；先检查头肩与躯干，再检查可见四肢和体积。自然衣裙遮挡不自动失败，也不虚构精确测量。动态透视缩短和弯曲按空间关系判断；明确数值任务按其冻结口径单列验收。

人物占画面大小与身材比例分开验收：是否挤满或过小，头顶、脚下和最外侧衣饰是否有适当留白，脸部衣装是否可读，背景是否保有空间且不抢主体。按 [占比与留白](character-framing.md) 判断，建议百分比不能代替实图审美。

每个人物任务必须分别记录头身与肩颈、胸廓腰臀、上下臂、上下腿、肌肉与软组织的证据和结论，不能用一个“比例通过”覆盖所有部位。可见部位明显失衡时，该项失败；自然遮挡且未要求展示的部位记为不可判断，不强行露出，也不宣称其已达到精确比例。此拆分细化检查证据，不改动已冻结评分的维度、权重或历史结果。

比例研究图中的等距标尺、数字和辅助线属于校准信息，不能替代人体端点证据。若同一冻结条款既要求标尺正确又要求人物对齐，标尺子项通过而人体偏离时整条仍失败；逐项证据可以说明哪些部分成立，但不能改写原标准。只读线距统计也不自动识别颅顶、下巴或人体足底，研究图用途与净版母图用途分别记录。

评审顺序：先确认实际输入与目标 → 看整幅的比例和姿态 → 比对面部及头发 → 检查衣片与材质 → 手脚和边缘 → 对照上一候选记录改善/保持/退步。局部修复后必须重查已通过项。

局部编辑还须对照实际输入基准图检查本轮保护范围。最终衣装设计相同，不代表衣领位置、肩线或身体尺寸保持；头部修复改善，也不能抵消肩部被意外重绘。新编辑按 [执行记录](../routes/production-execution.md) 冻结允许修改与必须保持的内容，分别填写变化和保持证据；发现越界判本轮需修订，不以最终目标的其他通过项覆盖。

所有关键项通过才是 reviewer_qualified；关键失败为 needs_revision，关键不确定为 needs_review。不得用综合平均分掩盖身份错误、严重比例错误或裁切。自动文件/alpha/画幅检查只作为辅助，视觉结论由实际观察负责。

写回执前逐条复核问题、证据与结论：同一条包含多个必须满足条件时，只要证据明确指出其中一个未满足，就不能标记通过。不要从评分维度机械复制一段证据给所有检查项，例如衣装设计通过不能抵消同一任务中的面容媒介失败；可见手指正确也不代表身体朝向正确。对旧回执发现矛盾时公开记录复核注记，保留原记录、原评分与累计分母，并说明是否影响总体结论；不能静默改成有利结果。程序摘要验证不具备这项语义审查能力。

实测报告同时给出分子分母、首次与修订后的结果、工具错误、重复或复用图片、评审未完成数。不要从少量样本推断任意参考或任意模型的成功率。

需要量化评估时，按 [图像评分标准](图像评分标准.md) 在生成前固定维度与权重。分数来自逐图观察，脚本只验证计算、文件绑定和测试集完整性。均分达标不能覆盖关键失败或缺少测试案例。
