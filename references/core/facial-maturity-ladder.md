# 面容成熟感分级

本分级描述视觉上的成熟感，独立于人物身份与实际年龄；它是设计方法，不是年龄识别工具。“更成熟、更高级”不授权替换五官，也不默认添加衰老痕迹。

| 标识 | 视觉方向 | 使用边界 |
| --- | --- | --- |
| M0 | 明显幼态，圆润面颊、开阔眼神、较弱下颌感 | 成年角色不默认使用；不能为幼态改变已锁定年龄与身份。 |
| M1 | 年轻清新，面颊柔软、神态舒展 | 保留成年辨识与自然下颌过渡。 |
| M2 | 年轻精致，眼神稍稳、颊颌结构清楚而不尖锐 | 五官大小与间距自然，仍有年轻软组织。 |
| M2.5 | 年轻而从容，妆面精致，表情强度适中 | 适用于明确要求减少幼态、保持年轻的案例；不是所有人物默认。 |
| M3 | 更沉稳、结构感稍强、眼神内敛 | 不自动削脸、凹颊或增加皱纹。 |
| M4 | 明确的权威感与距离感 | 仅用于用户选择的成熟气质；女王或女将题材本身不强制此级别。 |

优先通过眼神、表情、妆容与布光表达变化。眼睑和嘴角可随表情自然运动，不能以锁定身份为由逐像素冻结表情；面宽、眼距、鼻唇和下颌辨识关系应保持。

局部修订通常一次小幅调整，避免跨多级改变；用户明确要求大幅转变时按新范围执行。内部可记录当前级别、目标级别和本轮幅度，例如 M1.5 到 M2.5，先尝试半级至一级。数字不是模型参数或可实测年龄。

原有研究来源见 `docs/research/facial-maturity-research.md`。相关形状、对比与表情线索只作设计参考，不据此推断某个人的年龄，也不自动重塑人物。对本项目年轻成年人物，细腻肤质建立在精致妆面之上。
