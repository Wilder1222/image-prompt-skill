# 人物真实感规则

微纹理并不单独决定真人感。先观察软组织体积、眼睑与眼球、妆面、分区反射、发束和成像是否共同成立，不只追加“毛孔”或“照片级真实”。

H0 保留风格化；H1 增加基础表面可信度；H2 改善人物体积与光学；H3 更接近摄影。它们是内部方向，不是所有资产必经的升级步骤。年龄、媒介和身体比例由当前人物确定。

可见依据包括眼睑厚度、面颊柔和体积、鼻翼和唇周过渡、下颌至颈部连续性；鼻部、外颊与嘴唇的反射应有区别并服从妆容。全身图优先清楚五官与精致妆面，不强制毛孔可见。

保留自然存在的不对称，不主动挪动眉眼嘴角来证明人物真实；见 [微小不对称](micro-asymmetry-policy-v2.md)。发型整理应减少遮脸碎发，同时保留发束层次和自然蓬松。

摄影目标检查柔和高光过渡、阴影细节、自然微对比与主体焦点；不把所有衣纹同等锐化，不添加描边光晕。原画目标仍以对应媒介表达这些体积与材料关系，不能擅自照片化。
