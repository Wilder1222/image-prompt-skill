# 参考继承强度

内部等级用于说明设计责任：0 不继承，1 借鉴方向，2 明显继承但可为目标适配，3 核心保持。它们不是工具原生权重，不保证模型按数字执行。

同一输出属性只指定一个主要来源。单张图可以提供身份、衣装和风格多个通道；多图时不能将冲突的脸型或衣片同时写成严格来源。具体分配见 [参考权限](reference-authority-matrix-v080.md)。

明确的白底任务不继承原环境；允许保留或调整场景时按当前要求决定。服装继承再强，也不能把未见下装称作原图已有设计，未知部分仍是有依据的延展。风格继承不能自行改变人物或衣片，用户授权的再设计另行说明。

“保持”通常要求较强连续性，“借鉴”允许一定适配，但最终要结合可见证据和任务判断。角色、年龄、动作、背景与编辑范围的明确要求高于旧预设。
