# Reference Fidelity Matrix v0.7.3

## 0–3 权重

- **0 Ignore**：不使用该通道。
- **1 Weak**：只借方向，不要求相似。
- **2 Strong**：明显继承，但允许为了目标调整。
- **3 Strict**：连续性核心，除非用户明确覆盖，不主动改变。

这些数字是项目内部控制语义，不是供应商原生权重参数。

## 冲突规则

1. 同一输出属性最多只有一个 strict 来源。
2. Identity 与 Style 不得由同一非资产参考同时 strict，除非用户明确要整体复刻。
3. 白底 Asset / Style-on-Asset 模式下，Environment 默认 0。
4. 图生图扩全身时，不可见区域不能因为 Costume=3 就伪装成“原图严格已有”，它仍受 Completion Level 约束。
5. Style=3 不能越权重画脸、服装结构和身体比例。

## 选择原则

用户说“保持”“严格沿用”“同一个人”通常对应 3；“参考”“延续”通常对应 2；“借一点感觉”“类似氛围”通常对应 1。最终仍要结合实际参考可见性判断。
