# Gemini Image — Style Restoration Adapter

Gemini image models support image editing and multiple references. For hybrid tasks, label each reference role in the natural-language instruction.

Recommended:
- A style reference: mood, atmosphere, lighting, motion language
- B asset reference: identity, costume, proportions, signature design
- C optional trait reference: maturity / expression only

Keep the role statement concise, then describe the final target. Multi-reference capability does not remove the need to explicitly isolate responsibilities.
