# Midjourney — Style Restoration Adapter

Midjourney V8.x separates Edit Model references and Style References.

Use:
- Edit Model reference for the asset / character continuity
- Style Reference for look-and-feel when the workflow supports it

Style Reference is designed to capture visual vibe such as colors, medium, textures and lighting rather than copying people/objects. Keep the text prompt focused on desired final content and selectively reinforce the style.

For a hybrid task:
- asset image → Edit Model reference
- original artwork → Style Reference when appropriate
- text → final character/content + essential style descriptors

Do not treat a Style Reference as an identity reference. Do not add V7 Omni rules to V8.2 Edit workflows.
