# 当前局部编辑范围写法示例

由 `npm run examples:build` 将[历史文本](compact-edit-history-prompt.md)投影为包含当前分辨率要求的方法示例。此页演示紧凑范围，不能替代完整生产 brief；未重出图，原输入、旧正文与原评审保留。当前完整契约见[全身生产示例](full-body-production-current-prompt.md)。

```text
【原人物肖像】
输入第一张近脸原图是唯一的肖像与原妆基准，第二张白底全身卡只是本次编辑对象及可见体型取景参考。保留第一张实际可见的脸型、柔和颊颌、眉形、青蓝眼部颜色、眼形眼距、细鼻、柔粉唇、人中下巴和年龄观感；保留自然不对称，不瘦脸、放大眼睛或换成另一张模板脸。

【原妆容】
沿用第一张原图的淡粉眼周、细深色眼线、柔粉唇色与唇纹、原额头小红点以及原可见的少量青色细闪线和细亮点；位置、范围、妆量、边缘与肤感不另造。原有细小妆饰是局部表面细节，不扩散成额头、脸颊或眼下的大片彩色斑驳；不新增亮片、泪痕、痣、重修容或浓妆。

【发型与头饰】
保留原图的深发、向后束起的主发型、原粉色侧花、青粉带饰与金色细链，整体发量和辨识结构不改。原脸侧细发自然保留，关键双眼、鼻唇可读；发丝与链饰只形成很淡的柔影，不把投影画成皮肤污斑。不新增花冠、厚重额饰或一套新的首饰。

【媒介与完成方式】
延续第一张原图精细的摄影式人物完成方式：细发丝、真实的浅柔肤光、唇纹与自然衣料受光。布光和衣装简化不改变人物媒介，不改成动漫、厚涂、塑料蜡像或粗颗粒旧画；细节清楚但克制，金属不产生满身碎亮点。

【身材比例】
保持第二张编辑对象已见的自然头肩、颈胸连接、胸腰与手臂体积；头脸有正常存在感，躯干长度与肩腰臀关系协调，手掌尺度自然。只简化包覆人体的衣料，不收窄身体、拉长脖子、缩头、抬腰或拉腿。原近脸没有提供全身体型，裙下骨点仍不可判断，本张身体延续仅为生成设计。

【正面全身与取景】
只输出一张纵幅单人正面全身卡。头颅、双肩、胸廓与骨盆一起朝镜头，头部端正不倾斜，平视弱透视；自然直立、双臂放松下垂略离躯干，双脚自然平行接地。最高头饰、完整两手、衣摆与足部都在画内，四边有清楚白边，衣摆不触边。只等比拉远完整人物取景，不改变身体内部比例；不出现多格、多个人物、文字、标尺或水印。

【白色背景】
保留均匀纯白摄影棚背景，人物与浅色衣料边缘清楚，足底仅极淡的自然接触影；画面没有环境陈设、生物、植物或强烈环境色染。

【均匀柔和棚光】
用镜头方向的大面积柔光主灯与左右柔和补光，使额头、双颊、眼下和鼻唇形成连续、浅柔的明暗体积；脸部肤色通透一致，仍有自然鼻侧和下颌体积。脸上不出现链饰、花冠、发丝或树叶形的大块碎影，不出现不规则灰红暗斑或碎金反射光斑。鼻唇和眼睑不因补光过曝、磨皮或平光而消失；原局部细闪妆继续按原位置克制保留。

【清爽衣装】
沿用第二张清理候选的青蓝外袍、淡粉内裙、交叠领型与自然完整长裙轮廓。青蓝衣身、袖面和淡粉裙面改成干净的素面丝质大色块；领缘保留一条很窄而克制的金色边线，其余衣片不铺金纹、花朵、碎点、藤蔓线或银白裂纹。腰带是平整素青蓝丝带，只做简洁结，不加腰花、珠链、坠饰或金属扣；头部原侧花、青粉飘带及耳饰保持。袖子保留一层轻薄透光衣料，外袍与内裙各一层，衣片之间只有必要的清楚分界，避免内外反复翻叠的锯齿边。

【纹样与材质层次】
服装用完好洁净的丝质和轻薄袖纱呈现，靠少数宽缓垂褶、自然遮叠和柔和反射体现材质。青蓝衣片与淡粉裙面的大部分区域是连续净色，细织纹只在近处自然可辨，不画成全身纹样；金色点缀只在窄领边，不从领边扩散到衣身、袖裙或腰带。衣料不出现灰褐污点、满铺亮斑、斑驳颗粒、旧裂纹与密集小皱线；保持精细摄影式完成方式，清爽而不塑料化。

【本次编辑范围】
允许修改：
- 仅调整脸部棚光及碎影，保留原妆细节和面部体积。
- 仅简化衣身、袖裙与腰带的纹样和层数，保持现有衣型与人体。
- 仅等比拉远取景，使完整头饰、手部和衣摆周围有白边。

必须保持：
- 保持图一可见本人五官、年龄、自然不对称、原妆与妆饰的形状位置颜色。
- 保持图一的发型头饰、摄影式精细完成方式及图二已见的身体体积。
- 除上述授权外，白底、主体数量和正文其余目标均保持；未见体型与侧背继续未知。

【输出分辨率】
4K 像素分辨率，保持当前画幅比例，成图长边至少 3840 像素。
```
