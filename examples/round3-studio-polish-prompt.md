# Round 3：棚拍完成度

以当前已经通过身份、服装结构和材料的角色资产图作为唯一编辑对象。人物、脸、身体、发型、服装设计、配色、姿态、鞋履与背景类型全部锁定，不再重新设计。本轮只修棚拍光线、白衣白底分离、材料反射和最终真实镜头质感。

【主补光】保持明亮高调白棚。主光来自镜头左前方约30–45°的大面积柔光源；镜头右侧补光比主光弱约半档到一档的视觉强度，让鼻梁、颧骨、下颌和衣褶出现非常柔和的立体变化，而不是全身均匀平光。

【分离光】从上方/侧后方加入非常弱的分离光，只帮助黑发、肩部、袖边与裙摆边缘从纯白背景中分离，不形成影视逆光光晕。

【白衣白底】背景接近纯白；米白、象牙白与冰蓝灰服装保持轻微明度与色相差。白色服装高光不能过曝，仍能看见织物、褶皱、刺绣和纱层边缘。使用自然光影与材料差异分离，不加人工黑边。

【材料反射】真丝、丝缎、云锦、轻纱、刺绣、白玉、珍珠与冷银金属保持各自不同的反射响应。皮肤高光仍遵守区域式光学，不因为棚拍抛光而回到统一塑料高光。

【真实解析力】使用真实镜头微对比和自然清晰度；面部、发丝、服装主要结构和鞋履可辨，但不增加过度锐化、clarity、halo、HDR、bloom和AI伪细节。

本轮完成后不再通过重新生成修改角色，若需要更高像素尺寸，进入独立 Upscale 阶段。
