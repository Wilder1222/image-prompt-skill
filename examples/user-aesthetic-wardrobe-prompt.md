# 黑金衣装双参考换装实测提示词

实际输入依次为白蓝汉服候选与用户黑金古装参考。正文与冻结调用一致；结果是衣装候选，双手保护失败、九头身未决，不能作为完整资产通过示例。

```text
【任务与参考】
编辑图一的成年女性全身照，保留她本人，只将身上白蓝汉服换为图二的黑金古装。图一提供人物、发型、表情、姿态、写实质感与白底柔光；图二只提供身体衣装和材料，不迁移图二的脸、冷艳表情、高髻、金冠、耳饰或站姿。输出一张无文字的单人全身照。

【人物身份与神态】
保留图一柔和的面颊与下颌、眉眼间距和眼形、鼻唇关系及表观年龄。继续看向镜头，嘴角保持图一轻微温柔笑意，头部角度不变。

【妆容与肌肤】
保持图一细腻明亮的妆肤、淡玫瑰唇颊、柔亮眼神和脸颈明暗；不随深色衣装变成粗粝皮肤、浓重眼妆或冷硬脸部。新领口露出的肩颈皮肤与图一肤色和柔和体积连续。

【发型与头饰】
保持图一近黑长发半盘半披的轮廓、额前与鬓边发束，以及银白小花发饰和长耳坠。衣服变为黑金，头发、头饰与耳饰仍沿用图一。

【黑金衣装设计】
以图二可见身体衣装为依据：黑色贴身上衣以古金纹样分区，象牙色领缘斜落至肩线，露出肩部；深墨绿与黑色长外衣形成宽大垂袖，浅色袖里从开口翻出。宽黑金束腰接深色分片长裙，古金纹样沿前身与竖向裙片延展，象牙色内层从衣片之间显露，古金挂件与流苏垂在腰前。保持图二的深浅层次与完整华服结构，替换图一身体衣装的白花绣、浅蓝腰封和珠串流苏。袖子随图一腰前轻搭的双手自然收拢，裙尾沿地面轻铺；不要照搬图二单手抬起的姿态。

【材料与细节】
深色织锦有沉静的丝质光泽与清楚长褶，古金绣线依附布面并沿褶皱转折；外袖薄纱叠压处更深，象牙色内层更厚且有柔和缎光。腰饰保留硬质边缘与小高光，金纹、布料、薄纱和皮肤各有不同反光。黑色衣片仍可读，华丽细节围绕领肩、束腰和竖向裙片展开。

【身材比例】
黄金九头身为硬性要求：直立人体高度等于九个颅顶至下巴的头长，不把发髻、头饰、鞋跟或裙尾计入。整体高挑修长、匀称优雅，头肩、自然颈长、完整胸廓、腰臀与四肢协调；保留柔和体积，不靠极小头、长颈、纸片腰或单独拉长腿部凑比例。

【构图与姿态】
保持图一身体轻微侧转、脸回向镜头、肩部放松及腰前双手轻搭的姿态，头部位置与人物在竖幅中的大小不变。新衣装轮廓随布料自然变化，发饰、宽袖和裙尾完整入画。

【背景与灯光】
保留图一明净白底和照亮面容的大面积柔光，脸部曝光和白平衡保持；深色衣料使用与其材料相符的较暗明度。新裙尾有轻淡接地影，不为黑金服装改成戏剧性暗光或环境场景。

【整体成片】
沿用图一柔亮精致的写实人物质感，面容、细发、手部和华服统一在同一受光中。新黑金华服的完整度参照图二，温柔神态与面部完成度保留图一，既有丰富细节也有清楚主次。

【手部与自然遮挡】
保持图一可见手指和手腕的形状、位置与自然轻搭关系，袖口适应手臂，避免融合和重复。鞋脚继续随长裙自然遮挡，不抬裙或开衩展示腿脚。

【本次编辑范围】
允许修改：
- 仅替换身体衣装及腰前衣饰；按图二衣片、配色、纹样与材料重新形成领袖、束腰和裙摆。
- 允许新领口显露连续自然的肩颈皮肤、新袖裙改变衣服外轮廓，并产生衣物自身的褶皱、遮挡和接地影。

必须保持：
- 保持图一眉眼、鼻唇、面颊下颌关系、表观年龄、轻微笑意与头部角度。
- 保持图一面部妆肤、肤色、曝光和柔和明暗，不因黑金衣装换脸或重做妆面。
- 保持图一半盘半披长发、银白花饰与长耳坠，不继承图二头部造型。
- 保持图一身体尺度、站姿与双手形状位置；本次换装不调整头颈、躯干或四肢长度，不用衣装轮廓替代人体比例。
- 保持图一画幅、头部位置与人物大小、白色背景和总体柔光布局。
```
