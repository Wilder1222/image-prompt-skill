# 白蓝汉服近景微笑实测提示词

仅输入白蓝汉服候选，使用内置生图工具生成近景。微笑及可见身份延续；首饰和花绣细部保护待核对，九头身未确认。本例不是完整合格资产。

```text
【近景任务】
以输入图这位成年女性为唯一人物基准，生成她的单张竖幅头肩近景。头顶发髻与银白花饰完整入画，下缘到上胸，双肩及原汉服交领可见。保持原头部轻倾和回望镜头的方向，白色背景；不拼板，不加文字。

【同一人物】
保留输入图的眉眼间距与杏眼走向、细巧鼻梁鼻尖、唇形特征及柔和面颊和下颌，表观年龄保持。近景里仍能认出输入图本人，不因微笑换成另一张面孔。

【微笑变化】
目光继续看镜头，嘴角自然向两侧轻提，双唇微启，只露少量上排牙齿，面颊稍抬、下眼睑柔和跟随，形成明亮亲切但克制的微笑。保留双眼睁开，不做眨眼、夸张大笑或歪嘴。牙齿只补出本次微笑需要的部分。

【妆容与肤质】
延续淡玫瑰唇颊、细致眉睫、柔亮眼神和细腻明净的脸颈肤质。近景可见柔和皮肤起伏、唇纹和细小散发，额鼻与面颊光泽有区别；不新增雀斑、痣、浓眼线或金属亮粉，不用粗硬毛孔破坏原有柔和面容。

【发型与首饰】
保留近黑长发半盘半披的发型、头顶发髻、额前分缕与鬓发，以及画面左侧为主的银白花枝、垂珠和两侧细长花形耳坠。保留原可见花饰的布局与耳坠的花形连接，不改成新冠或短耳钉。发梢与较低的挂坠可以随近景自然出画。

【领肩衣装】
保留原白色交叠衣领、浅蓝灰衣层、银白花绣和透明外纱。画面右肩的花绣与薄纱层次、胸前的交叠方向沿用输入图，不新增项链、披肩、立领或更换领口。只呈现近景范围内的原衣装。

【柔光与背景】
沿用原明净白底与大面积柔光，脸颈肤色、白平衡及柔和明暗关系保持。眼部有清楚而克制的湿润反射，发丝与衣纱有细微层次，不增加戏剧性暗影、彩光或发光边缘。

【身材比例】
人物身体设计继续遵守黄金九头身：直立人体高度为九个颅顶至下巴头长，发髻、饰物和鞋跟不计。本次只改变景别与微笑，不调整头颈肩相互尺度，不拉长颈部或缩小头部；画外身体不补入近景。

【整体质感】
延续输入图柔亮精致的写实古风人物质感，眼睛、皮肤、细发、花饰与薄纱处于同一光照和细节层次。整体清澈温柔，面部是视觉重点，衣饰细节有主次。

【本次编辑范围】
允许修改：
- 将全身构图改为头顶至上胸近景，允许近景必需的细节补绘；不声称恢复原图未记录的细节。
- 由原轻微笑意改为露少量上齿的微笑，允许嘴角、唇间、下颌、面颊和眼睑随表情自然运动；牙齿属于本次新补全。

必须保持：
- 保持眉眼、鼻部与脸颌的身份特征及表观年龄，表情联动不等于重新设计五官。
- 保持妆色、肤色与柔亮质感，头部朝向及可见头颈肩的自然尺度关系。
- 保持半盘半披发型、银白花枝布局与长花形耳坠的可见连接设计。
- 保持白色交领的方向、原领肩花绣与透明纱层，不新增颈饰或换衣。
- 保持白色背景、柔光方向与总体明暗观感。
```
