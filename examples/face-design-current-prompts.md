# 人物捏脸系统完整提示词示例

由 `npm run examples:build` 从独立面容方案与肖像 brief 生成。两例共用同一套面容结构，只修改神态；它们是原创文字设计，尚未生成图像，不能据此判断身份保持或美感。

## 原创药师：安静专注

```text
【人物身份与面容】
人物设定：一位26岁的成年东方女性药师，呈现自然、有辨识度的面容
脸型轮廓：短椭圆脸
面部长短关系：偏短
颧骨形态：颧骨平顺
下巴轮廓：圆润下巴
眼睛形状：杏圆眼
眼尾方向：眼尾轻微下垂
眼睑结构：上睑自然轻覆
鼻梁形态：自然鼻梁
鼻尖体积与形态：圆润鼻尖
唇部轮廓：自然丰满的唇形
面颊软组织体积：圆润面颊
眼距关系：眼距适中，双眼与鼻根之间的距离自然协调
自然眉形：眉毛自然舒展，眉峰平缓，眉尾逐渐变细

【构图与视点】
单人肩部以上正面平视肖像，头顶与发型完整入画，双眼、鼻唇和下颌清楚可见，四周有适度留白。

【可见头肩比例】
按修长舒展的黄金身材比例方向美化本肖像可见头颈肩：头肩相称、肩线自然展开，颈肩连接完整，不拉长脖子，不推断未显示的全身。
可见颈肩与上身轮廓苗条利落，保留自然厚度，不用缩头、纸片颈肩或露骨削瘦制造修长。
颈肩与可见上身适当有肌肉，呈现克制紧致的软组织与支撑，姿态舒展，不松垮，也不刻出粗大僵硬肌肉；画外肌肉不作判断。

【画面表现】
自然细腻的人物摄影表现，五官和软组织有可信体积，保持清楚的面容设计与生命感。

【发型与面部可读性】
深色头发自然向后整理，发际线与发根衔接自然，主发量有合理体积，次级发束粗细疏密有变化，发梢自然收束，高光随朝向变化。
少量细发留在鬓角及轮廓边缘，禁止过多碎发遮挡面容，眉眼、鼻口和下颌辨识点清楚；不为整洁将头发全部油亮贴平。

【可见衣装】
可见米白色亚麻交领衣的领口和肩部，织物低光泽，领缘厚度及搭接自然。

【背景】
浅暖灰无缝背景，无文字、图表或其他人物，让面部结构清楚可读。

【表情与眼神】
当前视线与眼神：目光安静地看向镜头，眼睑自然放松，带清醒而温和的专注感
当前唇口状态：双唇轻合，嘴角自然放松，没有刻意微笑

【妆容与肌肤】
妆容：薄而均匀的自然底妆，眼周和唇部颜色克制，妆面不改变原定五官轮廓
肤质表现：面颊柔和的软组织转折可见，额鼻高光克制，肤色与颈部连贯，保持26岁的表观年龄

【灯光】
照明条件：中性白平衡的大面积柔和正面主光，两眼清楚，保留鼻唇和面颊体积

【发型】
发型与脸部遮挡：深棕长发低束，额前少量弧形发束，露出眉眼与下颌外轮廓

【输出分辨率】
4K 像素分辨率，保持当前画幅比例，成图长边至少 3840 像素。
```
