## 银发空灵角色
| 变体 | 面容模式 | 当时预期 |
| --- | --- | --- |
| A | beauty_first | 年轻、空灵、漂亮，轻度面部真实感 |
| B | humanized_real | 摄影面容更强，可能增加成熟感 |
| C | stylized_beauty | 最理想化、最风格化的面容 |

主要判断：美感、年龄观感、身份、空灵气质，以及没有不需要的老化。

## 黑红女战士或女王
| 变体 | 面容模式 | 当时预期 |
| --- | --- | --- |
| A | beauty_first | 更柔和、更年轻的面容 |
| B | humanized_real | 目标为成熟但年轻的摄影人物感 |
| C | stylized_beauty | 海报或插画式美感 |

主要判断：权威感、人物生命感、身份、高级时尚编辑观感，以及没有年龄增加。
