# 共用审美完成度与不同面容的完整提示词

由 `npm run examples:build` 从独立面容方案编译。蓝衣长发肖像是审美示例之一，迁移妆肤与神态的完成度；这些人物的脸型、骨相和眉眼鼻唇关系为原创设计，不复制示例的脸、蓝衣或长发。前三例共用妆肤、神态、发型、衣装和照明，结构区别须由各自面容承担。

这是文字设计演练，没有新出图、逐人用户接受或跨模型证据；编译与冻结检查不证明图像中的美感、身份保持或人物区分。最后一例在既有药师面容上只修订妆肤和神态。
