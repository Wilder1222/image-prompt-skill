# Skill 行为回归任务

本页固定自然语言请求和验收重点，供独立代理按当前 Skill 从头完成；不向它提供上一轮答案。只交付提示词时不调用生成服务。生成正文、brief、编译/诊断及实际限制保存在独立 output 目录；文字演练与实图评审分别报告。

| 请求 | 关键行为与预期 |
| --- | --- |
| 设计一位40岁女园艺师，绘本插画，抱小盆栽，半身，成熟自然。 | 采用人物路线；年龄和二维媒介明确，只设计可见身体；妆光适配而不少女化，不扩全身；正文含4K。 |
| 设计一位矮壮的成年女重甲卫士，迈步举盾，精细CG全身。 | 指定矮壮覆盖默认苗条修长；独立体型例外、共同目标、动作承重与六区 body_plan；不将CG变成真人。 |
| 把同一个维修员画成正面、右侧、背面三视图，横向三格。 | 区分 layout 和 composition；每幅有 figure_id 与六区验收，背面不假称脸部可见；可参考 full-body-production-brief.json 的契约完整性。 |
| 第一次上传商品图，只把灰背景换成淡蓝，瓶身、标签文字和投影保持。 | 先看实际原图；编辑范围收窄；首次 `kind: edit` 无需伪造父记录；母图摘要和逐项保护冻结。无实际图片时说明尚未观察，不编造事实。 |
| 只修这张人物图的手，脸、身材、衣装和光线保持。 | 局部例外不扩大到全身、妆发美化；引用实际基准，逐项保护；未改的不足不能自动记为通过。 |
| Generate an English prompt for an empty white gallery in daylight. | 无人物路线；显式 language=en，正文及生成标签都为英文；4K条款只出现一次。 |
| 做香水广告，标签必须写“山岚”，竖版，指定 Gemini，尺寸4K。 | 产品构造与准确文字独立设计验收；原生字段仅使用当前已实现设置，不声称文生图适配器支持参考编辑。 |
| 将书店场景发给 SDXL；当前没有实际 tokenizer 检查。 | 保存完整中文正文，不静默截断；冻结计划 inspect 显示不可派发，不能拿字符数当 token 覆盖。 |

每例复核路线、用户必须项、编辑越界、可复制性、语言与分辨率、实际输入及能力声明。检查成功不等于美感或用户接受；重复运行的成功率只能来自同口径的独立运行记录。
