# Round 2：服装材料与物理

以上一轮已经通过脸部身份与真人肤感的全身资产图作为唯一编辑对象。严格保持人物脸、发型主体、身体比例、正面站姿、双手、服装大轮廓、米白＋冰蓝银灰配色、鞋履和白底构图不变。本轮只修服装材料、刺绣密度、褶皱重力和轻微自然不对称。

【材料差异】米白内层是真丝主结构：细密、柔软、弱至中等反光；冰蓝中层是丝缎或云锦：更有重量，折痕处有明显方向性高光；云锦/提花结构更厚、更挺，承担衣片结构；外层是真丝绡或高级轻纱：半透明、轻，但多层叠加后透光下降并能看见边缘层数；银蓝刺绣是真实线材，在布面上有轻微隆起和方向，不是平面印花。

【刺绣密度】整体重复刺绣密度比当前减少约20–30%。保留领口、胸前、袖缘、腰部局部和裙摆局部的重点纹样；减少袖子中段连续满纹和整个裙摆重复铺满的纹样，让华丽感更多来自面料、剪裁和真实织造。

【重力与褶皱】袖料在肘部与腕部形成不同尺度折痕；腰部因束腰产生少量不完全对称的径向褶皱；裙摆从腰臀向下形成长纵向褶皱，地面接触处产生随机压褶和轻微堆叠。左、右袖摆下垂程度允许很小差异，一侧裙摆可比另一侧多一层堆叠，内外层裙摆长度有轻微自然差，不要镜像复制。

【配件固定】腰饰固定在腰封结构上，刺绣与流苏有明确连接点，所有金属件和吊饰都有真实固定关系，不悬浮、不穿插布面。

本轮不改变人物面容、皮肤、身体、服装轮廓、配色、鞋履、姿态、背景与构图。
