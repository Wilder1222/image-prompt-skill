# 当前人物风格编译示例

由 `npm run examples:build` 从风格目录生成。以下为兼容编译素材，不是已观察具体人物后完成的生产提示词，也没有对应的逐风格实图验收。实际人物、衣装、动作和背景按当前任务编写；所有风格以协调、修长好看的比例为目标，按构图保留适当留白。

## 真人摄影

```text
【任务与参考】
依据实际参考与本轮设计生成单人完整全身人物资产，明确身份、衣装与风格来源，未见部位标为设计延展。本编译示例采用三比四白底检查图；实际生产按用户指定的场景、动作和取景编写。

【核心目标】
真实人物摄影质感：真实软组织、克制肤质与光学成像共同成立，精致妆容、服装结构与人物辨识度保持，不以粗糙皮肤证明真人感。

【人物身份与面容】
保持参考脸型与五官辨识点，眼睑厚度、眼球湿润反射、鼻唇与面颊软组织连续，呈现真实人物的体积。

【表情与眼神】
在保留人物辨识度和表观年龄的基础上，允许按本轮气质、姿态、背景与用途适配表情。明确眼神、眉眼张力、嘴角和唇部开合，选择一个自然协调的结果，不默认锁死参考神态，也不统一微笑。用户指定的表情与视线优先；表情运动可自然改变眼睑、面颊与嘴角，不能借此换脸或改变既定头部朝向。

【动作协调与生命感】
本素材采用静态正面检查姿态；实际生产可按用途与场景自动选择动作，也支持夸张伸展、跳跃或旋转，不把本例站姿当作通用限制。让视线与表情服务动作意图，肩颈和手指有自然松紧及不对称，衣料和头发响应重力与惯性。安静姿态也应有专注和呼吸感，不用僵直躯干、统一笑容、粗糙皮肤或大量飞发代替活人感。

【妆容与肌肤】
先完成贴肤精致妆容，再按景别呈现细微肤色和反射变化；近景可见克制纹理，全身小脸不强显毛孔，不磨成蜡皮。

【发型与头饰】
发型、发色和饰物来自参考；主发束与少量清楚发丝结合，反光沿毛发生长方向，不把全头画成同样粗亮的线。

【服装设计】
保留参考可见的领口、胸前、肩部、袖型、配色关系、纹样位置及设计语言；腰以下等未见部位依照同一设计自然延展，不把补全描述为原图已有。 不将不同角色套成同一件华服；主色、点缀色、纹样和护甲位置要根据本张参考逐项填写。

【材质与服装真实感】
服装按实际材质表现织纹、厚度、重力褶皱与接缝，金属局部反光、皮革细腻反射、薄纱透叠分别成立，不添加原设计没有的材料。 细节集中于可见面容、服装接缝与材料差异，肤质和织纹尺度服从景别，不全身等量锐化。

【构图与姿态】
本正面资产案例中，人物居中，头部端正，面部、双肩与骨盆正对镜头，目光看镜头，站姿自然稳定；具体用户姿态优先于本案例。双手在下腹前自然轻叠，右手轻搭左手手背，手腕方向清楚，手指放松不交叉纠缠。每手在解剖上为一拇指四手指，允许自然遮挡，只检查可见指节与袖口连接。 平视感与较弱透视，从最高发饰到自然衣摆或可见鞋履的完整轮廓入画，四周保留合理留白。不要为填满竖幅拉高人物。

【人物占比与留白】
本全身展示中，人物连同头饰、衣摆和鞋履的完整外轮廓约占画面高度八成至八成半，作为取景起点；头顶、脚下与左右最外侧衣饰均留出舒展空间，宽袖和拖尾以完整容纳为先。人物清楚可读，不贴边、不为了填满画幅拉伸身体；通过取景距离或扩展画布调整占比，用户指定构图优先。

【身材比例】
人物身材比例协调、修长好看，头肩相称、肩颈舒展，胸廓、腰腹和骨盆完整，腰臀与上下肢的长度、粗细自然衔接；保留适度柔和肌肉与软组织体积，不靠极端缩头、拉长脖子、纸片腰或单独拉腿制造修长。 躯干解剖关系完整，通过协调的髋膝踝关系表现修长，不生硬拉伸腿部。比例修正保持面宽相对头高、五官间距比例和脸型；必要时协调调整完整头部与身体的尺度，不单独压窄脸部或缩放某个五官，也不无条件冻结未达标的原头身关系。 袖摆宽度与既定服装设计协调，衣服支持修长观感而非将人物压成窄长筒。 肩、胸廓、腰和骨盆协调，腰部自然收束、臀部有体积；上臂、前臂、肘腕手与大腿、膝、小腿、脚踝在长度和粗细上相称。黄金比例是审美方向，不是通用数值公式，也不是透过衣服推断的人体测量。 可见肩臂、腰腿有适度均匀肌肉体积和柔和线条，随动作收缩放松；保留自然软组织，不画细杆四肢、纸片腰、健美分块或穿透不透明衣料的肌肉。

【手部与脚部完整性】
每只手在解剖上为一拇指四手指，可见指节和腕部连接自然，不融合、不重复；自然交叠时允许遮挡，不强行展开十指。鞋型沿用本角色风格；鞋履是否可见由站姿与衣摆重力决定，允许遮住一脚或双脚，不强制鞋尖露出。完整自然轮廓在画幅内，整体承重和接地关系可信；不为露鞋掀裙或改变裙长。

【背景与灯光】
白底资产采用真实摄影棚柔光与中性白平衡，阴影与人物受光一致，保留面部体积、浅衣边缘和轻微接触阴影。 视觉重点放在面部与上身；高光、亮色块或纸白按所选媒介表达，次要衣摆与附件不过亮，不新增发光装饰。 轮廓服从柔和棚光和真实材质：眼睑、衣料接缝与必要结构清楚，细发、薄纱和次要边缘自然柔化，保持白衣与白底分离；不描黑边，不锐化整圈轮廓。

【最终目标】
完整人物像真实拍摄的精致定妆照，皮肤、头发、衣料与光线处于同一摄影媒介，不混入卡通描线或雕塑表面。
```
