# 同一原创人物的多造型完整提示词

由 `npm run examples:build` 从 [造型方案](portrait-look-diversity-plan.json) 编译。[来源分析与优化方案](../docs/portrait-look-diversity-analysis-2026-10-15.md)仅用于提炼方法；这里另行原创人物，不复刻附件面容，不把旧拼板作为身份输入。

本例按来源场景演示十套、日韩风五套与中国风五套；这些是设计分组，不是人物族群、专属起源或2026流行榜单，实际任务的数量与分组另定。每套继承同一身份、正脸端正头位、自然乌黑发色、取景、身材和布光，分别选择脸前结构、妆面及可见表演。

这是文字设计演练。声明查重与编译通过不证明实际造型差异、本人保持、适配、流行度或用户接受，尚未生成新图。以下每套正文独立完整，可分别复制；真实参考任务仍须绑定并实际提供自己的身份原图。

## 日韩风演练：偏分齐颌短波波

```text
【人物身份与面容】
同一位二十八岁成年女性，中性偏暖肤色，短椭圆脸，颊部柔和，下颌转折平缓；眉眼横向舒展，自然眉形略有左右差异，鼻梁高度适中、鼻翼有自然宽度，上下唇体积均衡。所有方案保持这组脸型与五官间距、年龄和肤色，不借发型适配削脸、放大眼睛或换人。

【构图与视点】
单人肩部以上正面平视肖像，头脸正向镜头、头部端正，不侧转、不左右偏头或仰俯。头顶与主要发型完整入画，双眼、鼻唇与下颌清楚，四周留白；每套单独一张，画面无文字、分格或其他人物。

【可见头肩比例】
按修长舒展的黄金身材比例方向美化本肖像可见头颈肩：头肩相称、肩线自然展开，颈肩连接完整，不拉长脖子，不推断未显示的全身。
可见颈肩与上身轮廓苗条利落，保留自然厚度，不用缩头、纸片颈肩或露骨削瘦制造修长。
颈肩与可见上身适当有肌肉，呈现克制紧致的软组织与支撑，姿态舒展，不松垮，也不刻出粗大僵硬肌肉；画外肌肉不作判断。

【画面表现】
自然细腻的人物摄影表现，五官和软组织有可信体积，保持清楚的面容设计与生命感。

【可见衣装】
所有方案均为同一件简洁深灰色圆领上衣，仅展示自然连接的领口与肩部；面料低光泽，不用换衣或夸张首饰代替妆发及表演差异。

【背景】
统一浅暖灰无缝背景与柔和近正面棚光，眉眼和唇缘清楚，保留颊颌体积；不换光色、失焦或镜头角度制造造型差异。

【发型与头饰】
所有方案均为自然乌黑发色，发束有柔和分区高光，不借染棕、染红或漂浅制造差异。发根、主束与发梢连接自然；少量细发优先留在鬓角和轮廓边缘，禁止过多碎发遮挡眉眼、鼻口与关键辨识点。
自然乌黑的齐颌短波波，人物自身左侧深偏分，额前由一块向右展开、宽而轻薄的侧向短刘海构成，边缘停在眉毛上方；人物自身左耳后收净，右侧发尾在下颌外轻轻内扣。发根蓬松，颧颊前不留成排长细丝。

【表情与情绪】
安静自信；视线平稳直向镜头；眉峰保持自然，眉间舒展；上眼睑放松但目光有焦点；双唇轻合，嘴角轻微上提而不露齿。

【妆容与肌肤】
眉妆采用自然深棕细毛流；眼窝以低饱和灰棕薄晕染，细内眼线与纤细睫毛保持清楚。低位淡玫瑰腮红融入肤色，豆沙玫瑰唇色为柔和半哑光，鼻颊高光窄而克制。
```
